# Linear equations (1 & 2 variables)

> **Why it matters:** Linear equations (সরল সমীকরণ) are behind word problems on numbers, prices, digits, ages and fractions. BCS and bank exams also ask when a pair of equations has one, none or infinitely many solutions.

## Key concepts
- A **linear equation** has variables with power 1 only: ax + b = 0 (one variable) or ax + by = c (two variables).
- **One variable:** bring all x-terms to one side and numbers to the other. Whatever you do to one side, do to the other.
- **Two variables** need **two independent equations**. Methods:
  - **Substitution (প্রতিস্থাপন):** get one variable from one equation and put it into the other.
  - **Elimination (অপনয়ন):** make one variable's coefficients equal, then add or subtract.
  - **Cross-multiplication (আড়গুণন):** for a₁x + b₁y + c₁ = 0 and a₂x + b₂y + c₂ = 0.
- Graph of a linear equation in two variables is a **straight line**.

## Consistency of a pair of equations 🔥
For a₁x + b₁y = c₁ and a₂x + b₂y = c₂:

| Condition | Solutions | Lines |
|---|---|---|
| a₁/a₂ ≠ b₁/b₂ | **Exactly one** (consistent, independent) | Intersect |
| a₁/a₂ = b₁/b₂ ≠ c₁/c₂ | **No solution** (inconsistent) | Parallel |
| a₁/a₂ = b₁/b₂ = c₁/c₂ | **Infinitely many** (dependent) | Coincident |

## Shortcut table
| Situation | Shortcut |
|---|---|
| x + y = S, x − y = D | x = (S + D)/2, y = (S − D)/2 |
| ax + by = p and bx + ay = q | Add: (a + b)(x + y) = p + q; subtract: (a − b)(x − y) = p − q |
| Two-digit number with digits a (tens) and b (units) | 10a + b; reversed 10b + a; difference = 9(a − b) |
| MCQ with options | Put each option into both equations |

## Worked examples
**Example 1.** Solve 3x − 5 = 2x + 7.
Steps: 3x − 2x = 7 + 5 → x = 12.
**Answer: x = 12**

**Example 2.** Solve 2x + 3y = 12 and 3x − y = 7.
Steps: y = 3x − 7. 2x + 3(3x − 7) = 12 → 11x = 33 → x = 3, y = 2.
**Answer: x = 3, y = 2**

**Example 3.** 3 pens and 2 pencils cost Tk 50; 2 pens and 3 pencils cost Tk 45. Find the price of a pen.
Steps: Add: 5(p + q) = 95 → p + q = 19. Subtract: p − q = 5. p = 12, q = 7.
**Answer: Tk 12**

**Example 4.** The sum of the digits of a two-digit number is 9. Reversing the digits increases the number by 27. Find the number.
Steps: a + b = 9, 9(b − a) = 27 → b − a = 3 → b = 6, a = 3.
**Answer: 36**

**Example 5.** For what value of k do kx + 2y = 5 and 3x + y = 1 have no solution?
Steps: k/3 = 2/1 → k = 6 (and 2/1 ≠ 5/1, so no solution).
**Answer: k = 6**

## Common traps
- Changing the sign wrongly when moving a term across "=".
- Answering x when y is asked (or the number when its reversal is asked).
- "No solution" needs a₁/a₂ = b₁/b₂ **but** ≠ c₁/c₂; if all three are equal there are infinitely many.
- In digit problems, the number is 10a + b, not a + b.

## Quick revision
- Two unknowns need two equations.
- x + y = S, x − y = D ⇒ x = (S + D)/2.
- Unique solution: a₁/a₂ ≠ b₁/b₂.
- Parallel lines: a₁/a₂ = b₁/b₂ ≠ c₁/c₂.
- Same line: all three ratios equal.
- Reversing digits changes the number by 9 × (difference of digits).

## Practice MCQ
**1.** If x/2 + x/3 = 10, then x = ?
(a) 10 (b) 12 (c) 6 (d) 60

**2.** If x + y = 12 and x − y = 2, then x = ?
(a) 5 (b) 6 (c) 7 (d) 10

**3.** If 2x + y = 7 and x + 2y = 8, then y = ?
(a) 2 (b) 4 (c) 5 (d) 3

**4.** A fraction becomes 1/2 if 1 is added to its numerator, and 1/3 if 1 is subtracted from its denominator. The fraction is:
(a) 1/4 (b) 2/5 (c) 1/3 (d) 3/8

**5.** The equations 2x + 3y = 5 and 4x + 6y = 10 have:
(a) one solution (b) no solution (c) infinitely many solutions (d) two solutions

**6.** For what value of k do 2x + ky = 3 and 4x + 6y = 7 have no solution?
(a) 2 (b) 3 (c) 6 (d) 12

**7.** The sum of the digits of a two-digit number is 9. When the digits are reversed, the number increases by 27. The number is:
(a) 63 (b) 45 (c) 27 (d) 36

**8.** 2 chairs and 1 table cost Tk 1,700; 1 chair and 2 tables cost Tk 2,500. The price of a table is:
(a) Tk 1,100 (b) Tk 800 (c) Tk 300 (d) Tk 1,400

**9.** A wallet has 50 notes of Tk 10 and Tk 20, worth Tk 700 in all. The number of Tk 10 notes is:
(a) 20 (b) 25 (c) 30 (d) 35

**10.** The lines x + 2y = 4 and 2x + 4y = 12 are:
(a) intersecting (b) parallel (c) coincident (d) perpendicular

## Answer key
| Q | Ans | Explanation |
|---|---|---|
| 1 | b | 5x/6 = 10 → x = 12 |
| 2 | c | x = (12 + 2)/2 = 7 |
| 3 | d | x + y = 5, x − y = −1 → x = 2, y = 3 |
| 4 | a | d = 2n + 2 and d − 1 = 3n → n = 1, d = 4 |
| 5 | c | 2/4 = 3/6 = 5/10 → same line |
| 6 | b | 2/4 = k/6 → k = 3; 3/7 ≠ 1/2 |
| 7 | d | b − a = 3, a + b = 9 → 36 |
| 8 | a | c + t = 1400, c − t = −800 → t = 1100 |
| 9 | c | x + y = 50, x + 2y = 70 → y = 20, x = 30 |
| 10 | b | 1/2 = 2/4 ≠ 4/12 → parallel, no solution |

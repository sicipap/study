# Input & output devices

> **Why it matters:** Exams give a list of devices and ask which one is an input, output or both; they also ask about MICR (cheques), OMR (answer sheets), barcode readers and printer types.

## Input devices (ইনপুট ডিভাইস) 🔥
Devices that send data **into** the computer.

| Device | Key fact |
|---|---|
| **Keyboard** | Main input device; common layout **QWERTY**. Standard PC keyboard has about 101–104 keys |
| **Mouse** | Pointing device; invented by **Douglas Engelbart** (1960s) |
| **Scanner** | Converts paper documents/images to digital form |
| 🔥 **MICR** (Magnetic Ink Character Recognition) | Reads characters printed with magnetic ink; used by **banks to process cheques** |
| 🔥 **OMR** (Optical Mark Reader/Recognition) | Reads **marks (filled circles)**; used to check **MCQ answer sheets** and admission tests |
| **OCR** (Optical Character Recognition) | Converts printed/handwritten **text** in an image into editable text |
| **Barcode reader** | Reads **barcodes** (black and white bars) in shops; uses a laser/light |
| **QR code scanner** | Reads **QR (Quick Response) codes**, 2-D codes (invented by Denso Wave, Japan) |
| **Light pen** | Draws or selects directly on the screen |
| **Joystick** | Used in games and simulators |
| **Trackball, touchpad** | Pointing devices on laptops |
| **Digitizer / graphics tablet** | Converts drawings into digital form; used in design (CAD) |
| **Microphone** | Audio input |
| **Webcam, digital camera** | Image/video input |
| **Biometric scanner** | Fingerprint, iris or face reader (used in NID, SIM registration, attendance) |

## Output devices (আউটপুট ডিভাইস) 🔥
Devices that show or give results **from** the computer.

| Device | Key fact |
|---|---|
| **Monitor (VDU)** | **Main (soft-copy) output device**. Types: **CRT**, **LCD**, **LED**, **OLED**, plasma |
| **Printer** | **Hard-copy** output |
| **Plotter** | Prints large drawings: maps, engineering designs, building plans |
| **Speaker / headphone** | Sound output |
| **Projector** | Shows the screen on a large wall/screen |

- **Soft copy:** output on screen. **Hard copy:** output on paper.
- Screen resolution is measured in **pixels**; printer resolution in **dpi (dots per inch)**.
- **Pixel** = picture element, the smallest dot on a screen.

### Printers 🔥
| Type | Examples | Notes |
|---|---|---|
| **Impact printers** (strike the paper) | **Dot-matrix**, daisy-wheel, line printer | Noisy; can print carbon copies |
| **Non-impact printers** | **Laser**, **inkjet**, thermal | Quiet, better quality |

- **Laser printer:** uses **toner** and a drum; fast, high quality; works like a photocopier.
- **Inkjet printer:** sprays ink droplets.
- **Thermal printer:** uses heat; used for **ATM slips, POS receipts**, fax.
- Printer speed: **ppm** (pages per minute); dot-matrix speed in **cps** (characters per second).

## Devices that are both input and output (I/O) 🔥
- **Touchscreen** (input by touch + output display)
- **Modem** (sends and receives data)
- **Network card (NIC)**, **fax machine**, **headset with microphone**
- **Storage devices** such as pen drives and hard disks (read = input, write = output)
- **Multifunction printer** with a scanner

## Ports and connectors
| Port | Used for |
|---|---|
| **USB** (Universal Serial Bus) | Most devices; plug and play |
| **HDMI** | High-definition audio and video to monitor/TV |
| **VGA** | Older analog video to monitor |
| **RJ-45** | Ethernet (network) cable |
| **RJ-11** | Telephone line |
| **PS/2** | Old keyboard/mouse port |

## Quick revision
- Cheque processing in banks: **MICR**.
- MCQ answer sheet checking: **OMR**.
- Converting printed text to editable text: **OCR**.
- Large maps and engineering drawings: **plotter**.
- Main output device: **monitor**; soft copy on screen, hard copy on paper.
- Dot-matrix = **impact**; laser/inkjet = **non-impact**.
- Touchscreen and modem are **both input and output**.
- Printer resolution: **dpi**.

## Practice MCQ
**1.** Which device is used by banks to read cheques?
(a) OMR (b) OCR (c) MICR (d) Barcode reader

**2.** Answer sheets of MCQ admission tests are checked by:
(a) OMR (b) MICR (c) Plotter (d) Light pen

**3.** Which of the following is an output device?
(a) Scanner (b) Plotter (c) Joystick (d) Microphone

**4.** Which printer is an impact printer?
(a) Laser printer (b) Inkjet printer (c) Thermal printer (d) Dot-matrix printer

**5.** Which device works as both an input and an output device?
(a) Touchscreen (b) Keyboard (c) Mouse (d) Printer

**6.** Printer resolution is measured in:
(a) ppm (b) dpi (c) bps (d) Hz

**7.** Which technology converts a scanned page of printed text into editable text?
(a) MICR (b) OMR (c) OCR (d) RFID

**8.** The output shown on a monitor screen is called:
(a) Hard copy (b) Print copy (c) Carbon copy (d) Soft copy

## Answer key
| Q | Ans | Explanation |
|---|---|---|
| 1 | c | MICR reads magnetic-ink characters on cheques |
| 2 | a | OMR reads filled marks |
| 3 | b | Plotter prints large drawings |
| 4 | d | Dot-matrix pins strike a ribbon |
| 5 | a | Touchscreen takes touch input and displays output |
| 6 | b | dpi = dots per inch |
| 7 | c | OCR = Optical Character Recognition |
| 8 | d | Screen output = soft copy |

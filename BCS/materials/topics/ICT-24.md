## Quick revision
- ASCII: **American Standard Code for Information Interchange**.
- MODEM: **Modulator–Demodulator**; ISP: **Internet Service Provider**.
- URL: **Uniform Resource Locator**; HTML: **HyperText Markup Language**.
- SWIFT: **Society for Worldwide Interbank Financial Telecommunication**.
- GSM: **Global System for Mobile Communications**; LTE: **Long Term Evolution**.
- GPT: **Generative Pre-trained Transformer**.
- CAPTCHA ends with **"…Computers and Humans Apart"**.
- COBOL: **Common Business Oriented Language**.
- BIOS: **Basic Input Output System**.

## Practice MCQ
**1.** What is the full form of ASCII?
(a) American Standard Code for Information Interchange (b) American Standard Code for Internet Interchange (c) Advanced Standard Code for Information Interchange (d) American Scientific Code for Information Interchange

**2.** URL stands for:
(a) Universal Resource Link (b) Uniform Resource Link (c) Uniform Resource Locator (d) Universal Resource Locator

**3.** In banking, SWIFT stands for:
(a) Secure Worldwide Interbank Fund Transfer (b) Society for Worldwide Interbank Financial Telecommunication (c) Society for World Investment and Financial Trade (d) Standard Wire Interbank Financial Transfer

**4.** What does "MODEM" stand for?
(a) Modern Data Exchange Machine (b) Mobile Data Modulator (c) Memory Device Emulator (d) Modulator–Demodulator

**5.** In GSM, the letter "G" stands for:
(a) Global (b) General (c) Geographic (d) Grand

**6.** The full form of HTTP is:
(a) High Transfer Text Protocol (b) HyperText Transfer Protocol (c) Hyperlink Text Transmission Protocol (d) HyperText Transmission Program

**7.** The "Turing test" in the full form of CAPTCHA is named after:
(a) Tim Berners-Lee (b) Ted Hoff (c) Alan Turing (d) Linus Torvalds

**8.** What is the full form of BIOS?
(a) Binary Input Output System (b) Basic Integrated Operating System (c) Basic Internal Operating Software (d) Basic Input Output System

## Answer key
| Q | Ans | Explanation |
|---|---|---|
| 1 | a | 7-bit character code standard |
| 2 | c | Uniform Resource Locator = web address |
| 3 | b | SWIFT is the interbank messaging network |
| 4 | d | Modulates and demodulates signals |
| 5 | a | Global System for Mobile Communications |
| 6 | b | HyperText Transfer Protocol |
| 7 | c | Public Turing test, after Alan Turing |
| 8 | d | Firmware that starts the computer |

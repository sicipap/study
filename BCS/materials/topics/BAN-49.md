# এক কথায় প্রকাশ

> **Why it matters:** "'যা পূর্বে শোনা যায়নি' — এক কথায় কী?", "'বেঁচে থাকার ইচ্ছা' — এক কথায়?" — প্রায় প্রতিটি পরীক্ষায় ১–২টি প্রশ্ন। বিশেষ করে **"ইচ্ছা"** সূচক শব্দগুলো (জিগীষা, জিজীবিষা, জিঘাংসা) বারবার আসে।

## এক কথায় প্রকাশ কী
একটি বাক্যাংশ বা বর্ণনাকে **একটি শব্দে** প্রকাশ করাকে **এক কথায় প্রকাশ** (বাক্য সংকোচন) বলে। এতে ভাষা সংক্ষিপ্ত ও শ্রুতিমধুর হয়।

## "ইচ্ছা" বোঝায় এমন শব্দ 🔥
| বর্ণনা | এক কথায় |
|---|---|
| **জয় করার ইচ্ছা** | **জিগীষা** |
| **বেঁচে থাকার ইচ্ছা** | **জিজীবিষা** |
| **হত্যা করার ইচ্ছা** | **জিঘাংসা** |
| **জানার ইচ্ছা** | **জিজ্ঞাসা** |
| **দেখার ইচ্ছা** | **দিদৃক্ষা** |
| **পান করার ইচ্ছা** | **পিপাসা** |
| **ক্ষুধা / খাওয়ার ইচ্ছা** | **বুভুক্ষা** |
| **মুক্তি পাওয়ার ইচ্ছা** | **মুমুক্ষা** (যে মুক্তি চায় — **মুমুক্ষু**) |
| **মরণের ইচ্ছা** / মরণাপন্ন | **মুমূর্ষা** / **মুমূর্ষু** |
| **কিছু করার ইচ্ছা** | **চিকীর্ষা** |
| **উপকার করার ইচ্ছা** | **উপচিকীর্ষা** |
| **অনুসন্ধান করার ইচ্ছা** | **অনুসন্ধিৎসা** |

## বহুল জিজ্ঞাসিত এক কথায় প্রকাশ 🔥
| বর্ণনা | এক কথায় | বর্ণনা | এক কথায় |
|---|---|---|---|
| অকালে পেকেছে যা | **অকালপক্ব / ইঁচড়ে পাকা** | যা পূর্বে ছিল, এখন নেই | **ভূতপূর্ব** |
| অক্ষির অগোচরে | **পরোক্ষ** | যা পূর্বে দেখা যায়নি | **অদৃষ্টপূর্ব** |
| অক্ষির সমীপে | **সমক্ষ** | যা পূর্বে শোনা যায়নি 🔥 | **অশ্রুতপূর্ব** |
| অগ্র-পশ্চাৎ বিবেচনা না করে কাজ করে যে 🔥 | **অবিমৃশ্যকারী** | যা কখনো ভাবা যায়নি | **অভাবনীয়** |
| অনেকের মধ্যে একজন | **অন্যতম** | যা বলা হয়নি | **অনুক্ত** |
| অন্য উপায় নেই যার | **অনন্যোপায়** | যা বর্ণনা করা যায় না | **অবর্ণনীয়** |
| অন্য গতি নেই যার | **অনন্যগতি** | যা নিবারণ করা যায় না | **অনিবার্য** |
| অহংকার নেই যার | **নিরহংকার** | যা সহজে ভাঙে | **ভঙ্গুর** |
| আকাশে চরে যে | **খেচর** | যার কোনো উপায় নেই | **নিরুপায়** |
| জলে চরে যে | **জলচর** | যার দুই হাত সমান চলে 🔥 | **সব্যসাচী** |
| নিজেকে পণ্ডিত মনে করে যে 🔥 | **পণ্ডিতম্মন্য** | যার পত্নী মারা গেছে | **বিপত্নীক** |
| নিজেকে কেন্দ্র করে যার চিন্তা | **আত্মকেন্দ্রিক** | যে বিয়ে করেনি (পুরুষ) | **অকৃতদার** |
| ইতিহাস রচনা করেন যিনি | **ঐতিহাসিক** | যে মেয়ের বিয়ে হয়নি | **অনূঢ়া** |
| ঈষৎ উষ্ণ | **কবোষ্ণ / ঈষদুষ্ণ** | যে নারীর স্বামী মারা গেছে | **বিধবা** |
| উপকারীর উপকার স্বীকার করে যে | **কৃতজ্ঞ** | যে নারীর স্বামী ও পুত্র নেই | **অবীরা** |
| উপকারীর অপকার করে যে 🔥 | **কৃতঘ্ন** | যে নারী সূর্য দেখে না 🔥 | **অসূর্যম্পশ্যা** |
| ক্ষমার যোগ্য | **ক্ষমার্হ / ক্ষন্তব্য** | যে বিষয়ে বিতর্ক নেই | **অবিসংবাদিত** |
| চোখের সামনে সংঘটিত | **চাক্ষুষ** | অন্যের দোষ খোঁজে যে | **ছিদ্রান্বেষী** |
| দিনে একবার আহার করে যে | **একাহারী** | যা আঘাত পায়নি | **অনাহত** |
| নষ্ট হওয়াই স্বভাব যার | **নশ্বর** | একবার শুনেই মনে রাখতে পারে যে 🔥 | **শ্রুতিধর** |
| পা থেকে মাথা পর্যন্ত | **আপাদমস্তক** | রাত্রির মধ্যভাগ | **নিশীথ** |
| ফল পাকলে যে গাছ মরে যায় 🔥 | **ওষধি** | শত্রুকে দমন করে যে | **অরিন্দম** |
| বিদেশে থাকে যে | **প্রবাসী** | সকলের জন্য কল্যাণকর | **সর্বজনীন** |
| মাটি ভেদ করে ওঠে যা | **উদ্ভিদ** | সকলে জানে যা | **সর্বজনবিদিত** |
| মাটি দিয়ে তৈরি | **মৃন্ময়** | একই মায়ের সন্তান | **সহোদর** |
| একই সময়ে বর্তমান | **সমসাময়িক** | কোথাও উঁচু, কোথাও নিচু | **বন্ধুর** |
| গাছের নতুন পাতা | **কিশলয় / পল্লব** | হরিণের চামড়া | **অজিন** |

## প্রাণীর ডাক 🔥
| ডাক | এক কথায় |
|---|---|
| **হাতির ডাক** | **বৃংহণ** |
| **ঘোড়ার ডাক** | **হ্রেষা** |
| **ময়ূরের ডাক** | **কেকা** |
| **পাখির কলরব** | **কূজন** |

## Quick revision
- **জিগীষা** = জয়ের ইচ্ছা; **জিজীবিষা** = বাঁচার ইচ্ছা; **জিঘাংসা** = হত্যার ইচ্ছা।
- **দিদৃক্ষা** = দেখার ইচ্ছা; **বুভুক্ষা** = খাওয়ার ইচ্ছা; **মুমূর্ষু** = মরণাপন্ন।
- **অশ্রুতপূর্ব** = আগে শোনা যায়নি; **অদৃষ্টপূর্ব** = আগে দেখা যায়নি।
- **অবিমৃশ্যকারী** = না ভেবে কাজ করে যে; **পণ্ডিতম্মন্য** = নিজেকে পণ্ডিত ভাবে যে।
- **ওষধি** = ফল পাকলে যে গাছ মরে; **অসূর্যম্পশ্যা** = সূর্য দেখে না যে নারী।
- **বৃংহণ** = হাতির ডাক; **হ্রেষা** = ঘোড়ার ডাক; **কেকা** = ময়ূরের ডাক।

## Practice MCQ
**1.** "বেঁচে থাকার ইচ্ছা" — এক কথায় কী?
(ক) জিগীষা (খ) জিজীবিষা (গ) জিঘাংসা (ঘ) জিজ্ঞাসা

**2.** "যা পূর্বে শোনা যায়নি" — এক কথায় কী?
(ক) অদৃষ্টপূর্ব (খ) অভূতপূর্ব (গ) অশ্রুতপূর্ব (ঘ) ভূতপূর্ব

**3.** "ফল পাকলে যে গাছ মরে যায়" — এক কথায় কী?
(ক) বনস্পতি (খ) পরগাছা (গ) গুল্ম (ঘ) ওষধি

**4.** "হাতির ডাক" — এক কথায় কী?
(ক) বৃংহণ (খ) হ্রেষা (গ) কেকা (ঘ) কূজন

**5.** "অগ্র-পশ্চাৎ বিবেচনা না করে কাজ করে যে" — এক কথায় কী?
(ক) অনভিজ্ঞ (খ) অবিমৃশ্যকারী (গ) অকর্মণ্য (ঘ) অকালপক্ব

**6.** "নিজেকে পণ্ডিত মনে করে যে" — এক কথায় কী?
(ক) পণ্ডিতপ্রবর (খ) জ্ঞানী (গ) বিদ্বান (ঘ) পণ্ডিতম্মন্য

**7.** "যার দুই হাত সমান চলে" — এক কথায় কী?
(ক) সব্যসাচী (খ) দ্বিভুজ (গ) দক্ষ (ঘ) অরিন্দম

**8.** "হত্যা করার ইচ্ছা" — এক কথায় কী?
(ক) চিকীর্ষা (খ) মুমূর্ষা (গ) জিঘাংসা (ঘ) দিদৃক্ষা

| 6 | ঘ | পণ্ডিতম্মন্য |
| 7 | ক | অর্জুনের উপাধি সব্যসাচী |

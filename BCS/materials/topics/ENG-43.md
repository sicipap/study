# Spelling (correctly spelt words)

> **Why it matters:** "Which word is correctly spelt?" appears in most BCS, bank and primary-teacher papers. The same tricky words (accommodation, committee, millennium, questionnaire…) are asked again and again.

## Useful spelling rules 🔥
| Rule | Examples |
|---|---|
| **i before e, except after c** (when the sound is "ee") | believe, achieve, niece / **receive, deceive, ceiling, receipt, conceive** |
| Exceptions to the i–e rule | **seize, weird, either, neither, leisure, foreign, height** |
| **Drop silent -e** before a vowel suffix | hope → hoping, write → writing, argue → **argument**, true → **truly** |
| **Keep -e** after *c/g* before *-able/-ous* (soft sound) | **noticeable, changeable, manageable, courageous** |
| **Double the final consonant** (short vowel + stressed last syllable) | begin → **beginning**, occur → **occurred, occurrence**, refer → **referred**, commit → **committed** |
| No doubling if the stress moves or is not on the last syllable | benefit → **benefited**, offer → **offered**, travel → travelled (UK) / traveled (US) |
| **Consonant + y → i** | happy → happiness, carry → carried; but play → played |
| **-ful** has one *l* | beautiful, careful, **successful**; but **fulfil** (UK) / fulfill (US) |
| **-cede / -ceed / -sede** | only **supersede** ends in -sede; **exceed, proceed, succeed** end in -ceed; others end in -cede (precede, concede) |

## British vs American spelling (both are correct)
| British | American |
|---|---|
| colour, honour, labour | color, honor, labor |
| centre, theatre | center, theater |
| programme | program |
| travelled, cancelled | traveled, canceled |
| defence, licence (noun) | defense, license |
| organise / organize | organize |
| judgement (also judgment) | judgment |
| manoeuvre | maneuver |

In an exam, if both forms appear, the question usually has only one "standard" spelling among clearly wrong ones; choose that.

## Quick revision
- **Accommodation**: double c, double m.
- **Committee**: double m, double t, double e.
- **Millennium**: double l, double n.
- **Questionnaire**: double n.
- **Pronunciation**: no "o" after "n" (but *pronounce*).
- **Maintenance**: "ten", not "tain".
- **Separate**: "par" in the middle.
- **Supersede** is the only -sede word.

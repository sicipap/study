# Antonyms

> **Why it matters:** Antonym questions ("The antonym of *affluent* is…") appear in almost every job exam. Examiners often put the **synonym** among the options as a trap, so read carefully.

## Tips
- First recall the **meaning** of the word, then find its opposite.
- Watch for the synonym trap: *Antonym of "diligent"* → the options may include "industrious" (synonym) and "lazy" (answer).
- Many antonyms are formed with **negative prefixes** (see the last table).

## Antonyms with negative prefixes
| Prefix | Rule / examples |
|---|---|
| **un-** | happy → **unhappy**; able → **unable**; fair → **unfair** |
| **in-** | active → **inactive**; correct → **incorrect**; visible → **invisible** |
| **im-** (before b, m, p) | possible → **impossible**; mortal → **immortal**; balance → **imbalance** |
| **il-** (before l) | legal → **illegal**; literate → **illiterate**; logical → **illogical** |
| **ir-** (before r) | regular → **irregular**; responsible → **irresponsible**; relevant → **irrelevant** |
| **dis-** | honest → **dishonest**; agree → **disagree**; loyal → **disloyal** |
| **mis-** | understand → **misunderstand**; fortune → **misfortune** |
| **non-** | violence → **non-violence**; sense → **nonsense** |
| **mal-** | nutrition → **malnutrition**; function → **malfunction** |

Traps: the opposite of *flammable* is **non-flammable** (**inflammable** means the same as *flammable*). *Immoral* = against morals; *amoral* = without moral sense.

## Quick revision
- **Zenith ↔ nadir**; **wax ↔ wane**; **ebb ↔ flow**.
- **Affluent ↔ indigent**; **frugal ↔ extravagant**.
- **Acquit ↔ convict**; **conceal ↔ reveal**.
- **Benevolent ↔ malevolent**; **optimist ↔ pessimist**.
- **Ephemeral ↔ eternal**; **implicit ↔ explicit**.
- **Inflammable** is NOT the opposite of flammable.

## Practice MCQ
**1.** The antonym of "zenith" is:
(a) summit (b) nadir (c) apex (d) peak

**2.** The antonym of "affluent" is:
(a) wealthy (b) fluent (c) indigent (d) generous

**3.** The antonym of "frugal" is:
(a) extravagant (b) thrifty (c) careful (d) fruitful

**4.** The antonym of "acquit" is:
(a) release (b) pardon (c) accuse (d) convict

**5.** The antonym of "conceal" is:
(a) hide (b) reveal (c) cover (d) suppress

**6.** The antonym of "diligent" is:
(a) industrious (b) careful (c) lazy (d) active

**7.** The antonym of "ephemeral" is:
(a) eternal (b) transient (c) brief (d) fleeting

**8.** The antonym of "legal" is:
(a) unlegal (b) inlegal (c) dislegal (d) illegal

## Answer key
| Q | Ans | Explanation |
|---|---|---|
| 1 | b | Zenith = highest point; nadir = lowest point |
| 2 | c | Affluent = rich; indigent = poor |
| 3 | a | Frugal = thrifty; extravagant = wasteful |
| 4 | d | Acquit = declare not guilty; convict = declare guilty |
| 5 | b | Conceal = hide; reveal = disclose |
| 6 | c | Diligent = hard-working; lazy is the opposite |
| 7 | a | Ephemeral = short-lived; eternal = everlasting |
| 8 | d | il- before words starting with l |

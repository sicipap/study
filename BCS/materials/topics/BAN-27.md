# প্রত্যয় (কৃৎ ও তদ্ধিত)

> **Why it matters:** "'কর্তব্য' এর প্রকৃতি-প্রত্যয়", "'গায়ক'", "'নাবিক'", "'দাতা'", "'মানব'" — প্রকৃতি-প্রত্যয় নির্ণয় এবং কৃৎ ও তদ্ধিত প্রত্যয়ের পার্থক্য নিয়মিত প্রশ্ন।

## মূল ধারণা 🔥
- **প্রত্যয়:** ধাতু বা শব্দের **পরে** যে বর্ণ বা বর্ণসমষ্টি যুক্ত হয়ে নতুন শব্দ গঠন করে।
- **প্রকৃতি:** যে মূল ধাতু বা শব্দের সঙ্গে প্রত্যয় যুক্ত হয়। প্রকৃতি দুই প্রকার:
  - **ক্রিয়া প্রকৃতি (ধাতু):** √পড়্, √কৃ — ধাতু বোঝাতে **√** চিহ্ন।
  - **নাম প্রকৃতি (শব্দ):** মনু, সমাজ, ঢাকা।
- প্রত্যয় **দুই প্রকার:**

| প্রত্যয় | কোথায় যুক্ত হয় | গঠিত পদের নাম | উদাহরণ |
|---|---|---|---|
| **কৃৎ প্রত্যয়** | **ধাতুর পরে** | **কৃদন্ত পদ** | √পড়্ + উয়া = পড়ুয়া |
| **তদ্ধিত প্রত্যয়** | **শব্দের (নামপ্রকৃতির) পরে** | **তদ্ধিতান্ত শব্দ** | ঢাকা + ই = ঢাকাই |

- উৎস অনুযায়ী দুটিই আবার **বাংলা** ও **সংস্কৃত** — দুই ভাগে বিভক্ত।

## কৃৎ প্রত্যয় 🔥

### বাংলা কৃৎ প্রত্যয়
| প্রত্যয় | উদাহরণ |
|---|---|
| **অন** | √নাচ্ + অন = **নাচন**, √কাঁদ্ + অন = **কাঁদন** |
| **অনা** | √খেল্ + অনা = **খেলনা**, √বাজ্ + অনা = **বাজনা** |
| **আই** | √লড়্ + আই = **লড়াই**, √বাঁধ্ + আই = **বাঁধাই** |
| **ই** | √হাস্ + ই = **হাসি** |
| **উক** | √মিশ্ + উক = **মিশুক** |
| **উয়া** | √পড়্ + উয়া = **পড়ুয়া** |
| **না** | √ঝর্ + না = **ঝরনা** |
| **তি** | √কাট্ + তি = **কাটতি**, √ঘাট্ + তি = **ঘাটতি**, √বাড়্ + তি = **বাড়তি** |
| **অন্ত** | √চল্ + অন্ত = **চলন্ত**, √ডুব্ + অন্ত = **ডুবন্ত** |

|---|---|
| **তব্য** | 🔥 **√কৃ + তব্য = কর্তব্য**, √দা + তব্য = **দাতব্য**, √জ্ঞা + তব্য = **জ্ঞাতব্য** |
| **অনীয়** | **√কৃ + অনীয় = করণীয়**, √দৃশ্ + অনীয় = **দর্শনীয়**, √পা + অনীয় = **পানীয়** |
| **য** | √কৃ + য = **কার্য**, √ত্যজ্ + য = **ত্যাজ্য**, √বচ্ + য = **বাচ্য** |
| **তৃচ্ (তৃ)** | 🔥 **√দা + তৃচ্ = দাতা**, √কৃ + তৃচ্ = **কর্তা**, √শ্রু + তৃচ্ = **শ্রোতা**, √বচ্ + তৃচ্ = **বক্তা**, √নী + তৃচ্ = **নেতা** |
| **ক্ত (ত)** | √কৃ + ক্ত = **কৃত**, √গম্ + ক্ত = **গত**, √জ্ঞা + ক্ত = **জ্ঞাত**, √দৃশ্ + ক্ত = **দৃষ্ট**, √মৃ + ক্ত = **মৃত**, √বচ্ + ক্ত = **উক্ত**, √দা + ক্ত = **দত্ত** |
| **ক্তি (তি)** | √গম্ + ক্তি = **গতি**, √মন্ + ক্তি = **মতি**, √শক্ + ক্তি = **শক্তি**, √ভজ্ + ক্তি = **ভক্তি**, √দৃশ্ + ক্তি = **দৃষ্টি**, √সৃজ্ + ক্তি = **সৃষ্টি**, √বচ্ + ক্তি = **উক্তি** |
| **অনট্ (অন)** | √গম্ + অনট্ = **গমন**, √দৃশ্ + অনট্ = **দর্শন**, √শ্রু + অনট্ = **শ্রবণ**, √ভুজ্ + অনট্ = **ভোজন**, √নী + অনট্ = **নয়ন** |
| **ণক (অক)** | 🔥 **√গৈ + ণক = গায়ক**, √নী + ণক = **নায়ক**, √পঠ্ + ণক = **পাঠক**, √লিখ্ + ণক = **লেখক**, √কৃ + ণক = **কারক** |
| **ঘঞ্ (অ)** | √পঠ্ + ঘঞ্ = **পাঠ**, √ত্যজ্ + ঘঞ্ = **ত্যাগ**, √যুজ্ + ঘঞ্ = **যোগ**, √ভজ্ + ঘঞ্ = **ভাগ** |
| **শানচ্ (মান/আন)** | √বৃৎ + শানচ্ = **বর্তমান**, √চল্ + শানচ্ = **চলমান**, √দীপ্ + শানচ্ = **দীপ্যমান** |
| **ইষ্ণু** | √সহ্ + ইষ্ণু = **সহিষ্ণু**, √বৃধ্ + ইষ্ণু = **বর্ধিষ্ণু** |
| **উক** | √ভিক্ষ্ + উক = **ভিক্ষুক** |

| **ই** | 🔥 ঢাকা + ই = **ঢাকাই**, চাষ + ই = **চাষি**, রেশম + ই = **রেশমি**, বাঙাল + ই = **বাঙালি** |

| **ষ্ণি (ই)** | দশরথ + ষ্ণি = **দাশরথি** |

| **ষ্ণিক (ইক)** | 🔥 **নৌ + ষ্ণিক = নাবিক**, সমাজ + ষ্ণিক = **সামাজিক**, ধর্ম + ষ্ণিক = **ধার্মিক**, দিন + ষ্ণিক = **দৈনিক**, বর্ষ + ষ্ণিক = **বার্ষিক** |
| **ত্ব** | মনুষ্য + ত্ব = **মনুষ্যত্ব**, গুরু + ত্ব = **গুরুত্ব**, মহৎ + ত্ব = **মহত্ত্ব** |

| **ইন্ (ঈ)** | গুণ + ইন্ = **গুণী**, জ্ঞান + ইন্ = **জ্ঞানী**, ধন + ইন্ = **ধনী** |
| **বিন্ (বী)** | মেধা + বিন্ = **মেধাবী**, মায়া + বিন্ = **মায়াবী**, তেজস্ + বিন্ = **তেজস্বী** |
| **ঈয়** | জাতি + ঈয় = **জাতীয়**, রাষ্ট্র + ঈয় = **রাষ্ট্রীয়** |

**মনে রাখার কৌশল:** *"√ থাকলে কৃৎ, না থাকলে তদ্ধিত" — ধাতু + প্রত্যয় = কৃৎ; শব্দ + প্রত্যয় = তদ্ধিত।*

## Quick revision
- ধাতুর পরে **কৃৎ প্রত্যয়**; শব্দের পরে **তদ্ধিত প্রত্যয়**।
- কর্তব্য = **√কৃ + তব্য**; করণীয় = **√কৃ + অনীয়**।
- দাতা = **√দা + তৃচ্**; গায়ক = **√গৈ + ণক**।
- গমন = **√গম্ + অনট্**; দৃষ্টি = **√দৃশ্ + ক্তি**।
- মানব = **মনু + ষ্ণ**; নাবিক = **নৌ + ষ্ণিক**।
- মেধাবী = **মেধা + বিন্**; বুদ্ধিমান = **বুদ্ধি + মতুপ্**।
- ঢাকাই = **ঢাকা + ই**; ভিখারি = **ভিখ + আরি**।

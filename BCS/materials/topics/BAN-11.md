# সন্ধি: ব্যঞ্জন, বিসর্গ, নিপাতনে সিদ্ধ

> **Why it matters:** উচ্ছ্বাস, উল্লেখ, সংবাদ, মনোযোগ, নিরাকার, নীরব, নিশ্চয়, পরিচ্ছেদ, বৃহস্পতি, আশ্চর্য, ষোড়শ — ব্যঞ্জন ও বিসর্গ সন্ধির এসব বিচ্ছেদ প্রায় প্রতিটি পরীক্ষায় আসে।

## ব্যঞ্জনসন্ধি
স্বরে-ব্যঞ্জনে, ব্যঞ্জনে-স্বরে বা ব্যঞ্জনে-ব্যঞ্জনে মিলনকে **ব্যঞ্জনসন্ধি** বলে।

### ১. স্বর + ছ = চ্ছ 🔥
**পরি + ছেদ = পরিচ্ছেদ**, **বি + ছেদ = বিচ্ছেদ**, **অনু + ছেদ = অনুচ্ছেদ**, **এক + ছত্র = একচ্ছত্র**, **প্রতি + ছবি = প্রতিচ্ছবি**।

### ২. ক্, চ্, ট্, ত্, প্ + স্বর = গ্, জ্, ড্, দ্, ব্
**দিক্ + অন্ত = দিগন্ত**, **বাক্ + ঈশ = বাগীশ**, **ষট্ + আনন = ষড়ানন**, **তৎ + অবধি = তদবধি**, **সৎ + আনন্দ = সদানন্দ**, **জগৎ + ঈশ = জগদীশ**, **সুপ্ + অন্ত = সুবন্ত**।

### ৩. ক্, চ্, ট্, ত্, প্ + ঘোষ ধ্বনি = বর্গের তৃতীয় বর্ণ
**দিক্ + গজ = দিগ্‌গজ**, **বাক্ + দান = বাগ্‌দান**, **উৎ + ঘাটন = উদ্‌ঘাটন**, **সৎ + ভাব = সদ্ভাব**, **তৎ + রূপ = তদ্রূপ**, **উৎ + যোগ = উদ্যোগ**, **ভগবৎ + গীতা = ভগবদ্গীতা**।

### ৪. ক্, ত্, ট্ + ন/ম = নাসিক্য বর্ণ
**বাক্ + ময় = বাঙ্ময়**, **দিক্ + নির্ণয় = দিঙ্‌নির্ণয়**, **জগৎ + নাথ = জগন্নাথ**, **উৎ + নতি = উন্নতি**, **চিৎ + ময় = চিন্ময়**, **মৃৎ + ময় = মৃন্ময়**, **তৎ + মধ্যে = তন্মধ্যে**, **ষট্ + মাস = ষণ্মাস**।

### ৫. ত্/দ্ এর পরে বিভিন্ন ব্যঞ্জন 🔥
| নিয়ম | উদাহরণ |
|---|---|
| ত্/দ্ + চ/ছ = চ্চ/চ্ছ | **উৎ + চারণ = উচ্চারণ**, **সৎ + চরিত্র = সচ্চরিত্র**, **উৎ + ছেদ = উচ্ছেদ** |
| ত্/দ্ + জ/ঝ = জ্জ/জ্ঝ | **সৎ + জন = সজ্জন**, **উৎ + জ্বল = উজ্জ্বল**, **যাবৎ + জীবন = যাবজ্জীবন**, **বিপদ্ + জাল = বিপজ্জাল**, **কুৎ + ঝটিকা = কুজ্ঝটিকা** |
| ত্/দ্ + শ = চ্ছ | **উৎ + শ্বাস = উচ্ছ্বাস**, **চলৎ + শক্তি = চলচ্ছক্তি** |
| ত্/দ্ + হ = দ্ধ | **উৎ + হার = উদ্ধার**, **তৎ + হিত = তদ্ধিত**, **উৎ + হত = উদ্ধত**, **পদ্ + হতি = পদ্ধতি** |
| ত্/দ্ + ল = ল্ল | **উৎ + লাস = উল্লাস**, **উৎ + লেখ = উল্লেখ** |
| ত্/দ্ + ট/ড = ট্ট/ড্ড | **বৃহৎ + টীকা = বৃহট্টীকা**, **উৎ + ডীন = উড্ডীন** |

### ৬. ম্ এর পরে ব্যঞ্জন 🔥
- ম্ + বর্গীয় বর্ণ = ং বা সেই বর্গের নাসিক্য: **সম্ + চয় = সঞ্চয়**, **সম্ + তোষ = সন্তোষ**, **কিম্ + কর = কিঙ্কর**, **সম্ + গীত = সংগীত**।
- ম্ + য, র, ল, ব, শ, ষ, স, হ = ং: **সম্ + বাদ = সংবাদ**, **সম্ + যম = সংযম**, **সম্ + সার = সংসার**, **সম্ + হার = সংহার**, **সম্ + শয় = সংশয়**, **সম্ + রক্ষণ = সংরক্ষণ**।

### ৭. অন্যান্য
- চ্/জ্ + ন = ঞ: **যাচ্ + না = যাচ্ঞা**, **রাজ্ + নী = রাজ্ঞী**।
- ষ্ + ত = ষ্ট; ষ্ + থ = ষ্ঠ: **কৃষ্ + তি = কৃষ্টি**, **সৃষ্ + তি = সৃষ্টি**, **ষষ্ + থ = ষষ্ঠ**।

## বিসর্গসন্ধি
বিসর্গের (ঃ) সঙ্গে স্বর বা ব্যঞ্জনের মিলন। বিসর্গ দুই রকম: **র্-জাত** (নিঃ, দুঃ, আশীঃ) ও **স্-জাত** (মনঃ, তিরঃ, নমঃ)।

| নিয়ম | উদাহরণ |
|---|---|
| **অঃ + ঘোষ ব্যঞ্জন = ও** 🔥 | **মনঃ + যোগ = মনোযোগ**, **তিরঃ + ধান = তিরোধান**, **সদ্যঃ + জাত = সদ্যোজাত**, **বয়ঃ + বৃদ্ধ = বয়োবৃদ্ধ**, **যশঃ + দা = যশোদা**, **তপঃ + বন = তপোবন**, **মনঃ + রম = মনোরম**, **পুরঃ + হিত = পুরোহিত** |
| **অ/আ ভিন্ন স্বর + ঃ + ঘোষ ধ্বনি/স্বর = র্** | **নিঃ + আকার = নিরাকার**, **দুঃ + যোগ = দুর্যোগ**, **আশীঃ + বাদ = আশীর্বাদ**, **দুঃ + নীতি = দুর্নীতি**, **জ্যোতিঃ + ময় = জ্যোতির্ময়**, **বহিঃ + গত = বহির্গত**, **প্রাদুঃ + ভাব = প্রাদুর্ভাব** |
| **র্ + র = আগের স্বর দীর্ঘ, র্ লোপ** 🔥 | **নিঃ + রব = নীরব**, **নিঃ + রস = নীরস**, **নিঃ + রোগ = নীরোগ** |
| ঃ + চ/ছ = শ্ | **নিঃ + চয় = নিশ্চয়**, **দুঃ + চরিত্র = দুশ্চরিত্র**, **শিরঃ + ছেদ = শিরশ্ছেদ**, **নিঃ + ছিদ্র = নিশ্ছিদ্র** |
| ঃ + ট/ঠ = ষ্ | **ধনুঃ + টংকার = ধনুষ্টংকার** |
| ঃ + ত/থ = স্ | **দুঃ + তর = দুস্তর**, **মনঃ + তাপ = মনস্তাপ**, **নিঃ + তেজ = নিস্তেজ** |
| ই/উ + ঃ + ক/খ/প/ফ = ষ্ | **নিঃ + কাম = নিষ্কাম**, **দুঃ + কর = দুষ্কর**, **নিঃ + পাপ = নিষ্পাপ**, **চতুঃ + পদ = চতুষ্পদ**, **আবিঃ + কার = আবিষ্কার**, **বহিঃ + কার = বহিষ্কার** |
| অঃ + ক/প = স্ (কিছু শব্দে) | **নমঃ + কার = নমস্কার**, **পুরঃ + কার = পুরস্কার**, **তিরঃ + কার = তিরস্কার** |
| বিসর্গ অপরিবর্তিত | **প্রাতঃ + কাল = প্রাতঃকাল**, **মনঃ + কষ্ট = মনঃকষ্ট** |
| ঃ + স্ত/স্থ/স্প = বিসর্গ লোপ | **নিঃ + স্তব্ধ = নিস্তব্ধ**, **দুঃ + স্থ = দুস্থ**, **নিঃ + স্পৃহ = নিস্পৃহ** |

## নিপাতনে সিদ্ধ সন্ধি 🔥🔥
যেসব সন্ধি ব্যাকরণের নিয়ম মানে না, প্রচলিত রূপেই শুদ্ধ।

| প্রকার | উদাহরণ |
|---|---|
| **স্বরসন্ধি** | **গো + অক্ষ = গবাক্ষ**, **কুল + অটা = কুলটা**, **প্র + ঊঢ় = প্রৌঢ়**, **অন্য + অন্য = অন্যান্য**, **মার্ত + অণ্ড = মার্তণ্ড**, **শুদ্ধ + ওদন = শুদ্ধোদন** |
| **ব্যঞ্জনসন্ধি** | **আ + চর্য = আশ্চর্য**, **গো + পদ = গোষ্পদ**, **বন + পতি = বনস্পতি**, **বৃহৎ + পতি = বৃহস্পতি**, **তৎ + কর = তস্কর**, **পর + পর = পরস্পর**, **মনস্ + ঈষা = মনীষা**, **ষট্ + দশ = ষোড়শ**, **এক + দশ = একাদশ**, **পতৎ + অঞ্জলি = পতঞ্জলি** |
| **বিসর্গসন্ধি** | **বাচঃ + পতি = বাচস্পতি**, **ভাঃ + কর = ভাস্কর**, **অহঃ + অহ = অহরহ**, **অহঃ + নিশা = অহর্নিশ** |

**মনে রাখার কৌশল:** *"আশ্চর্য গবাক্ষে বৃহস্পতি তস্কর ষোড়শ বনস্পতি গুনছে" — সব নিপাতনে সিদ্ধ।*

## Quick revision
- পরিচ্ছেদ = **পরি + ছেদ**; উচ্ছ্বাস = **উৎ + শ্বাস**।
- উদ্ধার = **উৎ + হার**; উল্লেখ = **উৎ + লেখ**।
- সংবাদ = **সম্ + বাদ**; বাঙ্ময় = **বাক্ + ময়**।
- মনোযোগ = **মনঃ + যোগ**; নিরাকার = **নিঃ + আকার**।
- নীরব = **নিঃ + রব**; নিশ্চয় = **নিঃ + চয়**।
- নিষ্পাপ = **নিঃ + পাপ**; নমস্কার = **নমঃ + কার**।
- আশ্চর্য, বৃহস্পতি, ষোড়শ, তস্কর, বনস্পতি, গবাক্ষ — **নিপাতনে সিদ্ধ**।

## Practice MCQ
**1.** "উচ্ছ্বাস" শব্দের সন্ধি বিচ্ছেদ কোনটি?

**2.** "মনোযোগ" এর সন্ধি বিচ্ছেদ কোনটি?
(ক) মনো + যোগ (খ) মন + যোগ (গ) মনঃ + যোগ (ঘ) মনস + যোগ

**3.** "নীরব" শব্দের সঠিক সন্ধি বিচ্ছেদ কোনটি?
(ক) নী + রব (খ) নির + রব (গ) নি + রব (ঘ) নিঃ + রব

**4.** "বৃহস্পতি" কোন ধরনের সন্ধি?

**5.** "পরিচ্ছেদ" শব্দের সন্ধি বিচ্ছেদ কোনটি?
(ক) পরিচ্ + ছেদ (খ) পরি + ছেদ (গ) পরিৎ + ছেদ (ঘ) পরী + ছেদ

**6.** "সংবাদ" শব্দের সন্ধি বিচ্ছেদ কোনটি?
(ক) সং + বাদ (খ) সন্ + বাদ (গ) সম + বাদ (ঘ) সম্ + বাদ

**7.** "আশ্চর্য" শব্দের সন্ধি বিচ্ছেদ কোনটি?
(ক) আশ্ + চর্য (খ) আঃ + চর্য (গ) আস + চর্য (ঘ) আ + চর্য

**8.** "নিষ্পাপ" শব্দের সন্ধি বিচ্ছেদ কোনটি?
(ক) নিঃ + পাপ (খ) নিষ্ + পাপ (গ) নির্ + পাপ (ঘ) নি + পাপ

# Conditional sentences

> **Why it matters:** Almost every BCS, bank and NTRCA paper has one or two "fill in the gap" or "choose the correct form" questions on *if*-clauses, *unless*, inverted conditionals ("Had I known…") and *wish / as if / it is time*.

## The four main types 🔥
| Type | Use | *If*-clause | Main clause | Example |
|---|---|---|---|---|
| **Zero** | General truths, facts | present simple | present simple | If you **heat** ice, it **melts**. |
| **First** | Real / likely future | present simple | **will / can / may + V1** | If it **rains**, we **will stay** at home. |
| **Second** | Unreal present or unlikely future | past simple (**were** for all persons) | **would / could / might + V1** | If I **were** a bird, I **would fly**. |
| **Third** | Unreal past (did not happen) | **had + V3** | **would / could / might have + V3** | If he **had worked** hard, he **would have passed**. |

**Memory hook:** *Present → will; Past → would; Past perfect → would have.*

## Key rules 🔥
1. **No *will* in the *if*-clause** of a first conditional. ✗ If it *will rain*… ✓ If it **rains**…
2. **"Were" for all persons** in the second conditional: *If I were you, I would not go.* ("If I was" is informal and marked wrong in exams.)
3. **Third conditional never takes *would* in the *if*-clause.** ✗ If he *would have come*… ✓ If he **had come**…
4. **Unless = if … not.** Do not use *not* again after *unless*.
   - ✓ **Unless you work hard, you will fail.** ✗ Unless you do not work hard…
5. A comma is used when the *if*-clause comes first: *If you call me, I will come.* / *I will come if you call me.*

## Inverted conditionals (without *if*) 🔥
| With *if* | Inverted form |
|---|---|
| If I had known the truth, I would have helped. | **Had I known** the truth, I would have helped. |
| If I were rich, I would buy a car. | **Were I** rich, I would buy a car. |
| If you should need help, call me. | **Should you need** help, call me. |

Exam trap: "**Had** I been a king, I **would have** built…" (not "would build") when the meaning is past.

## Mixed conditionals
| Pattern | Example |
|---|---|
| Past condition → present result | If I **had taken** the medicine, I **would be** well **now**. |
| Present condition → past result | If I **were** a good swimmer, I **would have saved** the boy yesterday. |

## Other words that introduce a condition
| Word | Example |
|---|---|
| **provided (that) / providing** | You may go **provided** you finish the work. |
| **as long as / so long as** | You can stay **as long as** you keep quiet. |
| **on condition that** | He was released **on condition that** he left the country. |
| **in case** (precaution) | Take an umbrella **in case** it rains. |
| **suppose / supposing** | **Suppose** you lost your job, what would you do? |
| **but for / without + noun** | **But for** your help, I **would have failed**. |
| **otherwise / or else** | Hurry up, **otherwise** you will miss the bus. |
| **even if** | I will go **even if** it rains. |

## Related "unreal" structures 🔥
| Structure | Rule | Example |
|---|---|---|
| **I wish** (present) | wish + past / were | I wish I **were** a king. I wish I **knew** his address. |
| **I wish** (past) | wish + had + V3 | I wish I **had seen** the match. |
| **I wish** (future / annoyance) | wish + would | I wish you **would stop** talking. |
| **as if / as though** | + past / were (unreal) | He talks **as if** he **were** the boss. |
| | + had + V3 (past) | He looked **as if** he **had seen** a ghost. |
| **It is (high / about) time** | + subject + past | **It is high time** we **left**. / It is time you **went** to bed. |
| **would rather** (someone else) | + subject + past | I **would rather** you **stayed** here. |
| **If only** | same as *wish* | **If only** I **had listened** to you! |

## Worked examples
1. If I ____ you, I would accept the offer. → **were** (second conditional).
2. If he had run fast, he ____ the train. → **would have caught** (third).
3. ____ harder, he would have won. → **Had he tried** (inversion of third).
4. Unless you ____, you will be late. → **hurry** (not "do not hurry").
5. If water ____ to 100°C, it boils. → **is heated** (zero conditional, fact).

## Quick revision
- First: **If + present, will + V1**.
- Second: **If + past (were), would + V1**.
- Third: **If + had + V3, would have + V3**.
- **Unless = if not**; never "unless … not".
- **Had I known = If I had known**; **Were I = If I were**; **Should you = If you should**.
- **It is high time + past**: It is high time we started.
- **I wish + were / had + V3**.
- **But for** + noun = if it had not been for.

## Practice MCQ
**1.** If I ____ a bird, I would fly in the sky.
(a) am (b) will be (c) were (d) had been

**2.** If he had worked hard, he ____.
(a) would have passed (b) will pass (c) would pass (d) passes

**3.** ____ you work hard, you will not succeed.
(a) If (b) Unless (c) When (d) Provided

**4.** ____ I known the news, I would have informed you.
(a) If (b) Should (c) Were (d) Had

**5.** It is high time we ____ the work.
(a) finish (b) finished (c) have finished (d) will finish

**6.** If it rains tomorrow, we ____ the match.
(a) will cancel (b) would cancel (c) would have cancelled (d) cancelled

**7.** He talks as if he ____ the owner of the company.
(a) is (b) be (c) has been (d) were

**8.** But for your help, I ____.
(a) will fail (b) would have failed (c) had failed (d) fail

## Answer key
| Q | Ans | Explanation |
|---|---|---|
| 1 | c | Second conditional uses "were" for all persons |
| 2 | a | Third conditional: had + V3, would have + V3 |
| 3 | b | Unless = if not; the main clause is negative |
| 4 | d | Inversion: Had I known = If I had known |
| 5 | b | It is high time + subject + past tense |
| 6 | a | First conditional: if + present, will + V1 |
| 7 | d | As if + were for an unreal situation |
| 8 | b | But for + noun takes would have + V3 |

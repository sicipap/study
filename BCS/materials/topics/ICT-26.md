# Multimedia & file formats

> **Why it matters:** Exams ask the elements of multimedia, lossy vs lossless formats, which extension belongs to which kind of file (.mp3, .avi, .apk, .pdf), RGB vs CMYK, and which software edits images, video or vector graphics.

## Multimedia (মাল্টিমিডিয়া) 🔥
- **Multimedia** means combining **two or more media** — **text, graphics/images, audio, video and animation** — usually with **interactivity**.
- Five elements: **Text, Image (graphics), Audio, Video, Animation**.
- Uses: education (e-learning), entertainment, advertising, presentations, games, virtual tours, **multimedia classrooms** (widely set up in Bangladeshi schools).
- **Hypermedia:** multimedia with **hyperlinks** (like the WWW).

## Images: raster vs vector 🔥
| Raster (bitmap) | Vector |
|---|---|
| Made of **pixels** | Made of **mathematical paths** (lines, curves) |
| **Loses quality (pixelates) when enlarged** | **No quality loss** when resized |
| Photos | Logos, icons, illustrations, maps |
| JPEG, PNG, GIF, BMP, TIFF | **SVG**, AI (Illustrator), EPS, **CDR** (CorelDRAW) |
| Edited in **Photoshop**, GIMP | Edited in **Illustrator**, **CorelDRAW**, Inkscape |

## Compression 🔥
- **Lossy compression:** removes some data permanently; much smaller files. **JPEG, MP3, MP4, AAC**.
- **Lossless compression:** no data lost; original can be restored exactly. **PNG, GIF, ZIP, RAR, FLAC**.
- **Codec** = **Co**der–**Dec**oder: software/hardware that compresses and decompresses audio/video (e.g. H.264).

## File formats (extensions) 🔥🔥
| Category | Extensions and facts |
|---|---|
| **Images** | **.jpg/.jpeg** (photos, lossy); **.png** (lossless, supports **transparency**); 🔥 **.gif** (**supports simple animation**, max **256 colours**); **.bmp** (Microsoft bitmap, uncompressed); **.tiff/.tif** (high quality, printing/scanning); **.svg** (vector, web); **.webp** (Google); **.ico** (icons); **.psd** (Photoshop project) |
| **Audio** | 🔥 **.mp3** (most popular, lossy); **.wav** (uncompressed, Microsoft/IBM); **.aac**; **.wma** (Windows Media Audio); **.flac** (lossless); **.ogg**; **.midi/.mid** (stores musical **instructions**, not recorded sound, so files are tiny) |
| **Video** | **.mp4** (MPEG-4, most common); **.avi** (Audio Video Interleave, **Microsoft**); **.mkv** (Matroska); **.mov** (**Apple QuickTime**); **.wmv** (Windows Media Video); **.flv** (Flash video); **.3gp** (old mobile phones); **.webm** (web) |
| **Documents** | **.txt** (plain text); **.docx/.doc** (Word); **.pdf** (Adobe, Portable Document Format); **.rtf** (Rich Text Format); **.odt** (OpenDocument text); **.xlsx**, **.pptx**, **.csv** |
| **Compressed / archive** | **.zip**, **.rar** (WinRAR), **.7z** (7-Zip), .tar, .gz |
| **Executable / installer** | 🔥 **.exe** (Windows program), .msi, **.bat** (batch file); **.apk** (**Android** app); **.ipa** (iOS app); **.dmg** (macOS disk image) |
| **Web** | **.html/.htm**, .css, .js, .php, .asp |
| **Programming** | .c, .cpp (C++), .java, .class (Java bytecode), .py (Python) |
| **Disk image** | **.iso** |

- **PDF** was created by **Adobe** (1993) and keeps the same layout on every device.

## Audio and video basics
- **Sampling rate:** samples of sound per second. **Audio CD quality = 44.1 kHz, 16-bit**, stereo.
- **Frame rate:** frames per second (**fps**); films are usually **24 fps**; the illusion of motion comes from **persistence of vision**.
- **Resolution:** **HD = 1280×720 (720p)**, **Full HD = 1920×1080 (1080p)**, **4K UHD = 3840×2160**.
- **Aspect ratio:** width : height, e.g. **16:9** (widescreen) or 4:3.
- **Streaming:** playing audio/video while it downloads (YouTube, Netflix, Spotify).
- **Podcast:** audio (or video) shows released in episodes online.

## Colour models 🔥
| Model | Colours | Used for |
|---|---|---|
| 🔥 **RGB** | **Red, Green, Blue** (**additive**: all three together = white) | **Screens**: monitors, TVs, phones, cameras |
| 🔥 **CMYK** | **Cyan, Magenta, Yellow, Key (Black)** (**subtractive**) | **Printing** |

- 24-bit colour ("true colour") can show about **16.7 million** colours (2²⁴).

## Animation
- **2D animation**, **3D animation** (Blender, Maya), **stop-motion**.
- **Tweening (in-betweening):** creating frames between two key frames automatically.
- 🔥 **Morphing:** smoothly **changing one image into another**.
- **Adobe Flash** was widely used for web animation; Adobe **ended Flash support in 2020**.

## Quick revision
- Multimedia elements: **text, image, audio, video, animation**.
- Raster = **pixels**; vector = **paths**, scales without loss (**SVG, AI, CDR**).
- Lossy: **JPEG, MP3, MP4**; lossless: **PNG, GIF, ZIP, FLAC**.
- **GIF** supports animation, 256 colours; **PNG** supports transparency.
- **.avi** = Microsoft; **.mov** = Apple QuickTime; **.apk** = Android app.
- **RGB** for screens; **CMYK** for printing.
- **Morphing** = one image turning into another.
- PDF by **Adobe**; full form **Portable Document Format**.

## Practice MCQ

(a) Text (b) Audio (c) Compiler (d) Animation

(a) GIF (b) JPEG (c) BMP (d) TIFF

**3.** The file extension of an Android application package is:
(a) .exe (b) .ipa (c) .dmg (d) .apk

**4.** Which colour model is used for printing?
(a) RGB (b) CMYK (c) HSV (d) YUV

**5.** Which of the following is a vector graphics format?
(a) JPEG (b) PNG (c) SVG (d) BMP

**6.** MP3 is an example of:
(a) Lossless image compression (b) Lossy audio compression (c) A video format (d) An executable file

**7.** Smoothly transforming one image into another is called:
(a) Rendering (b) Streaming (c) Pixelation (d) Morphing

**8.** The .mov video format is associated with:
(a) Apple QuickTime (b) Microsoft (c) Google (d) Adobe Flash

| Q | Ans | Explanation |

| 2 | a | GIF supports animation with up to 256 colours |
| 3 | d | .apk = Android Package; .ipa = iOS |

| 5 | c | SVG = Scalable Vector Graphics |
| 6 | b | MP3 removes some audio data to shrink files |
| 7 | d | Morphing changes one shape/image into another |
| 8 | a | .mov is Apple's QuickTime format |

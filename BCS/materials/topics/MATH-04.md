# Square/cube roots, surds & indices (সূচক)

> **Why it matters:** Index laws (সূচকের নিয়ম), rationalising surds (করণী) and square roots of decimals are standard 1-mark questions in BCS, bank and primary exams. Most can be solved in seconds with the rules below.

## Key concepts
- **Square root (বর্গমূল):** √x is the number whose square is x. **Cube root (ঘনমূল):** ∛x.
- **Prime-factor method:** pair equal primes for √, make triplets for ∛. √1764 = √(2²·3²·7²) = 2·3·7 = 42.
- A perfect square **never ends in 2, 3, 7 or 8**, and never ends in an odd number of zeros.
- Square root of a decimal: the number of decimal places must be even; the root has half as many. √0.0169 = 0.13 (4 places → 2 places).
- Cube root of a decimal: the number of decimal places must be a multiple of 3. ∛0.000064 = 0.04.
- **Surd (করণী):** an irrational root such as √2, √5, ∛3. **Conjugate (অনুবন্ধী)** of √a + √b is √a − √b.
- To make a number a perfect square, multiply (or divide) by the primes that are left **unpaired**.

## Laws of indices (সূচকের নিয়ম) 🔥
| Law | Example |
|---|---|
| aᵐ × aⁿ = aᵐ⁺ⁿ | 2³ × 2² = 2⁵ = 32 |
| aᵐ ÷ aⁿ = aᵐ⁻ⁿ | 5⁷ ÷ 5⁵ = 25 |
| (aᵐ)ⁿ = aᵐⁿ | (3²)³ = 3⁶ |
| (ab)ⁿ = aⁿbⁿ | (2·5)³ = 1000 |
| 🔥 **a⁰ = 1** (a ≠ 0) | 2026⁰ = 1 |
| a⁻ⁿ = 1/aⁿ | 2⁻³ = 1/8 |
| a^(1/n) = ⁿ√a | 8^(1/3) = 2 |
| a^(m/n) = (ⁿ√a)ᵐ | 81^(3/4) = 3³ = 27 |
| If aˣ = aʸ (a ≠ 0, 1) then x = y | 2ˣ = 32 → x = 5 |

## Surd rules and shortcuts
| Rule | Example |
|---|---|
| √a × √b = √(ab) | √2 × √8 = 4 |
| √(a²b) = a√b | √12 = 2√3 |
| Like surds add | 2√3 + 3√3 = 5√3 |
| 1/(√a + √b) = (√a − √b)/(a − b) | 1/(√3 − √2) = √3 + √2 |
| If aˣ = b, bʸ = c, cᶻ = a | then **xyz = 1** |

## Worked examples
**Example 1.** Find √1764.
Steps: 1764 = 2² × 3² × 7² → √ = 2 × 3 × 7 = 42.
**Answer: 42**

**Example 2.** If 2ˣ⁺³ = 32, find x.
Steps: 32 = 2⁵ → x + 3 = 5 → x = 2.
**Answer: 2**

**Example 3.** Rationalise 1/(√3 − √2).
Steps: Multiply top and bottom by √3 + √2: (√3 + √2)/(3 − 2) = √3 + √2.
**Answer: √3 + √2**

**Example 4.** Find the value of 81^(3/4).
Steps: 81^(1/4) = 3 → 3³ = 27.
**Answer: 27**

**Example 5.** By what least number must 180 be multiplied to make it a perfect square?
Steps: 180 = 2² × 3² × 5. 5 is unpaired → multiply by 5 (900 = 30²).
**Answer: 5**

## Common traps
- √(a + b) ≠ √a + √b. √(9 + 16) = 5, not 7.
- a⁰ = 1, not 0. And 0⁰ is undefined.
- A negative index gives a reciprocal, not a negative number: 2⁻² = 1/4.
- √0.9 ≈ 0.949, not 0.3 (0.3² = 0.09). Count decimal places carefully.

## Quick revision
- a⁰ = 1; a⁻ⁿ = 1/aⁿ; a^(m/n) = (ⁿ√a)ᵐ.
- Same base → equate the powers.
- Perfect squares never end in 2, 3, 7, 8.
- √ of a decimal: half the decimal places; ∛: one-third.
- Conjugate removes the surd from the denominator.
- aˣ = b, bʸ = c, cᶻ = a ⇒ xyz = 1.

## Practice MCQ
**1.** √0.0169 = ?
(a) 0.013 (b) 0.13 (c) 1.3 (d) 0.0013

**2.** ∛0.000064 = ?
(a) 0.4 (b) 0.004 (c) 0.04 (d) 0.008

**3.** The value of 125^(−2/3) is:
(a) 25 (b) −25 (c) 1/5 (d) 1/25

**4.** If 3ˣ⁻¹ = 81, then x = ?
(a) 5 (b) 4 (c) 3 (d) 27

**5.** 1/(√5 + 2) = ?
(a) √5 + 2 (b) √5 − 2 (c) (√5 − 2)/3 (d) 2 − √5

**6.** By what least number must 1575 be multiplied to make it a perfect square?
(a) 3 (b) 5 (c) 15 (d) 7

**7.** Which of the following cannot be a perfect square?
(a) 5328 (b) 4489 (c) 1296 (d) 7056

**8.** 2⁰ + 2⁻¹ + 2⁻² = ?
(a) 3/4 (b) 7/4 (c) 1/4 (d) 0

**9.** If aˣ = b, bʸ = c and cᶻ = a, then xyz = ?
(a) 0 (b) abc (c) 1 (d) −1

**10.** √12 + √27 = ?
(a) √39 (b) 6√3 (c) 13√3 (d) 5√3

# বর্ণের উচ্চারণ স্থান, যুক্তবর্ণ

> **Why it matters:** "'শ' কোন উচ্চারণ স্থানের বর্ণ?", "ওষ্ঠ্য বর্ণ কোনগুলো?", "'ক্ষ' কোন কোন বর্ণের যুক্তরূপ?", "'হ্ম'-এর বিশ্লিষ্ট রূপ" — বর্ণ বিশ্লেষণের প্রশ্ন নিয়মিত আসে।

## উচ্চারণ স্থান অনুযায়ী বর্ণ 🔥🔥
প্রচলিত (সংস্কৃত-ঐতিহ্যভিত্তিক) শ্রেণিবিভাগ, যা পরীক্ষায় সবচেয়ে বেশি ব্যবহৃত:

| উচ্চারণ স্থান | নাম | স্বরবর্ণ | ব্যঞ্জনবর্ণ |
|---|---|---|---|
| জিহ্বামূল/কণ্ঠ | **কণ্ঠ্য** (জিহ্বামূলীয়) | অ, আ | **ক খ গ ঘ ঙ, হ** |
| তালু | **তালব্য** | ই, ঈ | **চ ছ জ ঝ ঞ, য, য়, শ** |
| মূর্ধা | **মূর্ধন্য** (পশ্চাৎ দন্তমূলীয়) | ঋ | **ট ঠ ড ঢ ণ, র, ষ** (এবং ড়, ঢ়) |
| দন্ত | **দন্ত্য** | — | **ত থ দ ধ ন, ল, স** |
| ওষ্ঠ | **ওষ্ঠ্য** | উ, ঊ | **প ফ ব ভ ম** |
| কণ্ঠ + তালু | **কণ্ঠতালব্য** | **এ, ঐ** | — |
| কণ্ঠ + ওষ্ঠ | **কণ্ঠৌষ্ঠ্য** | **ও, ঔ** | — |

- নতুন কিছু পাঠ্যবইয়ে **ন, র, ল, স**-কে **দন্তমূলীয়** বলা হয়েছে; তবে পরীক্ষায় প্রচলিত উত্তর উপরের সারণি অনুযায়ী।
- 🔥 তিনটি শিস ধ্বনির নাম উচ্চারণ স্থান থেকে: **শ = তালব্য শ, ষ = মূর্ধন্য ষ, স = দন্ত্য স**।
- একইভাবে **ণ = মূর্ধন্য ণ**, **ন = দন্ত্য ন**।
- **হ** কণ্ঠনালীয় (কণ্ঠ্য) বর্ণ।

**মনে রাখার কৌশল:** *বর্গের নাম = উচ্চারণ স্থান — "ক-কণ্ঠ, চ-তালু, ট-মূর্ধা, ত-দাঁত, প-ঠোঁট"।*

## যুক্তবর্ণ
দুই বা ততোধিক ব্যঞ্জনবর্ণ স্বরধ্বনি ছাড়া একসঙ্গে লেখা হলে তাকে **যুক্তবর্ণ (সংযুক্ত বর্ণ)** বলে। যুক্তবর্ণের কিছু রূপ আলাদা হয়ে যায়, তাই পরীক্ষায় বিশ্লেষণ জিজ্ঞাসা করা হয়।

### বহুল জিজ্ঞাসিত যুক্তবর্ণ 🔥
| যুক্তবর্ণ | বিশ্লেষণ | উদাহরণ |
|---|---|---|
| **ক্ষ** | **ক + ষ** | পক্ষ, ক্ষমা |
| **জ্ঞ** | **জ + ঞ** | জ্ঞান, বিজ্ঞান |
| **ঞ্জ** | ঞ + জ | গঞ্জ, অঞ্জলি |
| **ঞ্চ** | ঞ + চ | পঞ্চ, অঞ্চল |
| **হ্ম** | **হ + ম** | ব্রাহ্মণ, ব্রহ্ম |
| **হ্ন** | **হ + ন** | চিহ্ন, অপরাহ্ন |
| **হ্ণ** | **হ + ণ** | পূর্বাহ্ণ |
| **ষ্ণ** | **ষ + ণ** | কৃষ্ণ, বিষ্ণু, উষ্ণ |
| **ঙ্ক** | ঙ + ক | অঙ্ক, শঙ্কা |
| **ঙ্গ** | ঙ + গ | অঙ্গ, বঙ্গ |
| **ক্ত** | ক + ত | রক্ত, ভক্ত |
| **ত্ত** | ত + ত | উত্তর, চিত্ত |
| **ত্থ** | ত + থ | উত্থান |
| **ত্ম** | **ত + ম** | আত্মা, মাহাত্ম্য |
| **ন্থ** | ন + থ | গ্রন্থ, পন্থা |
| **ষ্ট** | ষ + ট | কষ্ট, স্পষ্ট |
| **ষ্ঠ** | ষ + ঠ | শ্রেষ্ঠ, কাষ্ঠ |
| **ণ্ড** | ণ + ড | খণ্ড, কাণ্ড |
| **দ্ধ** | দ + ধ | যুদ্ধ, শুদ্ধ |
| **গ্ধ** | গ + ধ | দুগ্ধ, মুগ্ধ |
| **ম্ভ** | ম + ভ | সম্ভব, দম্ভ |
| **হৃ** | হ + ঋ-কার | হৃদয় |
| **ত্র** | ত + র-ফলা | পত্র, মিত্র |

### তিন বর্ণের যুক্তরূপ 🔥
| যুক্তবর্ণ | বিশ্লেষণ | উদাহরণ |
|---|---|---|
| **ক্ষ্ম** | **ক + ষ + ম** | লক্ষ্মী, সূক্ষ্ম |
| **ত্ত্ব** | ত + ত + ব | তত্ত্ব, সত্ত্ব |
| **জ্জ্ব** | জ + জ + ব | উজ্জ্বল |
| **ন্ত্র** | ন + ত + র | মন্ত্র, যন্ত্র |
| **স্ত্র** | স + ত + র | শাস্ত্র, অস্ত্র |
| **ঙ্ক্ষ** | **ঙ + ক + ষ** | আকাঙ্ক্ষা |
| **ন্ত্য** | ন + ত + য | অন্ত্য |

### ভুল হওয়ার মতো জোড়া
- **হ্ন (হ + ন)** আর **হ্ণ (হ + ণ)** আলাদা: **অপরাহ্ন** কিন্তু **পূর্বাহ্ণ**।
- **ক্ষ** আসলে **ক + ষ**; "ক + খ" নয়।
- **জ্ঞ = জ + ঞ**; "গ + জ" নয়।
- **হ্ম = হ + ম** (ব্রাহ্মণ); "ম + হ" নয়।

## Quick revision
- কণ্ঠ্য: **অ আ, ক-বর্গ, হ**।
- তালব্য: **ই ঈ, চ-বর্গ, য য় শ**।
- মূর্ধন্য: **ঋ, ট-বর্গ, র ষ**।
- দন্ত্য: **ত-বর্গ, ল স**।
- ওষ্ঠ্য: **উ ঊ, প-বর্গ**।
- কণ্ঠতালব্য **এ ঐ**; কণ্ঠৌষ্ঠ্য **ও ঔ**।
- **ক্ষ = ক + ষ**, **জ্ঞ = জ + ঞ**, **হ্ম = হ + ম**, **ক্ষ্ম = ক + ষ + ম**।

## Practice MCQ
**1.** "শ" কোন ধরনের বর্ণ?
(ক) মূর্ধন্য (খ) দন্ত্য (গ) তালব্য (ঘ) কণ্ঠ্য

**2.** কোনগুলো ওষ্ঠ্য বর্ণ?
(ক) প ফ ব ভ ম (খ) চ ছ জ ঝ ঞ (গ) ত থ দ ধ ন (ঘ) ট ঠ ড ঢ ণ

**3.** "এ" ও "ঐ" এর উচ্চারণ স্থান কোনটি?
(ক) কণ্ঠৌষ্ঠ্য (খ) দন্ত্য (গ) মূর্ধন্য (ঘ) কণ্ঠতালব্য

**4.** "ক্ষ" কোন কোন বর্ণের যুক্তরূপ?
(ক) ক + খ (খ) ক + ষ (গ) খ + ষ (ঘ) ক + স

**5.** "জ্ঞ" এর বিশ্লিষ্ট রূপ কোনটি?
(ক) গ + ঞ (খ) জ + ন (গ) জ + ঞ (ঘ) গ + য

**6.** "ব্রাহ্মণ" শব্দে "হ্ম" কোন বর্ণগুলোর যুক্তরূপ?
(ক) হ + ম (খ) ম + হ (গ) হ + ন (ঘ) হ + ব

**7.** "লক্ষ্মী" শব্দের যুক্তবর্ণটি কোন বর্ণগুলোর সমষ্টি?
(ক) ক + খ + ম (খ) ক + স + ম (গ) খ + ষ + ম (ঘ) ক + ষ + ম

**8.** কোন বর্ণটি মূর্ধন্য?
(ক) ল (খ) ষ (গ) স (ঘ) ন

# সমার্থক শব্দ

> **Why it matters:** "কোনটি 'চাঁদ'-এর সমার্থক নয়?", "'পদ্ম'-এর প্রতিশব্দ কোনটি?" — এ ধরনের প্রশ্ন প্রায় সব নিয়োগ পরীক্ষায় থাকে। অপশনে সাধারণত একটি কাছাকাছি কিন্তু ভুল শব্দ রাখা হয় (যেমন "অম্বু" জল, "অম্বর" আকাশ)।

## সমার্থক শব্দ কী
ভিন্ন ভিন্ন শব্দ কিন্তু **একই অর্থ** প্রকাশ করে — এদের **সমার্থক শব্দ** বা **প্রতিশব্দ** বলে। যেমন: সূর্য = রবি = তপন।

## বিভ্রান্তিকর জোড়া (সাবধান) 🔥
| শব্দ | অর্থ | সঙ্গে গুলিয়ে যায় |
|---|---|---|
| **অম্বর** | আকাশ (বস্ত্রও) | **অম্বু** = জল, **অম্বুদ** = মেঘ, **অম্বুধি** = সমুদ্র |
| **নীর** | জল | **নীরদ** = মেঘ (যে জল দেয়), **নীরধি** = সমুদ্র |
| **বারি** | জল | **বারিদ** = মেঘ, **বারিধি** = সমুদ্র |
| **জলধর** | মেঘ | **জলধি** = সমুদ্র |
| **ভূধর** | পর্বত | **ভূপতি** = রাজা |
| **দ্বিজ** | পাখি (ব্রাহ্মণ, দাঁতও) | **দ্বিপ** = হাতি |
| **শশী** | চাঁদ | **শশক** = খরগোশ |

- কৌশল: **"-দ" (দেয়)** যোগে মেঘ (বারিদ, নীরদ, অম্বুদ, তোয়দ, পয়োদ); **"-ধি" (ধারণ করে)** যোগে সমুদ্র (জলধি, বারিধি, অম্বুধি, পয়োধি)।

## Quick revision
- চাঁদ: **শশী, সুধাংশু, হিমাংশু, ইন্দু, বিধু, শশাঙ্ক**; সূর্য: **রবি, তপন, ভানু, দিবাকর, মার্তণ্ড, অর্ক**।
- আকাশ: **গগন, অম্বর, ব্যোম, নভ**; জল: **বারি, সলিল, অম্বু, নীর**।
- পৃথিবী: **ধরা, বসুধা, মেদিনী, অবনী, ক্ষিতি**।
- সমুদ্র: **জলধি, অর্ণব, রত্নাকর, সিন্ধু**; মেঘ: **জলধর, নীরদ, জীমূত**।
- পদ্ম: **কমল, পঙ্কজ, নলিনী, সরোজ, রাজীব, অরবিন্দ**।
- অগ্নি: **অনল, পাবক, বহ্নি, হুতাশন**; বাতাস: **পবন, সমীরণ, অনিল**।
- **-দ = মেঘ, -ধি = সমুদ্র**।

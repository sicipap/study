# Acids, bases, salts, pH

> **Why it matters:** Exams ask "which acid is in lemon/vinegar/ant sting?", pH of blood and common liquids, indicator colours, strong acids with common names, aqua regia, and neutralisation in daily life.

## Acids, bases and alkalis 🔥
| Property | Acid (এসিড) | Base (ক্ষারক) |
|---|---|---|
| Taste / feel | **Sour (টক)** | **Bitter**, soapy/slippery |
| Ion in water (Arrhenius) | Gives **H⁺ (H₃O⁺)** | Gives **OH⁻** |
| Litmus | **Blue → red** | **Red → blue** |
| Phenolphthalein | Colourless | **Pink** |
| Methyl orange | **Red** | **Yellow** |
| pH | **Below 7** | **Above 7** |

- An **alkali (ক্ষার)** is a **water-soluble base** (NaOH, KOH). **All alkalis are bases, but not all bases are alkalis** (e.g. Cu(OH)₂ is insoluble).
- **Litmus** is obtained from **lichen**. Turmeric turns **reddish-brown** with a base.
- Other definitions: **Brønsted–Lowry** (acid = proton donor, base = proton acceptor); **Lewis** (acid = electron-pair acceptor).

## Natural acids 🔥🔥
| Source | Acid |
|---|---|
| **Lemon, orange** (citrus) | **Citric acid** |
| **Vinegar (সিরকা)** | **Acetic acid** (≈ 5–8%) |
| **Sour milk, curd (দই)**; tired muscles | **Lactic acid** |
| **Tamarind (তেঁতুল)**, grapes | **Tartaric acid** |
| **Tomato**, spinach | **Oxalic acid** (tomato also has citric/malic) |
| **Apple** | **Malic acid** |
| **Ant sting, nettle sting (bee sting also often cited)** | **Formic acid** |
| **Tea** | **Tannic acid** |
| **Amla (আমলকী)**, citrus | **Ascorbic acid (vitamin C)** |
| **Gastric juice (stomach)** | **Hydrochloric acid (HCl)** |
| Urine | Uric acid |
| Rancid butter | Butyric acid |
| Proteins | Amino acids; fats → fatty acids |

## Strong acids and bases with common names 🔥
| Chemical | Formula | Common name / fact |
|---|---|---|
| Hydrochloric acid | HCl | **Muriatic acid**; in stomach |
| **Sulphuric acid** | **H₂SO₄** | **Oil of vitriol**, **"King of chemicals"**; made by **contact process**; car battery |
| Nitric acid | HNO₃ | Aqua fortis; fertilizer, explosives |
| **Aqua regia (অম্লরাজ)** | **3 HCl : 1 HNO₃** (by volume) | **Dissolves gold and platinum** |
| Hydrofluoric acid | HF | **Etches glass** (stored in plastic, not glass) |
| Carbonic acid | H₂CO₃ | In **soft drinks** (CO₂ dissolved) |
| Phenol | C₆H₅OH | **Carbolic acid**, antiseptic |
| Sodium hydroxide | NaOH | **Caustic soda** — soap making |
| Potassium hydroxide | KOH | **Caustic potash** — soft soap |
| Calcium hydroxide | Ca(OH)₂ | **Slaked lime (কলিচুন)**; its clear solution = **lime water** (turns milky with CO₂) |
| Magnesium hydroxide | Mg(OH)₂ | **Milk of magnesia** — **antacid**, laxative |
| Ammonium hydroxide | NH₄OH | Weak base; ammonia solution |

- **Acids + metals → salt + hydrogen gas**; acids + carbonates → CO₂.
- When diluting, **add acid to water, never water to acid** (the heat can make it splash).

## The pH scale 🔥🔥
- Introduced by **S. P. L. Sørensen (1909)**. **pH = −log[H⁺]**; scale usually **0 to 14**.
- **pH 7 = neutral** (pure water at 25 °C); **< 7 acidic**; **> 7 basic**. Each step = **10 times** change in H⁺ concentration.

| Substance | Approx. pH |
|---|---|
| **Gastric juice** | **1.5 – 3.5 (≈ 2)** |
| **Lemon juice** | **≈ 2.2 – 2.4** |
| Vinegar | ≈ 2.5 – 3 |
| Tomato juice | ≈ 4 – 4.5 |
| Black coffee | ≈ 5 |
| **Normal rain water** | **≈ 5.6** (CO₂ dissolved) |
| **Acid rain** | **Below 5.6** |
| **Milk** | **≈ 6.5 – 6.8** |
| Saliva | ≈ 6.5 – 7.4 |
| **Pure water** | **7** |
| **Human blood** | **7.35 – 7.45 (≈ 7.4), slightly alkaline** |
| Sea water | ≈ 8 |
| Baking soda solution | ≈ 8.3 |
| Milk of magnesia | ≈ 10.5 |
| Household ammonia | ≈ 11 – 12 |
| Lime water | ≈ 12.4 |
| Sodium hydroxide | ≈ 13 – 14 |

- Tooth enamel starts to decay when mouth pH falls **below about 5.5**; toothpaste is **basic**.
- Best soil pH for most crops ≈ **6 – 7.5**.

## Neutralisation and salts 🔥
- **Acid + base → salt + water** (neutralisation, প্রশমন). E.g. **HCl + NaOH → NaCl + H₂O**.
- **Salt (লবণ)**: compound of the positive ion of a base and the negative ion of an acid. Types: normal (NaCl), **acid salt (NaHSO₄, NaHCO₃)**, basic salt.

| Daily-life use | How |
|---|---|
| **Acidity / indigestion** | **Antacid** — milk of magnesia, **baking soda**, Al(OH)₃ |
| **Ant or bee sting** (acidic) | Rub **baking soda** or a mild base |
| Wasp sting (alkaline) | Vinegar |
| **Acidic soil** | Add **lime (CaO / Ca(OH)₂) or chalk** |
| Alkaline soil | Add **gypsum**, organic matter |
| Factory acid waste | Neutralised with slaked lime |

- **Acid rain** comes from **SO₂ and NOₓ**; it damages **marble (CaCO₃)** buildings (e.g. the Taj Mahal's "marble cancer"), soil and fish.

## Quick revision
- Acid: sour, **blue litmus → red**, pH < 7; base: bitter, red → blue, pH > 7.
- Lemon **citric**, vinegar **acetic**, curd **lactic**, tamarind **tartaric**, ant **formic**, tomato **oxalic**, tea **tannic**, stomach **HCl**.
- **Blood pH ≈ 7.4** (slightly alkaline); pure water **7**; gastric juice ≈ 2.
- Normal rain ≈ **5.6**; acid rain below that (SO₂, NOₓ).
- **Aqua regia = 3 HCl : 1 HNO₃** — dissolves gold.
- **H₂SO₄ = king of chemicals**; NaOH = caustic soda; Mg(OH)₂ = milk of magnesia.
- Phenolphthalein turns **pink in base**; methyl orange red in acid.
- pH scale: **Sørensen (1909)**.

(a) colourless (b) green (c) blue (d) pink

**7.** Acidic soil is treated by adding —
(a) gypsum (b) urea (c) lime (d) ammonium sulphate

**8.** Which acid is present in vinegar?
(a) Citric acid (b) Hydrochloric acid (c) Tannic acid (d) Acetic acid

## Answer key

| 2 | a | Blood pH is 7.35–7.45, slightly alkaline |
| 3 | d | 3 parts HCl : 1 part HNO₃ dissolves gold |

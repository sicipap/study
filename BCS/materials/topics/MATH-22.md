# Inequalities

> **Why it matters:** Inequalities (অসমতা) appear in BCS, bank and secondary-level based exams as: solve a linear inequality, find the solution set in natural numbers, the sign rule when multiplying by a negative number, and simple absolute-value and quadratic inequalities.

## Key concepts
- Symbols: **>** greater than, **<** less than, **≥** greater than or equal to, **≤** less than or equal to.
- **Solution set (সমাধান সেট):** all values that satisfy the inequality. It is often an interval, e.g. x > 3.
- Rules:
  1. Adding or subtracting the same number on both sides **keeps** the sign.
  2. Multiplying or dividing by a **positive** number **keeps** the sign.
  3. 🔥 Multiplying or dividing by a **negative** number **reverses** the sign: −2x > 6 → x < −3.
  4. Taking reciprocals of two positive numbers reverses the sign: if a > b > 0 then 1/a < 1/b.
- On a number line, a hollow dot means the point is **not included** (<, >) and a solid dot means **included** (≤, ≥).

## Absolute value and quadratic inequalities
- The absolute value of x (written with vertical bars around x) is its distance from 0.
- abs(x) < a means **−a < x < a** (between).
- abs(x) > a means **x < −a or x > a** (outside).
- abs(x − h) < k means **h − k < x < h + k**.
- For (x − p)(x − q) with p < q:
  - (x − p)(x − q) **< 0** → **p < x < q** (between the roots).
  - (x − p)(x − q) **> 0** → **x < p or x > q** (outside the roots).

## Formula and shortcut table 🔥
| Situation | Result |
|---|---|
| ax + b > c, a > 0 | x > (c − b)/a |
| ax + b > c, a < 0 | x < (c − b)/a (sign flips) |
| a > b and c > 0 | ac > bc |
| 🔥 a > b and c < 0 | **ac < bc** |
| Quadratic < 0 | between the roots |
| Quadratic > 0 | outside the roots |
| AM ≥ GM for positive a, b | (a + b)/2 ≥ √(ab) |
| x > 0 | x + 1/x ≥ 2 (minimum 2 at x = 1) |
| Triangle with sides a, b, c | each side < sum of the other two |

## Worked examples
**Example 1.** Solve 3x − 5 < 7.
Steps: 3x < 12 → x < 4.
**Answer: x < 4**

**Example 2.** Solve −2x + 3 ≥ 9.
Steps: −2x ≥ 6. Divide by −2 and reverse: x ≤ −3.
**Answer: x ≤ −3**

**Example 3.** Solve abs(x − 2) < 3.
Steps: −3 < x − 2 < 3 → −1 < x < 5.
**Answer: −1 < x < 5**

**Example 4.** Solve x² − 5x + 6 < 0.
Steps: (x − 2)(x − 3) < 0 → between the roots.
**Answer: 2 < x < 3**

**Example 5.** How many integers satisfy 2 < 3x − 1 ≤ 11?
Steps: Add 1: 3 < 3x ≤ 12 → 1 < x ≤ 4 → x = 2, 3, 4.
**Answer: 3**

## Common traps
- Forgetting to reverse the sign after dividing by a negative number.
- Mixing up "between" (< 0) and "outside" (> 0) for quadratic inequalities.
- Counting endpoints wrongly: x < 3 excludes 3; x ≤ 3 includes it.
- Natural numbers start from 1, so 0 is not in the solution set in ℕ.

## Quick revision
- Multiply/divide by a negative ⇒ reverse the sign.
- a > b, c < 0 ⇒ ac < bc.
- abs(x) < a ⇒ −a < x < a; abs(x) > a ⇒ outside.
- (x − p)(x − q) < 0 ⇒ p < x < q.
- x + 1/x ≥ 2 for x > 0.

## Practice MCQ
**1.** The solution of 5x + 3 > 18 is:
(a) x > 3 (b) x < 3 (c) x > 21/5 (d) x > 15

**2.** The solution of −3x ≥ 12 is:
(a) x ≥ −4 (b) x ≤ 4 (c) x ≤ −4 (d) x ≥ 4

**3.** If a > b and c < 0, then:
(a) ac > bc (b) ac < bc (c) ac = bc (d) a/c > b/c

**4.** The solution of |x − 3| ≤ 2 is:
(a) 1 < x < 5 (b) x ≤ 5 (c) −1 ≤ x ≤ 5 (d) 1 ≤ x ≤ 5

**5.** The solution of x² − 9 < 0 is:
(a) x < 3 (b) −3 < x < 3 (c) x > 3 or x < −3 (d) x > −3

**6.** How many integers satisfy −3 ≤ 2x + 1 < 7?
(a) 4 (b) 6 (c) 5 (d) 3

**7.** The solution of x² − x − 6 > 0 is:
(a) −2 < x < 3 (b) x > 3 only (c) −3 < x < 2 (d) x < −2 or x > 3

**8.** The solution set of 2x − 1 < 5 in natural numbers is:
(a) {1, 2} (b) {1, 2, 3} (c) {0, 1, 2} (d) {2, 3}

**9.** If a and b are positive and ab = 16, the least value of a + b is:
(a) 16 (b) 4 (c) 10 (d) 8

**10.** For x > 0, the minimum value of x + 1/x is:
(a) 0 (b) 1 (c) 2 (d) 4

# বচন, লিঙ্গ, পুরুষ

> **Why it matters:** বহুবচনের সঠিক চিহ্ন, দ্বিবচন-বাহুল্য ("সকল ছাত্রগণ"), লিঙ্গান্তর (বিদ্বান–বিদুষী, সম্রাট–সম্রাজ্ঞী) এবং পুরুষ চেনা — এগুলো থেকে প্রতি বছর সরাসরি প্রশ্ন আসে।

## বচন
- যে শব্দ দিয়ে বিশেষ্য বা সর্বনামের **সংখ্যা** বোঝায়, তাকে **বচন** বলে।
- বাংলায় বচন **দুই প্রকার: একবচন ও বহুবচন**। (সংস্কৃতে দ্বিবচনও আছে, বাংলায় নেই।)
- বচন শুধু **বিশেষ্য ও সর্বনামের** হয়।

### বহুবচন গঠনের নিয়ম 🔥
| চিহ্ন / শব্দ | কোথায় বসে | উদাহরণ |
|---|---|---|
| **রা, এরা** | শুধু **উন্নত প্রাণিবাচক** (মানুষ) | ছাত্ররা, শিক্ষকেরা |
| **গুলো, গুলি** | প্রাণী ও অপ্রাণী উভয়ে | বইগুলো, গরুগুলো |
| **গণ** | প্রাণিবাচক (সাধারণত মানুষ) | ছাত্রগণ, দেবগণ, জনগণ |
| **বৃন্দ** | প্রাণিবাচক (সম্মানিত) | সুধীবৃন্দ, শিক্ষকবৃন্দ, ভক্তবৃন্দ |
| **মণ্ডলী** | প্রাণিবাচক | শিক্ষকমণ্ডলী, সম্পাদকমণ্ডলী |
| **বর্গ** | প্রাণিবাচক | পণ্ডিতবর্গ, মন্ত্রিবর্গ |
| **কুল** | প্রাণী ও অপ্রাণী | পক্ষিকুল, মাতৃকুল, বৃক্ষকুল |
| **সকল, সব, সমূহ** | প্রাণী ও অপ্রাণী | বৃক্ষসমূহ, সকল মানুষ |
| **আবলি** | অপ্রাণিবাচক | **গ্রন্থাবলি, পদাবলি, রচনাবলি** |
| **গুচ্ছ** | অপ্রাণিবাচক | কবিতাগুচ্ছ, চাবিগুচ্ছ |
| **দাম** | অপ্রাণিবাচক | কুসুমদাম |
| **নিকর** | অপ্রাণিবাচক | কমলনিকর |
| **পুঞ্জ** | অপ্রাণিবাচক | মেঘপুঞ্জ, কুসুমপুঞ্জ |
| **মালা** | অপ্রাণিবাচক | **পর্বতমালা, মেঘমালা** |
| **রাজি** | অপ্রাণিবাচক | **তারকারাজি, বৃক্ষরাজি** |
| **রাশি** | অপ্রাণিবাচক | **বালিরাশি, জলরাশি** |

- 🔥 **এক শব্দে দুবার বহুবচন চিহ্ন বসে না** (বাহুল্য দোষ): "সকল ছাত্রগণ" ভুল → **"সকল ছাত্র" বা "ছাত্রগণ"**; "সব লোকেরা" ভুল → "সব লোক"।
- অপ্রাণিবাচক শব্দে **রা** বসে না: "বইরা" ভুল।
- বিশেষণ বা সংখ্যা আগে থাকলে বহুবচন চিহ্ন লাগে না: "অনেক বই", "দশজন ছাত্র"।

## লিঙ্গ
যে লক্ষণ দিয়ে পুরুষ, স্ত্রী বা অন্য কিছু বোঝায়, তাই **লিঙ্গ**। বাংলায় লিঙ্গ **চার প্রকার**:

| লিঙ্গ | উদাহরণ |
|---|---|
| **পুংলিঙ্গ** | বাবা, ছেলে, রাজা |
| **স্ত্রীলিঙ্গ** | মা, মেয়ে, রানি |
| **উভয় লিঙ্গ** (নারী-পুরুষ দুই-ই) | **শিশু, সন্তান, মানুষ, জন** |
| **ক্লীব লিঙ্গ** (অচেতন বস্তু) | বই, কলম, টেবিল, খাতা |

### লিঙ্গান্তরের নিয়ম
| প্রত্যয় | উদাহরণ |
|---|---|
| **আ** | অজ–অজা, কোকিল–কোকিলা, শিষ্য–শিষ্যা, প্রিয়–প্রিয়া, বৃদ্ধ–বৃদ্ধা |
| **ঈ** | নর–নারী, দেব–দেবী, কুমার–কুমারী, তরুণ–তরুণী, সিংহ–সিংহী, মানব–মানবী |
| **ইকা** | বালক–বালিকা, গায়ক–গায়িকা, নায়ক–নায়িকা, সেবক–সেবিকা |
| **আনী** | ইন্দ্র–ইন্দ্রাণী, ভব–ভবানী, রুদ্র–রুদ্রাণী, মাতুল–মাতুলানী |
| **নী / নি** | বাঘ–বাঘিনী, মালী–মালিনী, কামার–কামারনি, ধোপা–ধোপানি |
| **বান/মান → বতী/মতী** | গুণবান–গুণবতী, বুদ্ধিমান–বুদ্ধিমতী, শ্রীমান–শ্রীমতী |
| **তা → ত্রী** | কর্তা–কর্ত্রী, দাতা–দাত্রী, নেতা–নেত্রী, অভিনেতা–অভিনেত্রী |

### ভিন্ন শব্দে ও বিশেষ লিঙ্গান্তর 🔥
| পুংলিঙ্গ | স্ত্রীলিঙ্গ | পুংলিঙ্গ | স্ত্রীলিঙ্গ |
|---|---|---|---|
| **বিদ্বান** | **বিদুষী** | **সম্রাট** | **সম্রাজ্ঞী** |
| **মহান** | **মহতী** | **যুবক** | **যুবতী** |
| পিতা | মাতা | ভ্রাতা | ভগিনী |
| পুত্র | কন্যা | বর | কনে |
| শ্বশুর | শাশুড়ি | বাদশাহ | বেগম |
| সভাপতি | সভানেত্রী | শিক্ষক | শিক্ষয়িত্রী / শিক্ষিকা |
| সখা | সখী | দেবর / ভাশুর | জা |

- **আচার্য** → **আচার্যানী** (আচার্যের স্ত্রী), কিন্তু নিজে শিক্ষক হলে **আচার্যা**। একইভাবে উপাধ্যায় → উপাধ্যায়ানী (স্ত্রী) / উপাধ্যায়া (নিজে শিক্ষক)।
- **নিত্য স্ত্রীবাচক** (পুরুষবাচক রূপ নেই): **সতীন, সৎমা, সধবা, বিধবা, এয়ো, দাই, অসূর্যম্পশ্যা**।
- **নিত্য পুরুষবাচক**: **কৃতদার, অকৃতদার, বিপত্নীক, কবিরাজ**।
- কিছু শব্দের আগে "মহিলা/নারী" যোগ করে স্ত্রীবাচক করা হয়: **মহিলা কবি, মহিলা ডাক্তার, মহিলা সদস্য**।

## পুরুষ
বাক্যে বক্তা, শ্রোতা ও অন্য কাউকে বোঝাতে বিশেষ্য ও সর্বনামের তিনটি রূপ — **পুরুষ তিন প্রকার**:

| পুরুষ | কাকে বোঝায় | সর্বনাম | ক্রিয়ারূপ |
|---|---|---|---|
| **উত্তম পুরুষ** | বক্তা নিজে | আমি, আমরা, মোরা | আমি **করি** |
| **মধ্যম পুরুষ** | শ্রোতা | তুমি, তোমরা, **আপনি**, **তুই** | তুমি **কর**, আপনি **করেন**, তুই **করিস** |
| **নাম পুরুষ** (প্রথম পুরুষ) | অন্য কেউ / কিছু | সে, তারা, তিনি, ইনি, উনি, **সব বিশেষ্য** | সে **করে**, তিনি **করেন** |

- 🔥 **"আপনি"** শ্রোতাকে সম্মান করে বোঝালে **মধ্যম পুরুষ (সম্মানসূচক)**; **"তুই"** মধ্যম পুরুষ (তুচ্ছার্থক)।
- সব **বিশেষ্য পদ নাম পুরুষ**: "রহিম বই পড়ে"।
- একাধিক পুরুষ একসঙ্গে কর্তা হলে ক্রিয়া হয় অগ্রাধিকার অনুসারে **উত্তম > মধ্যম > নাম**: "তুমি আর আমি যাব" (উত্তম পুরুষের রূপ); "তুমি আর সে যাও" (মধ্যম পুরুষের রূপ)।

## Quick revision
- বাংলায় বচন **২টি**, লিঙ্গ **৪টি**, পুরুষ **৩টি**।
- **রা/এরা** শুধু মানুষবাচক শব্দে; **আবলি, রাজি, রাশি, মালা, পুঞ্জ, গুচ্ছ** অপ্রাণিবাচক শব্দে।
- "সকল ছাত্রগণ" ভুল — দুবার বহুবচন।
- **বিদ্বান–বিদুষী, মহান–মহতী, সম্রাট–সম্রাজ্ঞী, যুবক–যুবতী**।
- **শিশু, সন্তান** উভয় লিঙ্গ; **বই, কলম** ক্লীব লিঙ্গ।
- **সতীন, সধবা, বিধবা** নিত্য স্ত্রীবাচক; **কৃতদার, বিপত্নীক** নিত্য পুরুষবাচক।
- **আপনি** মধ্যম পুরুষ; সব বিশেষ্য **নাম পুরুষ**।

## Practice MCQ
**1.** কোনটি শুদ্ধ বহুবচন?
(ক) সকল ছাত্রগণ (খ) সব লোকেরা (গ) তারকারাজি (ঘ) বইরা

**2.** "বিদ্বান" শব্দের স্ত্রীলিঙ্গ কোনটি?
(ক) বিদ্বানী (খ) বিদুষী (গ) বিদ্যাবতী (ঘ) বিদ্বানা

**3.** কোনটি উভয় লিঙ্গবাচক শব্দ?
(ক) শিশু (খ) কলম (গ) রানি (ঘ) বাবা

**4.** কোনটি নিত্য স্ত্রীবাচক শব্দ?
(ক) কবিরাজ (খ) বিপত্নীক (গ) কৃতদার (ঘ) সতীন

**5.** "আপনি" কোন পুরুষ?
(ক) উত্তম পুরুষ (খ) নাম পুরুষ (গ) মধ্যম পুরুষ (ঘ) প্রথম পুরুষ

**6.** "রাশি" বহুবচন চিহ্নটি কোন শব্দের সঙ্গে সঠিকভাবে বসেছে?
(ক) ছাত্ররাশি (খ) শিক্ষকরাশি (গ) পাখিরাশি (ঘ) বালিরাশি

**7.** "মহান" শব্দের স্ত্রীলিঙ্গ কোনটি?
(ক) মহতী (খ) মহীয়সী (গ) মহানা (ঘ) মহিলা

**8.** "রহিম বই পড়ে" — বাক্যে "রহিম" কোন পুরুষ?
(ক) উত্তম পুরুষ (খ) মধ্যম পুরুষ (গ) তুচ্ছার্থক মধ্যম পুরুষ (ঘ) নাম পুরুষ

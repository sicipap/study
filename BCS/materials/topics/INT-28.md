# Global indices & Bangladesh's rank

> **Why it matters:** Two kinds of questions come up: (1) **who publishes** an index (stable — learn these well), and (2) **Bangladesh's latest rank** (changes every year — note the figures below with their year, then check the newest reports).

## Who publishes which index 🔥
| Index / report | Publisher | Note |
|---|---|---|
| 🔥 **Human Development Index (HDI)** | **UNDP** (Human Development Report) | Since **1990**; created by **Mahbub ul Haq** (Pakistan) with **Amartya Sen**; measures **health (life expectancy), education, income (GNI per capita)** |
| Gender Inequality Index; Multidimensional Poverty Index | **UNDP** (MPI with **OPHI**, Oxford) | |
| 🔥 **Corruption Perceptions Index (CPI)** | **Transparency International** (HQ **Berlin**) | Since **1995**; score **0 (highly corrupt) to 100 (very clean)** |
| 🔥 **World Happiness Report** | **UN Sustainable Development Solutions Network (SDSN)** with Gallup and Oxford's Wellbeing Research Centre | Since **2012**; released around **20 March** |
| 🔥 **Global Gender Gap Index** | **World Economic Forum (WEF)**, Geneva | Since **2006** |
| 🔥 **World Press Freedom Index** | **Reporters Without Borders (RSF)**, Paris | Since **2002**; released around **3 May** |
| 🔥 **Global Hunger Index (GHI)** | **Concern Worldwide** (Ireland) & **Welthungerhilfe** (Germany) | |
| **Global Peace Index**; **Global Terrorism Index** | **Institute for Economics and Peace (IEP)**, Sydney | |
| **Global Innovation Index** | **WIPO** | |
| **Democracy Index** | **Economist Intelligence Unit (EIU)** | Classes: full democracy, flawed democracy, hybrid regime, authoritarian |
| **Global Liveability Index** | **EIU** | Dhaka is usually near the bottom |
| **Index of Economic Freedom** | **Heritage Foundation** (USA) | |
| **Ease of Doing Business** | **World Bank** | **Discontinued in 2021**; replaced by **B-READY (Business Ready)** from 2024 |
| **Global Competitiveness Index** | **WEF** | |
| **World Competitiveness Ranking** | **IMD** (Lausanne) | |
| **Henley Passport Index** | **Henley & Partners** (using IATA data) | |
| 🔥 **Climate Risk Index** | **Germanwatch** (Germany) | Bangladesh has long ranked among the **most affected** countries |
| **Environmental Performance Index** | **Yale & Columbia** universities | |
| **World Air Quality Report** | **IQAir** (Switzerland) | Bangladesh was the **most polluted country** in several recent reports (e.g. **2023**) |
| **SDG Index** (Sustainable Development Report) | **SDSN** | |
| **Rule of Law Index** | **World Justice Project** | |
| **Global Soft Power Index** | **Brand Finance** | |

## How to remember publishers
- **UN family:** HDI → **UNDP**; Happiness → **SDSN**; Innovation → **WIPO**.
- **Geneva forum:** Gender Gap, Competitiveness, Travel & Tourism → **WEF**.
- **NGOs:** CPI → **Transparency International (Berlin)**; Press Freedom → **RSF (Paris)**; Hunger → **Concern Worldwide & Welthungerhilfe**; Climate Risk → **Germanwatch**.
- **Think-tanks:** Peace & Terrorism → **IEP (Sydney)**; Democracy & Liveability → **EIU**; Economic Freedom → **Heritage Foundation**.

## Quick revision
- HDI: **UNDP**, since **1990**, idea of **Mahbub ul Haq**; three dimensions: health, education, income.
- CPI: **Transparency International**; 0–100 scale; Bangladesh **151st (CPI 2024)**.
- World Happiness Report: **SDSN**; Finland top; Bangladesh **134th (2025)**.
- Global Gender Gap: **WEF**; Bangladesh **24th (2025)**.
- Press Freedom: **RSF**; Bangladesh **149th (2025)**.
- Global Hunger Index: **Concern Worldwide & Welthungerhilfe**.
- Global Peace Index: **IEP**; Democracy Index: **EIU**; Climate Risk Index: **Germanwatch**.

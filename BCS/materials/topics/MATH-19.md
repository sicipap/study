# Factorization

> **Why it matters:** Factorization (উৎপাদকে বিশ্লেষণ) questions — "which is a factor of…", "find the remainder", "if (x − 1) is a factor, find k" — are asked regularly in BCS, primary and bank exams. The remainder and factor theorems make them very fast.

## Key concepts
- **Factorizing** means writing an expression as a product of simpler expressions.
- Methods, in the order you should try them:
  1. **Take out the common factor:** 6x² + 9x = 3x(2x + 3).
  2. **Use a formula:** a² − b², a³ ± b³, perfect squares.
  3. **Grouping (দলবদ্ধ করা):** ax + ay + bx + by = (a + b)(x + y).
  4. **Middle-term split (মধ্যপদ বিভাজন):** for ax² + bx + c, find two numbers whose **product = ac** and **sum = b**.
  5. **Factor theorem** for cubics: try x = ±1, ±2, ±3 … (divisors of the constant term).
- 🔥 **Remainder theorem (ভাগশেষ উপপাদ্য):** when f(x) is divided by (x − a), the remainder is **f(a)**. When divided by (ax − b), the remainder is f(b/a).
- 🔥 **Factor theorem (উৎপাদক উপপাদ্য):** (x − a) is a factor of f(x) if and only if **f(a) = 0**.

## Formula and shortcut table
| Pattern | Factors |
|---|---|
| a² − b² | (a + b)(a − b) |
| a² + 2ab + b² | (a + b)² |
| a³ + b³ | (a + b)(a² − ab + b²) |
| a³ − b³ | (a − b)(a² + ab + b²) |
| x² + (p + q)x + pq | (x + p)(x + q) |
| x⁴ + x² + 1 | (x² + x + 1)(x² − x + 1) |
| x⁴ + 4 | (x² + 2x + 2)(x² − 2x + 2) |
| Sum of coefficients = 0 | (x − 1) is a factor |
| Sum of coefficients of even powers = sum of odd powers | (x + 1) is a factor |

## Worked examples
**Example 1.** Factorize x² − 7x + 12.
Steps: Numbers with product 12 and sum −7: −3 and −4.
**Answer: (x − 3)(x − 4)**

**Example 2.** Factorize 2x² − 5x − 3.
Steps: ac = −6; numbers −6 and +1 (sum −5). 2x² − 6x + x − 3 = 2x(x − 3) + 1(x − 3).
**Answer: (2x + 1)(x − 3)**

**Example 3.** Factorize x⁴ + x² + 1.
Steps: (x⁴ + 2x² + 1) − x² = (x² + 1)² − x² = (x² + 1 + x)(x² + 1 − x).
**Answer: (x² + x + 1)(x² − x + 1)**

**Example 4.** Find the remainder when x³ − 3x² + 4x − 5 is divided by (x − 2).
Steps: f(2) = 8 − 12 + 8 − 5 = −1.
**Answer: −1**

**Example 5.** If (x − 1) is a factor of x³ + kx² − 4x + 1, find k.
Steps: f(1) = 1 + k − 4 + 1 = 0 → k = 2.
**Answer: k = 2**

## Common traps
- For division by (x + 2), put **x = −2**, not +2.
- a² + b² cannot be factorized over real numbers (unlike a² − b²).
- In middle-term split, match the **signs**: product positive → same signs; product negative → opposite signs.
- Always take out the common factor first; otherwise you may miss a factor.

## Quick revision
- Remainder on dividing by (x − a) = f(a).
- (x − a) is a factor ⇔ f(a) = 0.
- Split middle term: product = ac, sum = b.
- x⁴ + x² + 1 = (x² + x + 1)(x² − x + 1).
- Coefficients add to 0 ⇒ (x − 1) is a factor.

## Practice MCQ
**1.** The factors of x² − 5x + 6 are:
(a) (x + 2)(x + 3) (b) (x − 2)(x − 3) (c) (x − 1)(x − 6) (d) (x + 1)(x − 6)

**2.** x² − x − 12 = ?
(a) (x + 4)(x − 3) (b) (x − 6)(x + 2) (c) (x − 4)(x + 3) (d) (x − 12)(x + 1)

**3.** Which is a factor of a³ + 27?
(a) a − 3 (b) a + 9 (c) a² + 3a + 9 (d) a + 3

**4.** 6x² + x − 2 = ?
(a) (2x − 1)(3x + 2) (b) (2x + 1)(3x − 2) (c) (6x − 1)(x + 2) (d) (3x − 1)(2x + 2)

**5.** The remainder when x³ + 2x² − 5x + 3 is divided by (x − 1) is:
(a) 3 (b) −1 (c) 1 (d) 11

**6.** If (x + 2) is a factor of x³ + 3x² + kx + 4, then k = ?
(a) −4 (b) 2 (c) 8 (d) 4

**7.** x⁴ + 4 = ?
(a) (x² + 2)² (b) (x² + 2x + 2)(x² − 2x + 2) (c) (x² + 2)(x² − 2) (d) (x + 2)(x³ − 2)

**8.** a² − b² + 2b − 1 = ?
(a) (a + b − 1)(a − b + 1) (b) (a − b)(a + b − 1) (c) (a + b + 1)(a − b − 1) (d) (a − 1)(a + 1)

**9.** The common factor of x² − 1 and x² + 3x + 2 is:
(a) x − 1 (b) x + 2 (c) x + 3 (d) x + 1

**10.** x³ − 7x + 6 = ?
(a) (x + 1)(x − 2)(x + 3) (b) (x − 1)(x + 2)(x − 3) (c) (x − 1)(x − 2)(x + 3) (d) (x + 1)(x + 2)(x − 3)

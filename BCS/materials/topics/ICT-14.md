# Email, WWW, browsers, search engines

> **Why it matters:** Exams ask who invented WWW and email, what CC and BCC mean, the first web browser, and search-engine/browser makers. These are short one-line facts.

## World Wide Web (WWW) 🔥
- 🔥 **Tim Berners-Lee** invented the **WWW** in **1989** at **CERN** (Switzerland/Geneva). He is the **father of the WWW**.
- He also created **HTML**, **HTTP** and the **URL**, the first web server and the first web browser (called **WorldWideWeb**, later renamed **Nexus**, 1990).
- **Internet vs WWW:** the internet is the **network (hardware + protocols)**; the WWW is a **service** on the internet made of linked web pages.
- **W3C (World Wide Web Consortium)**, founded by Tim Berners-Lee in **1994**, sets web standards.
- **Web page:** one document on the web. **Website:** a group of related web pages. **Home page:** the first/main page of a website.
- **Hyperlink:** a clickable link to another page. **Hypertext:** text with links.
- **HTML (HyperText Markup Language):** the language of web pages; tags like `<html>`, `<body>`, `<a>`. **CSS** styles the page; **JavaScript** adds interactivity.
- **Web 1.0** = read-only; **Web 2.0** = interactive, user content (social media); **Web 3.0** = semantic / decentralised web.
- **Web hosting:** storing a website on a server. **Bandwidth** and **domain** are needed.
- **Cookie:** a small file a website saves in your browser to remember you. **Cache:** stored copies of pages for faster loading.

## Email (ই-মেইল) 🔥
- 🔥 **Ray Tomlinson** sent the **first network email in 1971** (on ARPANET) and chose the **@** symbol.
- **Email address format:** **username@domain**, e.g. name@example.com. "@" is read as **"at"**.
- Email **cannot** contain spaces in the address.

| Term | Meaning |
|---|---|
| **To** | Main recipient |
| 🔥 **CC** (Carbon Copy) | Copy to others; **all recipients can see** CC addresses |
| 🔥 **BCC** (Blind Carbon Copy) | Copy sent **secretly**; other recipients **cannot see** BCC addresses |
| **Inbox** | Received mail |
| **Outbox** | Mail waiting to be sent |
| **Sent items** | Mail already sent |
| **Draft** | Unfinished, saved mail |
| **Spam / junk** | Unwanted bulk mail |
| **Attachment** | A file sent with the mail |
| **Reply / Reply all / Forward** | Answer sender / answer all / send to a new person |

- Protocols: **SMTP** sends; **POP3/IMAP** receive. **MIME** allows attachments (images, audio) in email.
- Popular services: **Gmail** (Google, 2004), **Outlook/Hotmail** (Hotmail founded by **Sabeer Bhatia** and Jack Smith, 1996; bought by Microsoft), Yahoo Mail.

## Web browsers 🔥
A **browser** is application software used to view web pages.

| Browser | Maker / fact |
|---|---|
| **WorldWideWeb (Nexus)** | **First browser**, Tim Berners-Lee, 1990 |
| 🔥 **Mosaic** | **First popular graphical browser**, 1993 (NCSA; **Marc Andreessen**) |
| **Netscape Navigator** | 1994, Marc Andreessen's company |
| **Internet Explorer** | Microsoft (1995); retired in 2022 |
| **Microsoft Edge** | Microsoft (2015) |
| **Google Chrome** | **Google** (2008); most used browser |
| **Mozilla Firefox** | **Mozilla Foundation**; open source |
| **Safari** | **Apple** |
| **Opera** | Opera Software (Norway) |
| **UC Browser** | UCWeb (Alibaba) |

- **Not browsers:** Google (search engine), Yahoo (portal), Linux (OS) — a common trick option.
- **Incognito / private mode:** browsing without saving history.
- **Bookmark / favourites:** saved web addresses.

## Search engines 🔥
A **search engine** finds information on the web using **crawlers (spiders/bots)** and **indexing**.

| Search engine | Fact |
|---|---|
| **Archie** | **First search engine** (1990), Alan Emtage; searched FTP files |
| 🔥 **Google** | **Larry Page & Sergey Brin**, **1998**; most used; **PageRank** algorithm |
| **Bing** | **Microsoft** (2009) |
| **Yahoo!** | Jerry Yang & David Filo (1994) |
| **Baidu** | **China**'s largest search engine |
| **Yandex** | **Russia** |
| **DuckDuckGo** | Privacy-focused, no tracking |
| **Ask.com**, AltaVista | Older engines |

- **SEO (Search Engine Optimization):** improving a website to rank higher in search results.
- **Pipilika** was Bangladesh's first Bangla search engine (launched 2013).

## Quick revision
- WWW: **Tim Berners-Lee, 1989, CERN**.
- First email and "@": **Ray Tomlinson, 1971**.
- **BCC** hides addresses from other recipients.
- First browser: **WorldWideWeb (Nexus)**; first popular graphical: **Mosaic (1993)**.
- Chrome = Google; Safari = Apple; Edge = Microsoft; Firefox = Mozilla.
- Google founders: **Larry Page, Sergey Brin (1998)**; first search engine: **Archie**.
- Baidu = China; Yandex = Russia; Bing = Microsoft.
- Internet = network; WWW = service on it.

# পদ: বিশেষ্য, বিশেষণ, সর্বনাম

> **Why it matters:** "পদ কত প্রকার?", "'সততা' কোন বিশেষ্য?", "'স্বয়ং' কোন সর্বনাম?", "'ধীরে ধীরে চলো' — 'ধীরে ধীরে' কোন বিশেষণ?" — বাক্য থেকে পদ চেনার প্রশ্ন প্রায় নিশ্চিত।

## পদ: মূল ধারণা
- বিভক্তিযুক্ত শব্দ বা ধাতু বাক্যে ব্যবহৃত হলে তাকে **পদ** বলে। (শব্দ + বিভক্তি = পদ)
- 🔥 প্রচলিত ব্যাকরণে পদ **৫ প্রকার:** **বিশেষ্য, বিশেষণ, সর্বনাম, অব্যয়, ক্রিয়া**।
- প্রথম চারটিকে একসঙ্গে বলা হয় **নামপদ** (বিশেষ্য, বিশেষণ, সর্বনাম, অব্যয়)।
- নতুন কিছু পাঠ্যবইয়ে পদকে ৮ ভাগে (ক্রিয়াবিশেষণ, অনুসর্গ, যোজক, আবেগ আলাদা করে) দেখানো হয়েছে; তবে চাকরির পরীক্ষায় প্রচলিত উত্তর **৫ প্রকার**।

## বিশেষ্য পদ 🔥
যে পদ দিয়ে কোনো ব্যক্তি, জাতি, বস্তু, স্থান, সমষ্টি, কাজ বা গুণের নাম বোঝায়। বিশেষ্য **৬ প্রকার**:

| প্রকার | ব্যাখ্যা | উদাহরণ |
|---|---|---|
| **নামবাচক (সংজ্ঞাবাচক)** | নির্দিষ্ট ব্যক্তি, স্থান, নদী, গ্রন্থের নাম | **নজরুল, ঢাকা, মেঘনা, হিমালয়, গীতাঞ্জলি** |
| **জাতিবাচক** | একই জাতীয় প্রাণী বা বস্তুর সাধারণ নাম | **মানুষ, গরু, পাখি, নদী, পর্বত** |
| **বস্তুবাচক (দ্রব্যবাচক)** | উপাদানবাচক বস্তু, যা গোনা যায় না, মাপা যায় | **বই, চাল, পানি, লোহা, সোনা, চিনি** |
| **সমষ্টিবাচক** | ব্যক্তি বা প্রাণীর সমষ্টি | **সভা, দল, জনতা, পরিবার, বাহিনী, ঝাঁক, মাহফিল** |
| **ভাববাচক (ক্রিয়াবাচক)** | কাজের ভাব বা নাম | **গমন, দর্শন, ভোজন, শয়ন, দেখা, শোনা, যাওয়া** |
| **গুণবাচক** | দোষ বা গুণের নাম | **সততা, সৌন্দর্য, মধুরতা, তারুণ্য, দয়া, সুখ, দুঃখ** |

- মনে রাখুন: **"গমন"** ভাববাচক বিশেষ্য, **"সততা"** গুণবাচক বিশেষ্য, **"জনতা"** সমষ্টিবাচক বিশেষ্য।

## বিশেষণ পদ 🔥
যে পদ বিশেষ্য, সর্বনাম বা ক্রিয়ার দোষ, গুণ, অবস্থা, সংখ্যা, পরিমাণ ইত্যাদি প্রকাশ করে। বিশেষণ **২ প্রকার: নাম বিশেষণ ও ভাব বিশেষণ**।

### ১. নাম বিশেষণ (বিশেষ্য বা সর্বনামকে বিশেষিত করে)
| ধরন | উদাহরণ |
|---|---|
| রূপবাচক | **নীল** আকাশ, **সবুজ** মাঠ |
| গুণবাচক | **চৌকস** লোক, **দক্ষ** কারিগর |
| অবস্থাবাচক | **তাজা** মাছ, **রোগা** ছেলে |
| সংখ্যাবাচক | **হাজার** লোক, **দশ** টাকা |
| ক্রমবাচক | **দশম** শ্রেণি, **প্রথম** পুরস্কার |
| পরিমাণবাচক | **বিঘাটেক** জমি, **এক কেজি** চাল |
| অংশবাচক | **অর্ধেক** সম্পত্তি |
| উপাদানবাচক | **বেলে** মাটি, **পাথুরে** মূর্তি |
| প্রশ্নবাচক | **কতদূর** পথ? |
| নির্দিষ্টতাজ্ঞাপক | **এই** লোক, **সেই** ছেলে |

### ২. ভাব বিশেষণ (বিশেষ্য ও সর্বনাম ছাড়া অন্য পদকে বিশেষিত করে) 🔥
| ধরন | উদাহরণ |
|---|---|
| **ক্রিয়া বিশেষণ** | **ধীরে ধীরে** বায়ু বয়; **পরে** একবার এসো |
| **বিশেষণীয় বিশেষণ** (বিশেষণের বিশেষণ) | **খুব** ভালো; **অতি** সুন্দর |
| **অব্যয়ের বিশেষণ** | **ধিক্** তারে, **শত** ধিক্ |
| **বাক্যের বিশেষণ** | **দুর্ভাগ্যক্রমে** দেশ আবার নানা সমস্যায় জড়িয়ে পড়েছে |

### বিশেষণের অতিশায়ন
দুই বা ততোধিকের মধ্যে তুলনায় গুণের তারতম্য:
- **তর, তম:** গুরু → **গুরুতর** → **গুরুতম**; প্রিয় → প্রিয়তর → প্রিয়তম।
- **ঈয়স, ইষ্ঠ:** গুরু → **গরীয়ান** → **গরিষ্ঠ**; প্রশস্য → **শ্রেয়** → **শ্রেষ্ঠ**।
- বাংলায় **চেয়ে, অপেক্ষা, থেকে, সবচেয়ে** দিয়ে তুলনা: "গরুর চেয়ে ঘোড়ার দাম বেশি"।

## সর্বনাম পদ 🔥
বিশেষ্যের পরিবর্তে যে পদ ব্যবহৃত হয়। প্রচলিত ব্যাকরণে সর্বনাম **১০ প্রকার**:

| প্রকার | উদাহরণ |
|---|---|
| **ব্যক্তিবাচক (পুরুষবাচক)** | **আমি, তুমি, সে, তারা, আপনি, তিনি** |
| **আত্মবাচক** | 🔥 **স্বয়ং, নিজ, খোদ, আপনি** (নিজে অর্থে) |
| **সামীপ্যবাচক** | **এ, এই, এরা, ইহা, এখানে** |
| **দূরত্ববাচক** | **ঐ, ওই, ওরা, ওখানে** |
| **সাকুল্যবাচক** | **সব, সকল, সমুদয়, তাবৎ** |
| **প্রশ্নবাচক** | **কে, কী, কোন, কার, কাহার, কিসে** |
| **অনির্দিষ্টতাজ্ঞাপক** | **কেউ, কেহ, কিছু, কোনো** |
| **ব্যতিহারিক** | **আপনা আপনি, নিজে নিজে, পরস্পর, আপসে** |
| **সংযোগজ্ঞাপক** | **যে, যিনি, যারা, যাঁরা, যাহারা** |
| **অন্যাদিবাচক** | **অন্য, অপর, পর** |

- **সাপেক্ষ সর্বনাম** (জোড়ায় ব্যবহৃত): **যে–সে, যিনি–তিনি, যারা–তারা, যেমন–তেমন, যত–তত**।

## Quick revision
- পদ প্রচলিত মতে **৫ প্রকার**।
- বিশেষ্য **৬ প্রকার**; "গমন" ভাববাচক, "সততা" গুণবাচক, "জনতা" সমষ্টিবাচক।
- বিশেষণ **২ প্রকার: নাম বিশেষণ ও ভাব বিশেষণ**।
- "ধীরে ধীরে চলো" — **ক্রিয়া বিশেষণ**; "খুব ভালো" — **বিশেষণীয় বিশেষণ**।
- "দুর্ভাগ্যক্রমে" — **বাক্যের বিশেষণ**।
- সর্বনাম **১০ প্রকার**; "স্বয়ং" — **আত্মবাচক**; "পরস্পর" — **ব্যতিহারিক**।
- "সব, সকল" — **সাকুল্যবাচক**; "যে, যিনি" — **সংযোগজ্ঞাপক**।

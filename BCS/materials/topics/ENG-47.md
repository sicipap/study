# Analogy

> **Why it matters:** Bank (especially Bangladesh Bank AD/Officer) and some BCS papers ask "DOCTOR : HOSPITAL :: TEACHER : ?". The trick is to name the **exact relationship** in the first pair and find the option with the **same** relationship in the same order.

## How to solve (3 steps)
1. Make a sentence with the first pair: "A **doctor works in** a **hospital**."
2. Put each option into the same sentence: "A **teacher works in** a **school**." ✔
3. If two options fit, make the sentence more specific. Keep the **same order** (A is to B as C is to D).

## Common relationship types 🔥
| Type | Example pair | Matching pair |
|---|---|---|
| **Synonym** | Big : Large | Begin : Start |
| **Antonym** | Hot : Cold | Victory : Defeat |
| **Part : whole** | Petal : Flower | Page : Book |
| **Worker : tool** | Carpenter : Saw | Surgeon : Scalpel |
| **Worker : workplace** | Doctor : Hospital | Teacher : School |
| **Worker : product** | Poet : Poem | Author : Book; Architect : Building |
| **Cause : effect** | Virus : Disease | Rain : Flood |
| **Object : function** | Pen : Write | Knife : Cut |
| **Degree / intensity** | Warm : Hot | Cool : Cold; Happy : Ecstatic |
| **Instrument : what it measures** | Thermometer : Temperature | Barometer : Atmospheric pressure |
| **Study : subject** | Botany : Plants | Zoology : Animals |
| **Country : capital / currency** | Bangladesh : Dhaka | Japan : Tokyo; Japan : Yen |

## Worked examples
1. **PEN : WRITE :: KNIFE : ?** → Pen is used to write; knife is used to **cut**.
2. **COW : CALF :: DOG : ?** → Young of a cow is a calf; young of a dog is a **puppy**.
3. **BEE : HIVE :: LION : ?** → Bee lives in a hive; lion lives in a **den**.
4. **WARM : HOT :: COOL : ?** → Greater degree of warm is hot; of cool is **cold**.
5. **AUTHOR : BOOK :: SCULPTOR : ?** → An author creates a book; a sculptor creates a **statue**.

## Quick revision
- Name the relation in a **sentence**, then test options.
- Keep the **order** the same.
- Young: **calf, puppy, kitten, lamb, foal, cub, kid, cygnet, fawn**.
- Sounds: **neigh (horse), bray (donkey), bleat (sheep), hoot (owl), croak (frog)**.
- Homes: **hive, den, stable, kennel, sty, eyrie**.
- **Barometer** → air pressure; **seismograph** → earthquakes.

# বিপরীতার্থক শব্দ

> **Why it matters:** "'খাতক'-এর বিপরীত শব্দ কোনটি?", "'ঋজু'-এর বিপরীত?" — প্রতিটি পরীক্ষায় অন্তত একটি প্রশ্ন থাকে। কঠিন তৎসম জোড়াগুলোই (জঙ্গম–স্থাবর, ব্যষ্টি–সমষ্টি, উত্তমর্ণ–অধমর্ণ) বেশি আসে।

## বিপরীত শব্দ গঠনের উপায়
| উপায় | উদাহরণ |
|---|---|
| **ভিন্ন শব্দ দিয়ে** | আলো–অন্ধকার, দিন–রাত, জোয়ার–ভাটা |
| **"অ/অন্" উপসর্গে** | জ্ঞান–অজ্ঞান, সৎ–অসৎ, আবশ্যক–অনাবশ্যক |
| **"নি/নির্/নিঃ" উপসর্গে** | আশা–নিরাশা, সাকার–নিরাকার, সচেষ্ট–নিশ্চেষ্ট |
| **"বি" উপসর্গে** | অনুরাগ–বিরাগ, স্মরণ–বিস্মরণ |
| **"অপ" উপসর্গে** | মান–অপমান, উপকার–অপকার, যশ–অপযশ |
| **"দুঃ/দুর্" উপসর্গে** | সুলভ–দুর্লভ, সুশীল–দুঃশীল, সুদিন–দুর্দিন |
| **"না/বে/গর" (বিদেশি) উপসর্গে** | হক–নাহক, হিসাবি–বেহিসাবি, হাজির–গরহাজির |
| **উপসর্গ বদলে** | আবির্ভাব–তিরোভাব, প্রবৃত্তি–নিবৃত্তি, উন্নত–অবনত |

### অর্থ মনে রাখো
- **খাতক** = ঋণগ্রহীতা, **মহাজন** = ঋণদাতা; একইভাবে **অধমর্ণ** = ঋণী, **উত্তমর্ণ** = ঋণদাতা।
- **জঙ্গম** = চলনশীল, **স্থাবর** = অচল।
- **ব্যষ্টি** = একক ব্যক্তি, **সমষ্টি** = সমগ্র।
- **বন্ধুর** = উঁচু-নিচু (এবড়োখেবড়ো), বিপরীত **মসৃণ** (বন্ধুর অর্থ "বন্ধুর মতো" নয়)।
- **ঐহিক** = ইহলোকের, **পারত্রিক** = পরলোকের।
- **অর্বাচীন** = নবীন/অপরিণত, বিপরীত **প্রাচীন**।

## Quick revision
- **খাতক–মহাজন**, **উত্তমর্ণ–অধমর্ণ**।
- **জঙ্গম–স্থাবর**, **ব্যষ্টি–সমষ্টি**।
- **ঋজু–বক্র/কুটিল**, **বন্ধুর–মসৃণ**।
- **আবির্ভাব–তিরোভাব**, **আবাহন–বিসর্জন**।
- **ঐহিক–পারত্রিক**, **কৃতজ্ঞ–কৃতঘ্ন**।
- **প্রবৃত্তি–নিবৃত্তি**, **আকুঞ্চন–প্রসারণ**, **সন্ধি–বিগ্রহ**।

## Practice MCQ
**1.** "খাতক" শব্দের বিপরীত শব্দ কোনটি?
(ক) গ্রাহক (খ) মহাজন (গ) অধমর্ণ (ঘ) দেনাদার

**2.** "জঙ্গম" শব্দের বিপরীত শব্দ কোনটি?
(ক) স্থাবর (খ) অস্থাবর (গ) জঙ্গল (ঘ) চলমান

**3.** "ঋজু" শব্দের বিপরীত শব্দ কোনটি?
(ক) সরল (খ) সোজা (গ) বক্র (ঘ) দীর্ঘ

**4.** "ব্যষ্টি" শব্দের বিপরীত শব্দ কোনটি?
(ক) বৃষ্টি (খ) অব্যষ্টি (গ) সৃষ্টি (ঘ) সমষ্টি

**5.** "আবির্ভাব" শব্দের বিপরীত শব্দ কোনটি?
(ক) অভাব (খ) তিরোভাব (গ) প্রাদুর্ভাব (ঘ) স্বভাব

**6.** "বন্ধুর" শব্দের বিপরীত শব্দ কোনটি?
(ক) শত্রু (খ) উঁচু (গ) মসৃণ (ঘ) কঠিন

**7.** "ঐহিক" শব্দের বিপরীত শব্দ কোনটি?
(ক) পারত্রিক (খ) লৌকিক (গ) দৈহিক (ঘ) আধ্যাত্মিক

**8.** "উত্তমর্ণ" শব্দের বিপরীত শব্দ কোনটি?
(ক) নিম্নবর্ণ (খ) মহাজন (গ) উত্তম (ঘ) অধমর্ণ

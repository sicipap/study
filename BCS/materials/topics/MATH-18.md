# Algebraic formulas & identities

> **Why it matters:** Algebraic formulas (বীজগণিতের সূত্রাবলি) are the most used tools in the BCS math section. Questions like "if a + b = 7 and ab = 12, find a² + b²" or "if x + 1/x = 3, find x³ + 1/x³" come almost every year.

## Key concepts
- An **identity (অভেদ)** is true for all values of the variables, e.g. (a + b)² = a² + 2ab + b².
- An **equation (সমীকরণ)** is true only for some values, e.g. x + 2 = 5.
- Most exam questions give a sum/difference and a product, and ask for squares or cubes. Choose the formula that links what is given to what is asked.

## Formula table 🔥
| No. | Formula |
|---|---|
| 1 | (a + b)² = a² + 2ab + b² |
| 2 | (a − b)² = a² − 2ab + b² |
| 3 | a² − b² = (a + b)(a − b) |
| 4 | 🔥 a² + b² = (a + b)² − 2ab = (a − b)² + 2ab |
| 5 | (a + b)² − (a − b)² = 4ab ; (a + b)² + (a − b)² = 2(a² + b²) |
| 6 | (a + b)³ = a³ + 3a²b + 3ab² + b³ = a³ + b³ + 3ab(a + b) |
| 7 | (a − b)³ = a³ − b³ − 3ab(a − b) |
| 8 | 🔥 a³ + b³ = (a + b)(a² − ab + b²) = (a + b)³ − 3ab(a + b) |
| 9 | a³ − b³ = (a − b)(a² + ab + b²) = (a − b)³ + 3ab(a − b) |
| 10 | (a + b + c)² = a² + b² + c² + 2(ab + bc + ca) |
| 11 | a³ + b³ + c³ − 3abc = (a + b + c)(a² + b² + c² − ab − bc − ca) |
| 12 | 🔥 If a + b + c = 0, then a³ + b³ + c³ = 3abc |
| 13 | (x + a)(x + b) = x² + (a + b)x + ab |

## x + 1/x shortcuts 🔥
| Given | Result |
|---|---|
| x + 1/x = k | x² + 1/x² = k² − 2 |
| x + 1/x = k | x³ + 1/x³ = k³ − 3k |
| x − 1/x = k | x² + 1/x² = k² + 2 |
| x − 1/x = k | x³ − 1/x³ = k³ + 3k |
| x = √a + √b (with a − b = 1) | 1/x = √a − √b |

## Worked examples
**Example 1.** If a + b = 7 and ab = 12, find a² + b².
Steps: (a + b)² − 2ab = 49 − 24 = 25.
**Answer: 25**

**Example 2.** If x + 1/x = 3, find x³ + 1/x³.
Steps: k³ − 3k = 27 − 9 = 18.
**Answer: 18**

**Example 3.** If a − b = 3 and ab = 10, find a³ − b³.
Steps: (a − b)³ + 3ab(a − b) = 27 + 3 × 10 × 3 = 117.
**Answer: 117**

**Example 4.** If x − 1/x = 4, find x² + 1/x².
Steps: k² + 2 = 16 + 2 = 18.
**Answer: 18**

**Example 5.** Find 98 × 102 mentally.
Steps: (100 − 2)(100 + 2) = 100² − 2² = 10000 − 4 = 9996.
**Answer: 9996**

## Common traps
- (a + b)² ≠ a² + b². Do not forget the 2ab term.
- a³ + b³ has **−ab** inside the bracket; a³ − b³ has **+ab**.
- x + 1/x gives k² **− 2**; x − 1/x gives k² **+ 2**.
- When a + b + c = 0 the answer to (a³ + b³ + c³)/abc is **3**, not 0.

## Quick revision
- a² + b² = (a + b)² − 2ab.
- 4ab = (a + b)² − (a − b)².
- a³ + b³ = (a + b)³ − 3ab(a + b).
- a³ − b³ = (a − b)³ + 3ab(a − b).
- a + b + c = 0 ⇒ a³ + b³ + c³ = 3abc.
- x + 1/x = k ⇒ x² + 1/x² = k² − 2, x³ + 1/x³ = k³ − 3k.

## Practice MCQ
**1.** If a + b = 5 and ab = 6, then a² + b² = ?
(a) 13 (b) 25 (c) 19 (d) 37

**2.** If x + 1/x = 4, then x² + 1/x² = ?
(a) 16 (b) 18 (c) 14 (d) 12

**3.** If a + b = 4 and a − b = 2, then ab = ?
(a) 2 (b) 3 (c) 4 (d) 6

**4.** If x + 1/x = 3, then x³ + 1/x³ = ?
(a) 27 (b) 24 (c) 36 (d) 18

**5.** If a + b + c = 0, then (a³ + b³ + c³)/abc = ?
(a) 3 (b) 0 (c) 1 (d) −3

**6.** 997² = ?
(a) 994009 (b) 994091 (c) 996009 (d) 994001

**7.** If a − b = 5 and ab = 24, then a³ − b³ = ?
(a) 125 (b) 485 (c) 245 (d) 365

**8.** If a + b + c = 9 and ab + bc + ca = 26, then a² + b² + c² = ?
(a) 55 (b) 107 (c) 29 (d) 81

**9.** If x = √3 + √2, then x² + 1/x² = ?
(a) 12 (b) 2√3 (c) 8 (d) 10

**10.** a³ + b³ is equal to:
(a) (a + b)(a² + ab + b²) (b) (a − b)(a² + ab + b²) (c) (a + b)(a² − ab + b²) (d) (a + b)³

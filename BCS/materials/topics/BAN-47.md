# বাগধারা ও প্রবাদ

> **Why it matters:** "'অকাল কুষ্মাণ্ড' বাগধারার অর্থ কী?" ধরনের প্রশ্ন প্রিলিমিনারি, ব্যাংক, প্রাথমিক শিক্ষক — সব পরীক্ষায় আসে। প্রতি পরীক্ষায় সাধারণত ১–২টি।

## বাগধারা কী
যে শব্দগুচ্ছ **আভিধানিক অর্থ ছাড়িয়ে বিশেষ অর্থ** প্রকাশ করে, তাকে **বাগধারা** বলে। যেমন "অরণ্যে রোদন" মানে বনে কান্না নয়, **নিষ্ফল আবেদন**।
**প্রবাদ** হলো লোকমুখে প্রচলিত **সংক্ষিপ্ত, অভিজ্ঞতালব্ধ উক্তি**, যা একটি সম্পূর্ণ বাক্য। যেমন "অতি লোভে তাঁতি নষ্ট"।

**মনে রাখার দল:**
- **অসম্ভব বস্তু:** আকাশ কুসুম, কাঁঠালের আমসত্ত্ব, সোনার পাথরবাটি, ঘোড়ার ডিম।
- **অপদার্থ:** অকাল কুষ্মাণ্ড, আমড়া কাঠের ঢেঁকি, গোবর গণেশ (মূর্খ)।
- **ভণ্ড/কপট:** বকধার্মিক, বিড়াল তপস্বী, ভিজে বিড়াল, বর্ণচোরা আম, তুলসী বনের বাঘ।

## বহুল প্রচলিত প্রবাদ
| প্রবাদ | অর্থ / প্রয়োগ |
|---|---|
| **অতি লোভে তাঁতি নষ্ট** | বেশি লোভে সর্বনাশ |
| **অল্পবিদ্যা ভয়ংকরী** | অল্প জ্ঞান বিপজ্জনক |
| **অভাবে স্বভাব নষ্ট** | দারিদ্র্য মানুষের চরিত্র নষ্ট করে |
| **ইচ্ছা থাকলে উপায় হয়** | দৃঢ় ইচ্ছায় পথ মেলে |
| **কষ্ট না করলে কেষ্ট মেলে না** | পরিশ্রম ছাড়া সাফল্য নেই |
| **কানা ছেলের নাম পদ্মলোচন** | নামের সঙ্গে গুণের অমিল |
| **চোর পালালে বুদ্ধি বাড়ে** | সময় পেরোলে উপায় মনে আসে |
| **দশের লাঠি একের বোঝা** | সবাই মিলে করলে কাজ সহজ |
| **নাচতে না জানলে উঠান বাঁকা** | নিজের অক্ষমতায় অন্যের দোষ দেওয়া |
| **যত গর্জে তত বর্ষে না** | যে বেশি হম্বিতম্বি করে, সে কাজে কম |
| **সময়ের এক ফোঁড়, অসময়ের দশ ফোঁড়** | সময়ের কাজ সময়ে করা উচিত |
| **ঠাকুর ঘরে কে? আমি কলা খাই না** | অপরাধী নিজেই নিজেকে ধরিয়ে দেয় |
| **বানরের গলায় মুক্তার মালা** | অযোগ্যের হাতে মূল্যবান জিনিস |
| **হাতি ঘোড়া গেল তল, মশা বলে কত জল** | বড়রা যেখানে ব্যর্থ, সেখানে ক্ষুদ্রের দম্ভ |

## Quick revision
- **অকাল কুষ্মাণ্ড** = অপদার্থ; **অগস্ত্য যাত্রা** = চিরদিনের জন্য প্রস্থান।
- **অরণ্যে রোদন** = নিষ্ফল আবেদন; **আদায় কাঁচকলায়** = চরম শত্রুতা।
- **কূপমণ্ডূক** = সীমিত জ্ঞানের মানুষ; **গড্ডলিকা প্রবাহ** = অন্ধ অনুকরণ।
- **দুধের মাছি** = সুসময়ের বন্ধু; **মণিকাঞ্চন যোগ** = উপযুক্ত মিলন।
- **হাটে হাঁড়ি ভাঙা** = গোপন কথা প্রকাশ; **টনক নড়া** = হুঁশ হওয়া।
- **খয়ের খাঁ** = চাটুকার; **কলুর বলদ** = একটানা খাটুনি।

**4.** "দুধের মাছি" বলতে কাকে বোঝায়?

**5.** "কাঁঠালের আমসত্ত্ব" বাগধারার অর্থ কী?

(ক) বিজ্ঞ ব্যক্তি (খ) ভণ্ড ব্যক্তি (গ) চাটুকার (ঘ) সীমিত জ্ঞানের মানুষ

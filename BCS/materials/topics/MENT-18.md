# Figure series & pattern completion

> **Why it matters:** Figure series (চিত্র ধারা) shows 4–5 figures that change step by step; you choose the next one. Pattern completion shows a grid (often 3 × 3) with one cell missing. The changes follow a small set of rules that you can learn and describe in words.

## The common rules of change 🔥
| Rule | What to look for | Example in words |
|---|---|---|
| **Rotation** | A shape or arrow turns by a fixed angle (45°, 90°, 135°, 180°) clockwise or anticlockwise | Arrow: up → right → down → left |
| **Movement** | An element moves one step round the corners or along the sides | Black dot: TL → TR → BR → BL |
| **Addition** | One line, dot or side is added each step | Triangle → square → pentagon → hexagon |
| **Subtraction** | One element is removed each step | 5 dots → 4 → 3 |
| **Alternation** | Two states swap every step | Circle, square, circle, square |
| **Shading** | The shaded part moves or grows | ¼ shaded → ½ → ¾ |
| **Counting pattern** | Number of elements follows a number series | 1, 3, 6, 10 dots (add 2, 3, 4) |
| **Combination** | Two or more rules at once | Shape alternates AND a line is added each time |

## Rotation rules to remember
- On a clock face, **90° = 3 hours**, **45° = 1½ hours**, **30° = 1 hour**.
- Turning 360° brings a figure back to where it started, so **reduce the total turn by 360°**: 5 turns of 90° = 450° = **90°**.
- Clockwise from north: N → NE → E → SE → S → SW → W → NW (each 45°).

## Method
1. **Track one element at a time** (the arrow, the dot, the shading) through all the figures.
2. Write its change in words ("moves one corner clockwise").
3. Check whether a **second element** follows a different rule.
4. Check **alternate figures** (1st, 3rd, 5th) if consecutive ones do not fit.
5. Reject options that break **any** rule.

## Pattern completion (3 × 3 matrix)
- Check **each row** first: often the third figure = first + second, or the count goes up by one.
- Then check **each column**.
- Common matrix rules: every row contains the same three shapes in a different order (**Latin square**); the number of elements rises across a row; a figure is the overlap of the other two.
```
Row 1:   1 dot    2 dots   3 dots
Row 2:   2 dots   3 dots   4 dots
Row 3:   3 dots   4 dots   ?        → 5 dots
```

## Worked examples
**Example 1.** Triangle, square, pentagon, hexagon, ?
Sides increase by one: 3, 4, 5, 6 → **heptagon** (7 sides).

**Example 2.** An arrow points north, then north-east, then east, then south-east. Next?
45° clockwise each step → **south**.

**Example 3.** A black square is in the top-left corner, then top-right, then bottom-right. Next?
One corner clockwise each step → **bottom-left**.

**Example 4.** An arrow starts pointing up and turns 90° clockwise each step. Where does it point after 5 steps?
5 × 90° = 450° → 450 − 360 = 90° → **right**.

**Example 5.** Circle with 0 lines, square with 1 line, circle with 2 lines, square with 3 lines, ?
Shape alternates; lines increase by 1 → **circle with 4 lines**.

## Quick revision
- Look for rotation, movement, addition, subtraction, alternation, shading.
- Track one element at a time.
- Reduce total rotation by 360°.
- 45° steps: N, NE, E, SE, S, SW, W, NW.
- In a matrix, check rows first, then columns.
- The right option must satisfy every rule at once.

## Practice MCQ
**1.** Triangle, square, pentagon, hexagon, ? What comes next?
(a) Octagon (b) Heptagon (c) Circle (d) Square

**2.** In a figure series, an arrow points north, north-east, east, south-east. Where will it point in the next figure?
(a) South-west (b) West (c) South (d) North

**3.** A shaded corner moves: top-left, top-right, bottom-right, ? Where is it next?
(a) Bottom-left (b) Top-left (c) Centre (d) Top-right

**4.** The number of dots in a series of figures is 1, 3, 6, 10, ? How many dots are in the next figure?
(a) 12 (b) 14 (c) 16 (d) 15

**5.** An arrow starts pointing up and turns 90° clockwise at each step. Where does it point after 5 steps?
(a) Up (b) Right (c) Down (d) Left

**6.** A series goes: circle with 0 lines inside, square with 1 line, circle with 2 lines, square with 3 lines, ? What comes next?
(a) Square with 4 lines (b) Circle with 3 lines (c) Circle with 4 lines (d) Square with 5 lines

**7.** In a 3 × 3 matrix, row 1 has 1, 2, 3 dots; row 2 has 2, 3, 4 dots; row 3 has 3, 4 and ? dots. What is missing?
(a) 5 (b) 6 (c) 4 (d) 7

**8.** A line starts pointing to 12 on a clock face and turns 45° anticlockwise at each step. Which direction does it point after 3 steps (12 = north)?
(a) North-west (b) West (c) South (d) South-west

## Answer key
| Q | Ans | Explanation |
|---|---|---|
| 1 | b | Sides go 3, 4, 5, 6, so next is 7 (heptagon). |
| 2 | c | 45° clockwise each step: SE → S. |
| 3 | a | The corner moves clockwise; after BR comes BL. |
| 4 | d | Add 2, 3, 4, then 5: 10 + 5 = 15. |
| 5 | b | 450° − 360° = 90°, which points right. |
| 6 | c | Shapes alternate and lines increase by 1. |
| 7 | a | Each row rises by 1: 3, 4, 5. |
| 8 | d | N → NW → W → SW. |

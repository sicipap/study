# MS Office: Word, Excel, PowerPoint

> **Why it matters:** Practical questions on shortcut keys, file extensions, Excel formulas/cell references and PowerPoint views appear in almost every bank and ministry exam. The shortcut table is a must-memorise.

## Microsoft Office basics
- **MS Office** is an **application software package** (office suite) by **Microsoft**. Main programs: **Word** (word processor), **Excel** (spreadsheet), **PowerPoint** (presentation), **Access** (database), **Outlook** (email), OneNote.
- Free alternatives: **LibreOffice / OpenOffice** (Writer, Calc, Impress), **Google Docs/Sheets/Slides** (online).
- **Ribbon:** the tab-based toolbar (Home, Insert, Design, Layout, References, Mailings, Review, View), introduced in **Office 2007**.

## MS Word
- Word processor: typing, editing, formatting documents.
- **Mail Merge:** creates many personalised letters/labels from one document + a data list (under the **Mailings** tab).
- **Header/footer**, **page number**, **WordArt**, **drop cap** (large first letter), **watermark**, **table of contents**, **footnote/endnote** (References tab), **track changes** (Review tab).
- Default font: **Calibri, 11 pt** (Word 2007–2021). In recent Microsoft 365 (2023+) the default is **Aptos**.
- Default page margins: **1 inch** on all sides.
- **Orientation:** portrait (vertical) or landscape (horizontal).
- In Word, **F5** opens **Go To**.

## MS Excel 🔥
- **Spreadsheet** program. A file is a **workbook**; each page is a **worksheet**; a box is a **cell**.
- 🔥 **Cell address = column letter + row number**, e.g. **B3**. The selected cell is the **active cell**.
- Size (Excel 2007 and later): **1,048,576 rows** and **16,384 columns** (last column **XFD**).
- A new workbook has **1 sheet** in Excel 2013 and later (**3 sheets** in Excel 2010 and earlier).
- 🔥 Every formula starts with **"="**. Example: `=SUM(A1:A10)`.

| Reference type | Example | Behaviour when copied |
|---|---|---|
| **Relative** | A1 | Changes |
| 🔥 **Absolute** | **$A$1** | **Does not change** (press **F4** to toggle) |
| **Mixed** | $A1 or A$1 | Only one part changes |

| Function | Use |
|---|---|
| **SUM, AVERAGE** | Total, mean |
| **MAX, MIN** | Largest, smallest |
| **COUNT** | Counts cells with **numbers**; **COUNTA** counts non-empty cells |
| **IF** | Logical test: `=IF(A1>=33,"Pass","Fail")` |
| **VLOOKUP / HLOOKUP** | Look up a value vertically / horizontally |
| **ROUND**, **CONCATENATE** (or CONCAT, &) | Rounding; joining text |
| **TODAY(), NOW()** | Current date; current date and time |

| Error | Meaning |
|---|---|
| **#DIV/0!** | Division by zero |
| **#VALUE!** | Wrong type of value (text in a sum) |
| **#REF!** | Invalid cell reference |
| **#NAME?** | Unknown function/name |
| **#N/A** | Value not available (lookup failed) |
| **#####** | Column too narrow to show the number |

- Excel shortcuts: **F2** edit cell, **Alt + =** AutoSum, **Ctrl + ;** current date, **Ctrl + Shift + ;** current time, **F11** create chart, **Shift + F11** new worksheet, **Ctrl + 1** Format Cells.

## MS PowerPoint 🔥
- **Presentation** program; a file is a **presentation** made of **slides**.
- 🔥 **F5** = start slide show **from the beginning**; **Shift + F5** = from the **current slide**; **Esc** = end show.
- **Ctrl + M** = **new slide**.
- **Views:** **Normal** (default, for editing), **Slide Sorter** (thumbnails, to rearrange slides), Notes Page, **Reading View**, **Slide Show**.
- 🔥 **Transition** = effect **between slides**; **Animation** = effect on **objects (text, pictures) within a slide**.
- **Slide Master:** controls the design/layout of all slides at once.
- **Speaker notes:** notes for the presenter, not shown to the audience.

## Quick revision
- Word 2007+ extension **.docx**; Excel **.xlsx**; PowerPoint **.pptx**.
- **F12** = Save As; **F7** = spell check; **Ctrl + H** = Replace; **Shift + F3** = change case.
- Excel formula starts with **=**; absolute reference **$A$1** (F4).
- Excel 2007+: **1,048,576 rows × 16,384 columns** (last column XFD).
- **#DIV/0!** = divided by zero.
- PowerPoint: **F5** from start, **Shift + F5** from current slide; **Ctrl + M** new slide.
- Transition = between slides; animation = objects in a slide.
- Mail Merge is in Word's **Mailings** tab.

## Practice MCQ

**2.** Which is an absolute cell reference in Excel?
(a) $A$1 (b) A1 (c) A$1 (d) $A1

**3.** In PowerPoint, which key starts the slide show from the current slide?
(a) F5 (b) Ctrl + M (c) Shift + F5 (d) Alt + F5

**4.** The default file extension of an Excel 2016 workbook is:
(a) .xls (b) .docx (c) .pptx (d) .xlsx

**5.** Which shortcut opens the Find and Replace box on the Replace tab?
(a) Ctrl + H (b) Ctrl + F (c) Ctrl + R (d) Ctrl + P

**6.** In Excel, a formula must begin with:
(a) # (b) = (c) @ (d) $

**7.** The Excel error #DIV/0! means:
(a) Wrong cell reference (b) Unknown function name (c) Division by zero (d) Column too narrow

**8.** An effect applied when moving from one slide to the next is called:
(a) Animation (b) Slide Master (c) Mail Merge (d) Transition

## Answer key

|---|---|---|
| 1 | b | F12 = Save As; F7 = spelling |
| 2 | a | Both column and row are fixed with $ |
| 3 | c | F5 from beginning; Shift + F5 from current slide |
| 4 | d | Excel 2007 onwards saves .xlsx |
| 5 | a | Ctrl + H = Replace; Ctrl + F = Find |
| 6 | b | Formulas start with = |
| 7 | c | A number was divided by zero |

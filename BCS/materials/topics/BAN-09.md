# সন্ধি: স্বরসন্ধি

> **Why it matters:** প্রতিটি পরীক্ষায় "সন্ধি বিচ্ছেদ করুন" ধরনের এক-দুটি প্রশ্ন থাকে — হিমালয়, রবীন্দ্র, সূর্যোদয়, মহর্ষি, জনৈক, অত্যন্ত, স্বাগত, নায়ক, পবন, গবাক্ষ ইত্যাদি বারবার আসে।

## সন্ধি: মৌলিক ধারণা
- **সন্ধি:** পাশাপাশি দুটি ধ্বনির মিলনকে সন্ধি বলে। সন্ধির উদ্দেশ্য **উচ্চারণের সহজতা ও ধ্বনিগত মাধুর্য** সৃষ্টি।
- তৎসম (সংস্কৃত) সন্ধি **তিন প্রকার:** **স্বরসন্ধি, ব্যঞ্জনসন্ধি, বিসর্গসন্ধি**।
- খাঁটি বাংলা সন্ধি **দুই প্রকার:** স্বরসন্ধি ও ব্যঞ্জনসন্ধি (বাংলায় বিসর্গসন্ধি নেই)।
- **স্বরসন্ধি:** স্বরধ্বনির সঙ্গে স্বরধ্বনির মিলন।
- সন্ধি হয় **ধ্বনির** মিলনে; সমাস হয় **পদের** মিলনে।

## স্বরসন্ধির নিয়ম 🔥🔥

### নিয়ম ১: অ/আ + অ/আ = আ (া)
**নর + অধম = নরাধম**, **হিম + আলয় = হিমালয়**, **বিদ্যা + আলয় = বিদ্যালয়**, **যথা + অর্থ = যথার্থ**, **দেব + আলয় = দেবালয়**, **কথা + অমৃত = কথামৃত**, **হিত + অহিত = হিতাহিত**, **মহা + আশয় = মহাশয়**।

### নিয়ম ২: ই/ঈ + ই/ঈ = ঈ (ী)
**অতি + ইত = অতীত**, **রবি + ইন্দ্র = রবীন্দ্র**, **পরি + ঈক্ষা = পরীক্ষা**, **প্রতি + ইক্ষা = প্রতীক্ষা**, **সতী + ঈশ = সতীশ**, **মহী + ইন্দ্র = মহীন্দ্র**, **ক্ষিতি + ঈশ = ক্ষিতীশ**।

### নিয়ম ৩: উ/ঊ + উ/ঊ = ঊ (ূ)
**মরু + উদ্যান = মরূদ্যান**, **বধূ + উৎসব = বধূৎসব**, **লঘু + ঊর্মি = লঘূর্মি**।

### নিয়ম ৪: অ/আ + ই/ঈ = এ (ে)
**শুভ + ইচ্ছা = শুভেচ্ছা**, **নর + ইন্দ্র = নরেন্দ্র**, **পরম + ঈশ = পরমেশ**, **মহা + ঈশ = মহেশ**, **যথা + ইষ্ট = যথেষ্ট**, **রমা + ঈশ = রমেশ**, **গণ + ঈশ = গণেশ**।

### নিয়ম ৫: অ/আ + উ/ঊ = ও (ো)
**সূর্য + উদয় = সূর্যোদয়**, **পর + উপকার = পরোপকার**, **হিত + উপদেশ = হিতোপদেশ**, **যথা + উচিত = যথোচিত**, **মহা + উৎসব = মহোৎসব**, **নব + ঊঢ়া = নবোঢ়া**, **গঙ্গা + ঊর্মি = গঙ্গোর্মি**।

### নিয়ম ৬: অ/আ + ঋ = অর্ (রেফ)
**দেব + ঋষি = দেবর্ষি**, **মহা + ঋষি = মহর্ষি**, **সপ্ত + ঋষি = সপ্তর্ষি**, **রাজা + ঋষি = রাজর্ষি**, **ব্রহ্ম + ঋষি = ব্রহ্মর্ষি**।

### নিয়ম ৭: অ/আ + ঋত = আর্
**শীত + ঋত = শীতার্ত**, **তৃষ্ণা + ঋত = তৃষ্ণার্ত**, **ক্ষুধা + ঋত = ক্ষুধার্ত**, **দুঃখ + ঋত = দুঃখার্ত**।

### নিয়ম ৮: অ/আ + এ/ঐ = ঐ (ৈ)
**জন + এক = জনৈক**, **সদা + এব = সদৈব**, **মত + ঐক্য = মতৈক্য**, **হিত + এষী = হিতৈষী**, **মহা + ঐশ্বর্য = মহৈশ্বর্য**।

### নিয়ম ৯: অ/আ + ও/ঔ = ঔ (ৌ)
**বন + ওষধি = বনৌষধি**, **মহা + ঔষধ = মহৌষধ**, **পরম + ঔষধ = পরমৌষধ**।

### নিয়ম ১০: ই/ঈ + অন্য স্বর = য-ফলা 🔥
**অতি + অন্ত = অত্যন্ত**, **ইতি + আদি = ইত্যাদি**, **প্রতি + এক = প্রত্যেক**, **প্রতি + উপকার = প্রত্যুপকার**, **পরি + অন্ত = পর্যন্ত**, **অতি + আচার = অত্যাচার**, **প্রতি + আশা = প্রত্যাশা**, **অভি + আগত = অভ্যাগত**, **আদি + অন্ত = আদ্যন্ত**।

### নিয়ম ১১: উ/ঊ + অন্য স্বর = ব-ফলা 🔥
**সু + আগত = স্বাগত**, **অনু + ইত = অন্বিত**, **অনু + এষণ = অন্বেষণ**, **অনু + অয় = অন্বয়**, **পশু + অধম = পশ্বধম**, **তনু + অঙ্গী = তন্বঙ্গী**।

### নিয়ম ১২: ঋ + অন্য স্বর = র-ফলা
**পিতৃ + আলয় = পিত্রালয়**, **মাতৃ + আদেশ = মাত্রাদেশ**, **পিতৃ + অনুমতি = পিত্রনুমতি**।

### নিয়ম ১৩: এ, ঐ, ও, ঔ + অন্য স্বর 🔥
**এ → অয়, ঐ → আয়, ও → অব, ঔ → আব**

| বিচ্ছেদ | সন্ধি |
|---|---|
| **নে + অন** | **নয়ন** |
| **শে + অন** | **শয়ন** |
| **নৈ + অক** | **নায়ক** |
| **গৈ + অক** | **গায়ক** |
| **পো + অন** | **পবন** |
| **লো + অন** | **লবণ** |
| **গো + এষণা** | **গবেষণা** |
| **পৌ + অক** | **পাবক** |
| **ভৌ + উক** | **ভাবুক** |

## নিপাতনে সিদ্ধ স্বরসন্ধি 🔥
যেসব সন্ধি নিয়ম মানে না, প্রচলিত রূপেই শুদ্ধ:
**গো + অক্ষ = গবাক্ষ**, **কুল + অটা = কুলটা**, **প্র + ঊঢ় = প্রৌঢ়**, **অন্য + অন্য = অন্যান্য**, **মার্ত + অণ্ড = মার্তণ্ড**, **শুদ্ধ + ওদন = শুদ্ধোদন**।

## খাঁটি বাংলা স্বরসন্ধি
**মিথ্যা + উক = মিথ্যুক**, **রুপা + আলি = রুপালি**, **শত + এক = শতেক**, **যা + ইচ্ছা + তাই = যাচ্ছেতাই**।

**মনে রাখার কৌশল:** *"ই-য়, উ-ব, ঋ-র" — ই/উ/ঋ-এর পরে ভিন্ন স্বর এলে যথাক্রমে য-ফলা, ব-ফলা, র-ফলা হয়।*

## Quick revision
- হিমালয় = **হিম + আলয়**; বিদ্যালয় = **বিদ্যা + আলয়**।
- রবীন্দ্র = **রবি + ইন্দ্র**; পরীক্ষা = **পরি + ঈক্ষা**।
- সূর্যোদয় = **সূর্য + উদয়**; যথেষ্ট = **যথা + ইষ্ট**।
- মহর্ষি = **মহা + ঋষি**; তৃষ্ণার্ত = **তৃষ্ণা + ঋত**।
- জনৈক = **জন + এক**; মহৌষধ = **মহা + ঔষধ**।
- অত্যন্ত = **অতি + অন্ত**; স্বাগত = **সু + আগত**।
- নায়ক = **নৈ + অক**; পবন = **পো + অন**।
- গবাক্ষ = **গো + অক্ষ** (নিপাতনে সিদ্ধ)।

## Practice MCQ
**1.** "হিমালয়" এর সন্ধি বিচ্ছেদ কোনটি?
(ক) হিম + আলয় (খ) হিমা + আলয় (গ) হিম + লয় (ঘ) হিমা + লয়

**2.** "নায়ক" এর সঠিক সন্ধি বিচ্ছেদ কোনটি?
(ক) না + য়ক (খ) নায় + অক (গ) নৈ + অক (ঘ) নে + অক

**3.** "স্বাগত" শব্দের সন্ধি বিচ্ছেদ কোনটি?
(ক) স্ব + আগত (খ) সু + আগত (গ) স + আগত (ঘ) স্বা + গত

**4.** "মহর্ষি" এর সন্ধি বিচ্ছেদ কোনটি?
(ক) মহ + ঋষি (খ) মহঃ + ঋষি (গ) মহা + ঈর্ষি (ঘ) মহা + ঋষি

**5.** "গবাক্ষ" কোন ধরনের সন্ধি?
(ক) নিপাতনে সিদ্ধ স্বরসন্ধি (খ) ব্যঞ্জনসন্ধি (গ) বিসর্গসন্ধি (ঘ) খাঁটি বাংলা সন্ধি

**6.** "পরীক্ষা" এর সন্ধি বিচ্ছেদ কোনটি?
(ক) পরী + ক্ষা (খ) পরি + ইক্ষা (গ) পর + ঈক্ষা (ঘ) পরি + ঈক্ষা

**7.** "অত্যন্ত" শব্দের সন্ধি বিচ্ছেদ কোনটি?
(ক) অতি + অন্ত (খ) অত্য + অন্ত (গ) অতি + যন্ত (ঘ) অত্যা + অন্ত

**8.** "জনৈক" শব্দের সন্ধি বিচ্ছেদ কোনটি?
(ক) জনৈ + এক (খ) জনা + ঐক (গ) জন + এক (ঘ) জন + ঐক

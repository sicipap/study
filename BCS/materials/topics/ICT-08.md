# Software & operating systems

> **Why it matters:** Exams ask system vs application software, examples of operating systems, open-source software, who made Linux/Android, and OS terms like booting, multitasking and kernel.

## Software (সফটওয়্যার) 🔥
Software is a set of **programs (instructions)** that tells the hardware what to do.

| Type | What it does | Examples |
|---|---|---|
| 🔥 **System software** | Runs and manages the computer itself | **Operating systems**, device drivers, utility programs, language translators (compiler, interpreter, assembler), BIOS/firmware |
| 🔥 **Application software** | Does a specific job for the user | **MS Word, Excel**, web browsers, Photoshop, games, accounting software, media players |

- **Utility software:** maintenance tools, e.g. **antivirus**, disk cleanup, disk defragmenter, backup, file compression (WinRAR, 7-Zip).
- **Device driver:** lets the OS talk to a hardware device (printer driver).
- **Firmware:** software stored permanently in ROM/flash (e.g. **BIOS/UEFI**).
- **Customised (tailor-made) software:** built for one organisation. **Packaged software:** sold ready-made to many users.

## Software by licence 🔥
| Type | Meaning | Examples |
|---|---|---|
| **Proprietary (closed source)** | Source code is secret; must be bought/licensed | MS Windows, MS Office, macOS |
| 🔥 **Open source** | **Source code is free** to see, change and share | **Linux**, **Android**, Firefox, LibreOffice, **Apache**, MySQL, Python |
| **Freeware** | Free to use, but source code is not open | Skype (old), Adobe Acrobat Reader |
| **Shareware** | Free trial for a limited time, then pay | WinRAR (trial) |

- **Richard Stallman** started the **GNU Project (1983)** and the **Free Software Foundation**; he wrote the **GPL** licence.

## Operating system (অপারেটিং সিস্টেম) 🔥
The OS is the **main system software**. It works as the **interface between the user and the hardware** and manages all resources.

**Functions of an OS:** process (CPU) management, **memory management**, **file management**, device (I/O) management, security, and the user interface.

### Popular operating systems
| OS | Developer / key fact |
|---|---|
| **MS-DOS** | Microsoft (1981); **command-line (CUI)**, single-user, single-tasking |
| **Windows** | Microsoft; **GUI**; Windows 1.0 (1985), Windows 95, XP, 7, 10, **11** (2021) |
| **UNIX** | **Bell Labs (AT&T), 1969**; Ken Thompson & Dennis Ritchie; multi-user |
| 🔥 **Linux** | **Linus Torvalds (1991)**, Finland; **open source**; mascot: a penguin named **Tux**. Distributions: Ubuntu, Fedora, Debian, Red Hat |
| **macOS** | **Apple**, for Mac computers (UNIX-based) |
| 🔥 **Android** | **Google** (bought Android Inc., 2005); **Linux-based**, open source; developed by **Andy Rubin** and colleagues. Most used mobile OS |
| **iOS** | **Apple**, for iPhone |
| **Chrome OS** | Google, for Chromebooks |
| **HarmonyOS** | Huawei |
| **Symbian, BlackBerry OS** | Old mobile OSs |

### Types of operating systems
| Type | Meaning |
|---|---|
| **Single-user, single-tasking** | One user, one program (MS-DOS) |
| **Multitasking** | One user runs several programs at once (Windows) |
| **Multi-user** | Many users share one computer (UNIX, Linux) |
| **Multiprocessing** | Uses two or more CPUs |
| **Time-sharing** | CPU time is divided among users in small slices |
| **Batch processing** | Jobs are grouped and run without user interaction |
| 🔥 **Real-time OS (RTOS)** | Responds **within a fixed time**; used in air-traffic control, missiles, medical devices, industrial robots |
| **Distributed OS** | Manages a group of networked computers as one system |

## Key OS terms 🔥
- **Booting:** starting the computer and loading the OS into RAM. **Cold booting** = start from power off; **warm booting** = restart (**Ctrl+Alt+Del**).
- **Kernel:** the **core** of the OS; stays in memory and controls hardware.
- **Shell:** the program that takes user commands and passes them to the kernel.
- **GUI** (Graphical User Interface): icons, windows, mouse. **CUI/CLI**: typed commands.
- **Deadlock:** two or more processes wait for each other forever.
- **Spooling:** putting jobs (e.g. print jobs) in a buffer/queue.
- **Virtual memory:** using hard disk space as extra RAM. **Paging** divides memory into fixed-size pages.
- **File systems:** FAT32, **NTFS** (Windows), ext4 (Linux).

## Quick revision
- OS is **system software**; MS Word is **application software**.
- Antivirus and disk defragmenter are **utility software**.
- Linux: **Linus Torvalds, 1991**, open source.
- UNIX: **Bell Labs, 1969**.
- Android is **Linux-based**, owned by **Google**.
- MS-DOS is **CUI**; Windows is **GUI**.
- Real-time OS: **air-traffic control, missiles**.
- Restart = **warm booting**; core of the OS = **kernel**.

## Practice MCQ
**1.** Which of the following is system software?
(a) MS Excel (b) Operating system (c) Photoshop (d) Google Chrome

**2.** Who created Linux?
(a) Linus Torvalds (b) Richard Stallman (c) Dennis Ritchie (d) Bill Gates

**3.** Android is based on which kernel?
(a) Windows (b) macOS (c) Linux (d) Symbian

**4.** Restarting a computer that is already on is called:
(a) Cold booting (b) Spooling (c) Paging (d) Warm booting

**5.** Which of the following is open-source software?
(a) MS Windows (b) macOS (c) MS Office (d) LibreOffice

**6.** An operating system used in air-traffic control, which must respond within a fixed time, is a:
(a) Real-time OS (b) Batch OS (c) Single-user OS (d) Time-sharing OS only

**7.** The core part of an operating system that stays in memory is the:
(a) Shell (b) Kernel (c) Driver (d) Compiler

**8.** Antivirus software belongs to which category?
(a) Application package (b) Firmware (c) Utility software (d) Compiler

## Answer key
| Q | Ans | Explanation |
|---|---|---|
| 1 | b | OS manages the computer; others are applications |
| 2 | a | Linus Torvalds released Linux in 1991 |
| 3 | c | Android uses the Linux kernel |
| 4 | d | Warm boot = restart without switching off |
| 5 | d | LibreOffice source code is free |
| 6 | a | RTOS gives guaranteed response time |
| 7 | b | Kernel is the core; shell is the interface |
| 8 | c | Antivirus is a utility program |

# Group verbs

> **Why it matters:** Bank and BCS papers regularly ask "*Put off* means…" or "Fill in: The meeting was called ___." A **group verb (phrasal verb)** is a verb + preposition/adverb whose meaning changes, e.g. *give up* = abandon.

## Key tips
- The particle changes the meaning: **look after** (take care of) vs **look for** (search) vs **look into** (investigate).
- Most-tested verbs: **look, put, give, take, break, bring, call, come, get, make, run, set, turn**.

## Easily confused pairs
| Pair | Difference |
|---|---|
| **Call on** / **call at** | *on* + person, *at* + place |
| **Put off** / **put out** | postpone / extinguish |
| **Look after** / **look into** | take care of / investigate |
| **Take after** / **take over** | resemble / assume control |
| **Give in** / **give up** | yield / abandon |
| **Break out** / **break into** | start suddenly / enter by force |

## Quick revision
- **Put off** = postpone; **put out** = extinguish; **put up with** = tolerate.
- **Call off** = cancel; **call on** = visit a person.
- **Look after** = take care of; **look into** = investigate; **look up to** = respect.
- **Take after** = resemble; **turn down** = reject.
- **Break out** = start suddenly; **bring up** = rear.
- **Do away with** = abolish; **come across** = meet by chance.

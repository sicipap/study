# বানান শুদ্ধি (প্রমিত বানান রীতি)

> **Why it matters:** "কোনটি শুদ্ধ বানান?" প্রশ্ন প্রিলিমিনারি, ব্যাংক ও শিক্ষক নিয়োগ — সব পরীক্ষায় একাধিকবার আসে। বাংলা একাডেমির প্রমিত বানানের নিয়ম আর বহুল ভুল হওয়া শব্দগুলো মুখস্থ রাখলেই নম্বর নিশ্চিত।

## বাংলা একাডেমির প্রমিত বানানের মূল নিয়ম 🔥
বাংলা একাডেমি প্রমিত বানানের নিয়ম প্রথম প্রকাশ করে **১৯৯২ সালে**; পরে পরিমার্জিত হয় (সর্বশেষ বড় সংস্করণ **২০১২**)।

| নিয়ম | উদাহরণ |
|---|---|
| **১. তৎসম শব্দের বানান অপরিবর্তিত** থাকবে | সূর্য, মুহূর্ত, পুরস্কার |
| **২. যেসব তৎসম শব্দে ই/ঈ বা উ/ঊ দুই-ই শুদ্ধ, সেখানে ই/উ** ব্যবহৃত হবে | **শ্রেণি, পদবি, ধমনি, সরণি, ভঙ্গি, রচনাবলি, কিংবদন্তি, সূচিপত্র** |
| **৩. রেফের পর ব্যঞ্জনের দ্বিত্ব হবে না** | **অর্চনা, কার্য, সূর্য, কর্ম, মূর্ছা, বার্ধক্য, কার্তিক** (কার্য্য, সূর্য্য ভুল) |
| **৪. সন্ধিতে ম্‌ এর পরে ক-বর্গ থাকলে ং** লেখা যাবে | **অহংকার, ভয়ংকর, সংগীত, শুভংকর, সংখ্যা, সংঘ** |
| **৫. সন্ধি ছাড়া ঙ্ক, ঙ্গ অপরিবর্তিত** | **অঙ্ক, অঙ্গ, আকাঙ্ক্ষা, আতঙ্ক, গঙ্গা, বঙ্গ, লঙ্ঘন, সঙ্গ** |
| **৬. অতৎসম (তদ্ভব, দেশি, বিদেশি) শব্দে শুধু ই, উ** 🔥 | **বাড়ি, গাড়ি, পাখি, হাতি, দিঘি, রানি, দাদি, নানি, খুশি, বেশি, সরকারি, দরকারি, কাহিনি** |
| **৭. ভাষা ও জাতির নামে ই** | **বাঙালি, ইংরেজি, আরবি, ফারসি, জাপানি, হিন্দি** |
| **৮. অতৎসম শব্দে ণত্ব বিধান খাটে না** — ন হবে | **রানি, কান, সোনা, ঝরনা, ধরন, পরান, কোরান, গভর্নর, হর্ন** |
| **৯. বিদেশি শব্দে ষ নয়, স** | **স্টেশন, পোস্ট, মাস্টার, স্টুডিও, স্টল** |
| **১০. পদের শেষে বিসর্গ থাকবে না** | **কার্যত, মূলত, প্রধানত, বস্তুত, ক্রমশ, প্রায়শ** (তবে শব্দের মধ্যে থাকবে: দুঃখ, অন্তঃপুর, নিঃশব্দ) |
| **১১. হস্‌-চিহ্ন যথাসম্ভব বর্জন** | চট, কাত, করব, করলেন |
| **১২. "কী" ও "কি"** 🔥 | হ্যাঁ/না উত্তরের প্রশ্নে **"কি"** (তুমি কি যাবে?); সর্বনাম, বিশেষণ বা ক্রিয়াবিশেষণে **"কী"** (তোমার নাম কী? কী সুন্দর!) |

### ইন্‌-ভাগান্ত শব্দের নিয়ম 🔥
**মন্ত্রী, প্রাণী, শশী, গুণী, স্বামী** ইত্যাদি **ইন্‌-ভাগান্ত** শব্দ সমাসে পূর্বপদ হলে **ঈ-কার → ই-কার** হয়:
- **মন্ত্রিসভা, মন্ত্রিপরিষদ, প্রাণিবিদ্যা, প্রাণিজগৎ, শশিভূষণ, গুণিজন**।
- **-ত্ব, -তা** প্রত্যয় যুক্ত হলেও ই-কার হয়: **মন্ত্রিত্ব, প্রতিযোগিতা, সহযোগিতা, দায়িত্ব**।

### ণ ও ন-এর বিশেষ শব্দ 🔥
- **অপরাহ্ণ, পূর্বাহ্ণ** (ণ) — কিন্তু **মধ্যাহ্ন, সায়াহ্ন** (ন)।
- **ব্রাহ্মণ, গ্রহণ, পরিমাণ, প্রমাণ, কারণ, রামায়ণ** (ণ)।

**মনে রাখার কৌশল:**
- **"-তা" যোগে বাড়তি ভুল:** দারিদ্র্য, সৌজন্য, ঐক্য, উৎকর্ষ, মাধুর্য, দৈন্য — নিজেরাই বিশেষ্য; এদের সঙ্গে "তা" লাগে না।
- **নিঃ + র → নীর:** নীরব, নীরস, নীরোগ, নীরন্ধ্র (নিঃ-এর বিসর্গ র-এর আগে লোপ পেয়ে ই দীর্ঘ হয়)।
- **দুঃ + অবস্থা → দুরবস্থা**; দুঃ + নীতি → **দুর্নীতি** (দূ নয়, দু)।

## Quick revision
- রেফের পর দ্বিত্ব নয়: **কার্য, সূর্য, অর্চনা**।
- অতৎসম শব্দে **ই/উ**: বাড়ি, সরকারি, রানি, বাঙালি, ইংরেজি।
- বিকল্প থাকলে তৎসমেও ই: **শ্রেণি, পদবি, সূচিপত্র**।
- **মন্ত্রিসভা, প্রাণিবিদ্যা** — ইন্‌-ভাগান্ত নিয়ম।
- **অপরাহ্ণ, পূর্বাহ্ণ** কিন্তু **মধ্যাহ্ন**।
- "তুমি **কি** যাবে?" / "তোমার নাম **কী**?"
- **দারিদ্র্য, সৌজন্য, ঐক্য** — "তা" যোগ ভুল।

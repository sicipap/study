# শব্দ গঠন, দ্বিরুক্ত শব্দ

> **Why it matters:** "'গবেষণা' কোন ধরনের শব্দ (যৌগিক/রূঢ়ি/যোগরূঢ়)?", "'পঙ্কজ' কোন শ্রেণির শব্দ?", "'ঘরে ঘরে' কোন ধরনের দ্বিরুক্তি?", "'ঝমঝম' কী?" — এগুলো ব্যাকরণ অংশে নিয়মিত আসে।

## শব্দ গঠন
নতুন শব্দ তৈরির প্রধান উপায়:

| উপায় | উদাহরণ |
|---|---|
| **উপসর্গ যোগে** | প্র + হার = **প্রহার**; বি + জ্ঞান = **বিজ্ঞান**; অপ + মান = **অপমান** |
| **প্রত্যয় যোগে** (কৃৎ ও তদ্ধিত) | √পঠ্‌ + অক = **পাঠক**; মিঠা + আই = **মিঠাই**; বাবু + আনা = **বাবুয়ানা** |
| **সমাস যোগে** | বিদ্যা রূপ ধন = **বিদ্যাধন**; সিংহ চিহ্নিত আসন = **সিংহাসন** |
| **সন্ধি যোগে** | বিদ্যা + আলয় = **বিদ্যালয়**; নিঃ + রব = **নীরব** |
| **দ্বিরুক্তি যোগে** | ঘরে ঘরে, ঝমঝম, টাকা-পয়সা |

### গঠন অনুসারে শব্দ: দুই প্রকার 🔥
| প্রকার | অর্থ | উদাহরণ |
|---|---|---|
| **মৌলিক শব্দ** | ভাঙা বা বিশ্লেষণ করা যায় না | **গোলাপ, নাক, লাল, হাত, তিন, গাছ** |
| **সাধিত শব্দ** | উপসর্গ, প্রত্যয়, সমাস বা সন্ধির মাধ্যমে গঠিত | **চলন্ত, প্রশাসন, গরমিল, নীলাকাশ** |

### অর্থ অনুসারে শব্দ: তিন প্রকার 🔥
| প্রকার | বৈশিষ্ট্য | উদাহরণ |
|---|---|---|
| **যৌগিক শব্দ** | প্রকৃতি-প্রত্যয়ের অর্থ আর ব্যবহারিক অর্থ **একই** | **গায়ক** (√গৈ + ণক = যে গান করে), **কর্তব্য** (যা করা উচিত), **মধুর** (মধুর মতো মিষ্টি), **দৌহিত্র** (কন্যার পুত্র), **বাবুয়ানা** |
| **রূঢ়ি শব্দ** 🔥 | প্রকৃতি-প্রত্যয়ের অর্থ থেকে **সম্পূর্ণ ভিন্ন** অর্থে প্রচলিত | **হস্তী** (হস্ত + ইন্ = হাত আছে যার, কিন্তু অর্থ **হাতি**), **গবেষণা** (গো + এষণা = গরু খোঁজা, অর্থ **গবেষণা**), **তৈল** (তিলজাত, কিন্তু যেকোনো তেল), **প্রবীণ** (প্র + বীণা = বীণায় দক্ষ, অর্থ **বয়স্ক/অভিজ্ঞ**), **বাঁশি**, **সন্দেশ** |
| **যোগরূঢ় শব্দ** 🔥 | সমাসের অর্থ **একটি বিশেষ অর্থে** সীমিত | **পঙ্কজ** (পঙ্কে জন্মে যা — অনেক কিছুই জন্মে, কিন্তু অর্থ **পদ্ম**), **জলধি** (সমুদ্র), **রাজপুত** (জাতিবিশেষ), **মহাযাত্রা** (মৃত্যু) |

## দ্বিরুক্ত শব্দ 🔥
একই শব্দ **দুবার** ব্যবহার করে বিশেষ অর্থ প্রকাশ করলে তাকে **দ্বিরুক্ত শব্দ** বলে। দ্বিরুক্ত শব্দ **তিন প্রকার**:

| প্রকার | ধরন | উদাহরণ |
|---|---|---|
| **১. শব্দের দ্বিরুক্তি** | অবিকল একই শব্দ | **ভালো ভালো, বড় বড়, লাল লাল, ধীরে ধীরে** |
| | সমার্থক বা প্রায় সমার্থক সহচর শব্দ | **টাকা-পয়সা, ধন-দৌলত, হাসি-খুশি, লোক-লশকর, ধীরে-সুস্থে** |
| | বিকৃত বা অনুকার শব্দ (প্রথমটি মূল, দ্বিতীয়টি বিকৃত) | **বই-টই, জল-টল, চা-টা, মিটমাট** |
| **২. পদের দ্বিরুক্তি** | **বিভক্তিযুক্ত পদের** পুনরাবৃত্তি | **ঘরে ঘরে, হাতে হাতে, মনে মনে, দেশে দেশে, পথে পথে** |
| **৩. ধ্বন্যাত্মক দ্বিরুক্তি** | **ধ্বনির অনুকরণে** গঠিত | **ঝমঝম, টনটন, ঘেউ ঘেউ, কা কা, কনকন, ঝিকিমিকি, টলমল** |

### ধ্বন্যাত্মক দ্বিরুক্তির ভাগ
| ধরন | উদাহরণ |
|---|---|
| **প্রাণীর ডাক** | **ঘেউ ঘেউ** (কুকুর), **কা কা** (কাক), **মিউ মিউ** (বিড়াল), **হাম্বা** |
| **বস্তুর শব্দ** | **ঝমঝম** (বৃষ্টি), **ঠকঠক**, **কড়কড়** (বাজ), **শনশন** (বাতাস) |
| **অনুভূতি/অবস্থা** | **কনকন** (ঠান্ডা), **টনটন** (ব্যথা), **ঝিকিমিকি** (আলো), **টলমল**, **ছমছম** (ভয়) |

### দ্বিরুক্তির অর্থ-বৈচিত্র্য
| অর্থ | উদাহরণ |
|---|---|
| **আধিক্য / বহুবচন** | "**বড় বড়** গাছ", "**লাল লাল** ফুল" |
| **পুনরাবৃত্তি** | "**ডেকে ডেকে** হয়রান" |
| **ক্রমশ ভাব** | "**ধীরে ধীরে** যাও", "**দিন দিন** বাড়ছে" |
| **সামান্যতা / কাছাকাছি অবস্থা** | "**কাঁদো কাঁদো** মুখ", "**উড়ু উড়ু** মন" |
| **তাৎক্ষণিকতা** | "**হাতে হাতে** ফল", "**গরম গরম** জিলাপি" |
| **ভাবের গভীরতা** | "**মনে মনে** ভাবি" |

## Quick revision
- গঠন অনুসারে শব্দ **২ প্রকার**: মৌলিক ও সাধিত।
- অর্থ অনুসারে **৩ প্রকার**: যৌগিক, রূঢ়ি, যোগরূঢ়।
- **গায়ক, কর্তব্য, মধুর, দৌহিত্র** = যৌগিক।
- **হস্তী, গবেষণা, প্রবীণ, তৈল, সন্দেশ** = রূঢ়ি।
- **পঙ্কজ, জলধি, রাজপুত, মহাযাত্রা** = যোগরূঢ়।
- দ্বিরুক্ত শব্দ **৩ প্রকার**: শব্দের, পদের, ধ্বন্যাত্মক।
- **ঘরে ঘরে** = পদের দ্বিরুক্তি; **ঝমঝম** = ধ্বন্যাত্মক; **টাকা-পয়সা** = শব্দের দ্বিরুক্তি।

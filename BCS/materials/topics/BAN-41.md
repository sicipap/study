# বাক্য শুদ্ধি ও অপপ্রয়োগ

> **Why it matters:** "কোন বাক্যটি শুদ্ধ?" বা "অপপ্রয়োগের উদাহরণ কোনটি?" — প্রিলিমিনারি ও ব্যাংক পরীক্ষায় নিয়মিত। বেশিরভাগ ভুল কয়েকটি ধরনে পড়ে: বাহুল্য, গুরুচণ্ডালী, ভুল শব্দরূপ ও ভুল শব্দ নির্বাচন।

## ভুলের প্রধান ধরন 🔥
| ধরন | কী | উদাহরণ |
|---|---|---|
| **বাহুল্য দোষ** | একই অর্থের শব্দ দুবার | "সকল ছাত্রগণ", "অশ্রুজল" |
| **গুরুচণ্ডালী দোষ** | **সাধু ও চলিত** রীতির মিশ্রণ, অথবা **তৎসম শব্দের সঙ্গে দেশি/তদ্ভব শব্দের** বেমানান মিশ্রণ | "গরুর গাড়ি" ঠিক, "গরুর শকট" ভুল; "শবদাহ" ঠিক, "মড়াদাহ" ভুল |
| **বিশেষ্য–বিশেষণের ভুল** | বিশেষণের জায়গায় বিশেষ্য বা উল্টোটা | "তিনি অভিজ্ঞতা লোক" → অভিজ্ঞ |
| **ভুল প্রত্যয়/শব্দরূপ** | অপ্রয়োজনীয় প্রত্যয় | "দারিদ্রতা" → দারিদ্র্য |
| **ভুল শব্দ নির্বাচন** | কাছাকাছি অর্থের ভুল শব্দ | "সাক্ষী দিলেন" → সাক্ষ্য দিলেন |
| **আসত্তি/যোগ্যতার অভাব** | শব্দক্রম বা অর্থসংগতি ভুল | "একটি গরম ভাতের থালা" → এক থালা গরম ভাত |

## বহুল জিজ্ঞাসিত অশুদ্ধ → শুদ্ধ বাক্য 🔥
| অশুদ্ধ | শুদ্ধ | কারণ |
|---|---|---|
| সকল ছাত্রগণ উপস্থিত ছিল। | **সকল ছাত্র উপস্থিত ছিল।** / ছাত্রগণ উপস্থিত ছিল। | দ্বিবচন বাহুল্য |
| সব সদস্যবৃন্দ এসেছেন। | **সদস্যবৃন্দ এসেছেন।** | বাহুল্য |
| তার চোখে অশ্রুজল। | **তার চোখে অশ্রু।** | অশ্রু = চোখের জল |
| আপনাকে সুস্বাগতম। | **আপনাকে স্বাগতম।** | স্বাগত = সু + আগত |
| তিনি আমরণ পর্যন্ত সংগ্রাম করেছেন। | **তিনি আমরণ সংগ্রাম করেছেন।** | "আ" = পর্যন্ত |
| সে আকণ্ঠ পর্যন্ত খেয়েছে। | **সে আকণ্ঠ খেয়েছে।** | বাহুল্য |
| কেবলমাত্র এক টাকা দাও। | **কেবল এক টাকা দাও।** / মাত্র এক টাকা দাও। | কেবল = মাত্র |
| এটি একটি নতুন অভিনব কৌশল। | **এটি একটি অভিনব কৌশল।** | অভিনব = নতুন |
| দেশে আজ দারিদ্রতা বেড়েছে। | **দেশে আজ দারিদ্র্য বেড়েছে।** | দারিদ্র্য নিজেই বিশেষ্য |
| তার সৌজন্যতায় মুগ্ধ হলাম। | **তার সৌজন্যে মুগ্ধ হলাম।** | সৌজন্য বিশেষ্য |
| সে নিরপরাধী। | **সে নিরপরাধ।** | নিঃ + অপরাধ; "ঈ" বাড়তি |
| আবশ্যকীয় সব কাগজ আনবে। | **আবশ্যক সব কাগজ আনবে।** | আবশ্যক নিজেই বিশেষণ |
| তিনি স্বস্ত্রীক বেড়াতে গেলেন। | **তিনি সস্ত্রীক বেড়াতে গেলেন।** | স + স্ত্রী = স্ত্রীসহ |
| আপনি স্বপরিবারে আমন্ত্রিত। | **আপনি সপরিবারে আমন্ত্রিত।** | স + পরিবার = পরিবারসহ |
| মাতাহীন শিশুটি কাঁদছে। | **মাতৃহীন শিশুটি কাঁদছে।** | সমাসে মাতৃ |
| আদালতে সে সাক্ষী দিল। | **আদালতে সে সাক্ষ্য দিল।** | সাক্ষী = ব্যক্তি, সাক্ষ্য = প্রমাণ/বক্তব্য |
| এ কথা প্রমাণ হয়েছে। | **এ কথা প্রমাণিত হয়েছে।** | বিশেষণ প্রয়োজন |
| উপরোক্ত বিষয়টি দেখুন। | **উপর্যুক্ত / উপরিউক্ত বিষয়টি দেখুন।** | উপরি + উক্ত সন্ধি |
| ইতিপূর্বে তিনি এসেছিলেন। | **ইতঃপূর্বে তিনি এসেছিলেন।** | ইতঃ + পূর্বে |
| গরুর দুগ্ধ পুষ্টিকর। | **গরুর দুধ পুষ্টিকর।** | গুরুচণ্ডালী |
| মড়াদাহ করা হলো। | **শবদাহ করা হলো।** | গুরুচণ্ডালী |
| তাহারা খেলতে যাচ্ছে। | **তারা খেলতে যাচ্ছে।** | সাধু-চলিত মিশ্রণ |
| সে আসিবে বলে জানিয়েছে। | **সে আসবে বলে জানিয়েছে।** | সাধু-চলিত মিশ্রণ |
| তিনি সব বিষয়ে অভিজ্ঞতা। | **তিনি সব বিষয়ে অভিজ্ঞ।** | বিশেষণ দরকার |
| একটি গরম ভাতের থালা দাও। | **এক থালা গরম ভাত দাও।** | আসত্তি |
| বর্ষার রৌদ্র প্লাবন ঘটায়। | **বর্ষার বৃষ্টি প্লাবন ঘটায়।** | যোগ্যতা |
| সমুদয় বিষয়গুলো জানাও। | **সমুদয় বিষয় জানাও।** | বাহুল্য |
| অনাবশ্যকীয় কথা বলো না। | **অনাবশ্যক কথা বলো না।** | ভুল প্রত্যয় |
| বিবিধ প্রকার ফল আছে। | **বিবিধ ফল আছে।** / নানা প্রকার ফল আছে। | বিবিধ = নানা প্রকার |

## আরও কিছু সতর্কতা
- **দৈন্য, দারিদ্র্য, সৌজন্য, ঐক্য, উৎকর্ষ, মাধুর্য, সখ্য** — এগুলোর সঙ্গে "তা" লাগে না।
- **"যদিও … তথাপি/তবুও"** জোড়া ঠিক; "যদিও … কিন্তু" একসঙ্গে ব্যবহার বাহুল্য।
- **"পরস্পর"** নিজেই দুইয়ের সম্পর্ক বোঝায়: "তারা পরস্পরকে সাহায্য করে" ঠিক; "তারা একে অপরকে পরস্পর সাহায্য করে" ভুল।
- **"গণ" ও "বৃন্দ"** দুটোই বহুবচন; "সকল/সব/সমূহ" এর সঙ্গে একসাথে নয়।
- **"অধীন"** নিজেই অধীনতা বোঝায়: "অধীনস্থ" শুদ্ধ, কিন্তু "অধীনস্ত" অশুদ্ধ বানান।

## Quick revision
- বাহুল্য: **সকল ছাত্রগণ, অশ্রুজল, সুস্বাগতম, আমরণ পর্যন্ত, কেবলমাত্র** — সব ভুল।
- গুরুচণ্ডালী: সাধু-চলিত মিশ্রণ বা তৎসম-দেশি অসংগত মিশ্রণ (**মড়াদাহ, গরুর শকট**)।
- **সাক্ষ্য দেওয়া**, সাক্ষী দেওয়া নয়।
- **সপরিবারে**, **সস্ত্রীক** (স-যোগে)।
- **নিরপরাধ**, নিরপরাধী নয়; **আবশ্যক**, আবশ্যকীয় নয়।
- **উপর্যুক্ত/উপরিউক্ত**, উপরোক্ত নয়।

## Practice MCQ
**1.** কোন বাক্যটি শুদ্ধ?
(ক) সকল ছাত্রগণ উপস্থিত ছিল (খ) সকল ছাত্র উপস্থিত ছিল (গ) সব ছাত্রবৃন্দ উপস্থিত ছিল (ঘ) সকল ছাত্ররা উপস্থিত ছিল

**2.** "গুরুচণ্ডালী দোষ" ঘটে কোন ক্ষেত্রে?
(ক) সাধু ও চলিত রীতির মিশ্রণে (খ) বানান ভুলে (গ) যতিচিহ্নের ভুলে (ঘ) ক্রিয়ার কাল ভুলে

**3.** কোন বাক্যটি শুদ্ধ?
(ক) আপনাকে সুস্বাগতম (খ) আপনি স্বপরিবারে আমন্ত্রিত (গ) দেশে দারিদ্রতা বেড়েছে (ঘ) তিনি সস্ত্রীক বেড়াতে গেলেন

**4.** কোন বাক্যটি শুদ্ধ?
(ক) আদালতে সে সাক্ষী দিল (খ) আদালতে সে সাক্ষ্য দিল (গ) আদালতে সে সাক্ষীতা দিল (ঘ) আদালতে সে স্বাক্ষ্য দিল

**5.** কোনটি গুরুচণ্ডালী দোষে দুষ্ট?
(ক) শবদাহ (খ) গরুর গাড়ি (গ) মড়াদাহ (ঘ) কাঠের পুতুল

**6.** "তার চোখে অশ্রুজল" — বাক্যটিতে কোন দোষ?
(ক) গুরুচণ্ডালী (খ) আসত্তির অভাব (গ) যোগ্যতার অভাব (ঘ) বাহুল্য

**7.** কোন বাক্যটি শুদ্ধ?
(ক) সে নিরপরাধী (খ) আবশ্যকীয় কাগজ আনবে (গ) সে নিরপরাধ (ঘ) উপরোক্ত বিষয়টি দেখুন

**8.** "তিনি আমরণ পর্যন্ত সংগ্রাম করেছেন" — শুদ্ধ রূপ কোনটি?
(ক) তিনি আমরণ সংগ্রাম করেছেন (খ) তিনি মরণ পর্যন্ত আমরণ সংগ্রাম করেছেন (গ) তিনি আমরণকাল সংগ্রাম করিয়াছেন (ঘ) তিনি আমরণ অবধি পর্যন্ত সংগ্রাম করেছেন

## Answer key
| Q | Ans | Explanation |
|---|---|---|
| 1 | খ | সকল + গণ বা রা একসঙ্গে বাহুল্য |
| 2 | ক | সাধু-চলিত বা তৎসম-দেশি বেমানান মিশ্রণ |
| 3 | ঘ | স + স্ত্রী = সস্ত্রীক; বাকিগুলোতে বাহুল্য বা ভুল |
| 4 | খ | প্রমাণ অর্থে সাক্ষ্য |
| 5 | গ | মড়া দেশি + দাহ তৎসম; শুদ্ধ শবদাহ |
| 6 | ঘ | অশ্রু মানেই চোখের জল |
| 7 | গ | নিরপরাধ বিশেষণ; ঈ বাড়তি |
| 8 | ক | আ-উপসর্গেই পর্যন্ত অর্থ |

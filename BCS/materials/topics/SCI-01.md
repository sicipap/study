# Units, measurement, SI

> **Why it matters:** Exams ask "unit of X?", "named after whom?", "how many base units?" and quick conversions (light-year, nautical mile, °C to °F). These are easy marks if memorised.

## SI system basics 🔥
- **SI (Système International d'Unités, আন্তর্জাতিক একক পদ্ধতি)** was adopted in **1960** by the General Conference on Weights and Measures (CGPM).
- SI has **7 base units (মৌলিক একক)**. All others are **derived units (লব্ধ একক)**.
- Since **2019 (20 May)**, all 7 base units are defined by fixed physical constants (the kilogram is now defined by the **Planck constant**; earlier it was a platinum-iridium cylinder kept in Sèvres, France).

| Base quantity | SI unit | Symbol |
|---|---|---|
| Length (দৈর্ঘ্য) | metre | m |
| Mass (ভর) | kilogram | kg |
| Time (সময়) | second | s |
| Temperature (তাপমাত্রা) | kelvin | K |
| Electric current (তড়িৎ প্রবাহ) | ampere | A |
| Luminous intensity (দীপন তীব্রতা) | candela | cd |
| Amount of substance (পদার্থের পরিমাণ) | mole | mol |

**Memory hook:** the seven symbols are **m, kg, s, K, A, cd, mol**. Anything else (N, J, W, Pa, V, Ω) is derived.

## Derived units named after scientists 🔥🔥
| Quantity | Unit | Named after |
|---|---|---|
| Force (বল) | **newton (N)** = kg·m/s² | Isaac Newton |
| Work / energy (কাজ/শক্তি) | **joule (J)** = N·m | James Prescott Joule |
| Power (ক্ষমতা) | **watt (W)** = J/s | James Watt |
| Pressure (চাপ) | **pascal (Pa)** = N/m² | Blaise Pascal |
| Frequency (কম্পাঙ্ক) | **hertz (Hz)** = 1/s | Heinrich Hertz |
| Electric charge (আধান) | **coulomb (C)** = A·s | Charles-Augustin de Coulomb |
| Potential difference (বিভব পার্থক্য) | **volt (V)** | Alessandro Volta |
| Resistance (রোধ) | **ohm (Ω)** | Georg Simon Ohm |
| Capacitance (ধারকত্ব) | **farad (F)** | Michael Faraday |
| Inductance | **henry (H)** | Joseph Henry |
| Magnetic flux | **weber (Wb)** | Wilhelm Weber |
| Magnetic flux density | **tesla (T)** | Nikola Tesla |
| Radioactivity | **becquerel (Bq)** | Henri Becquerel |
| Conductance | **siemens (S)** | Werner von Siemens |
| Absorbed radiation dose | gray (Gy) | Louis Harold Gray |

Other common units: acceleration **m/s²**, velocity **m/s**, density **kg/m³**, momentum **kg·m/s**, work done by electricity (commercial) **kilowatt-hour (kWh)**, 1 kWh = **3.6 × 10⁶ J** (1 "unit" of electricity bill = 1 kWh).

## Special and large units 🔥
| Unit | Measures | Value |
|---|---|---|
| **Light-year (আলোকবর্ষ)** | **Distance** (not time) | ≈ **9.46 × 10¹⁵ m** (distance light travels in 1 year) |
| **Astronomical unit (AU)** | Distance | Mean Earth–Sun distance ≈ **1.496 × 10¹¹ m** (≈15 crore km) |
| **Parsec** | Distance | ≈ **3.26 light-years** (largest distance unit commonly asked) |
| **Angstrom (Å)** | Very small length (wavelength) | **10⁻¹⁰ m** |
| **Fermi / femtometre** | Nuclear size | **10⁻¹⁵ m** |
| **Micron (µm)** | Length | 10⁻⁶ m |
| **Nautical mile (নটিক্যাল মাইল)** | Distance at sea | **1,852 m** (≈1.852 km) |
| **Knot** | **Speed of ships** | 1 nautical mile per hour |
| **Mile** | Distance | ≈ 1.609 km |
| **Fathom** | **Depth of sea** | 6 feet (≈1.83 m) |
| **Horsepower (HP)** | Power | **746 W** |
| **Calorie** | Heat energy | **4.2 J** (4.184 J) |
| **Barrel** | Crude oil | ≈ 159 litres |
| **Carat** | Purity of gold (24 carat = pure) / mass of gems (1 carat = 200 mg) | |
| **Decibel (dB)** | Sound intensity level | |
| **Richter scale** | Earthquake magnitude | |
| **Bar** | Atmospheric pressure | 10⁵ Pa |
| **Hectare** | Land area | 10,000 m² (≈ 2.47 acres) |

- 1 atmosphere (standard pressure) = **1.013 × 10⁵ Pa** = **76 cm (760 mm) of mercury**.
- 1 acre ≈ 100 decimal (শতাংশ); 1 bigha (Bangladesh) = 33 decimal (common value).

## Temperature scales 🔥
- Formula: **C/5 = (F − 32)/9 = (K − 273)/5**.
- Water freezes: **0 °C = 32 °F = 273 K**. Water boils: **100 °C = 212 °F = 373 K**.
- **−40 °C = −40 °F** (the two scales are equal at −40).
- Normal human body temperature: **37 °C = 98.4–98.6 °F** (NCTB uses 98.4 °F; many guides say 98.6 °F).

## Quick revision
- SI adopted 1960; **7 base units**; kilogram redefined by Planck constant in 2019.
- Unit of force **newton**, work **joule**, power **watt**, pressure **pascal**.
- **Light-year is a unit of distance**, ≈ 9.46 × 10¹⁵ m.
- **1 HP = 746 W**; **1 kWh = 3.6 × 10⁶ J**.
- **1 nautical mile = 1,852 m**; knot = speed of ships.
- **1 Å = 10⁻¹⁰ m**; fermi = 10⁻¹⁵ m.
- **−40 °C = −40 °F**; body temperature 37 °C.
- Lactometer: milk; hygrometer: humidity; anemometer: wind speed.

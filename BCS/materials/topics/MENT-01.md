# Verbal analogy

> **Why it matters:** Nearly every mental ability section has 1–3 analogy questions (সাদৃশ্য). They take the form "A : B :: C : ?". You find the relationship in the first pair and apply the same relationship to the second pair.

## What an analogy question is
- **Analogy (সাদৃশ্য/অনুরূপতা)** means a similarity of relationship. It is written **A : B :: C : D**, read as "A is to B as C is to D".
- The single colon ( : ) means "is related to". The double colon ( :: ) means "in the same way as".
- 🔥 The key skill is to **name the relationship in one short sentence**, e.g. "a doctor works in a hospital". Then test each option with the same sentence: "a teacher works in a ___".

## Solving method (3 steps)
1. **Form a sentence** that links A and B as precisely as possible.
2. **Apply the sentence** to C and each option.
3. If two options fit, **make the sentence more specific** (e.g. "young one of a cow" rather than "related to a cow").

Also check the **order**: if the first pair is "worker : tool", the answer must be in the same order, not "tool : worker".

## Common relationship types 🔥
| Type | Example pair | Relationship sentence |
|---|---|---|
| Synonym | Big : Large | Same meaning |
| Antonym | Rich : Poor | Opposite meaning |
| Worker : workplace | Doctor : Hospital | Works in |
| Worker : tool | Carpenter : Saw; Surgeon : Scalpel | Uses as the main tool |
| Worker : product | Author : Book; Poet : Poem | Creates |
| Instrument : what it measures | Thermometer : Temperature; Barometer : Atmospheric pressure; Ammeter : Current; Hygrometer : Humidity; Seismograph : Earthquakes | Measures |
| Animal : young one | Cow : Calf; Horse : Foal; Dog : Puppy; Cat : Kitten; Lion : Cub; Goat : Kid; Sheep : Lamb | Young one is called |
| Animal : sound | Lion : Roar; Elephant : Trumpet; Dog : Bark; Horse : Neigh; Donkey : Bray; Snake : Hiss; Wolf : Howl | Makes the sound |
| Animal : home | Bee : Hive; Lion : Den; Bird : Nest; Horse : Stable; Spider : Web; Rabbit : Burrow; Cow : Shed | Lives in |
| Part : whole | Page : Book; Petal : Flower; Wheel : Car | Is a part of |
| Cause : effect | Fire : Smoke; Virus : Disease | Produces |
| Degree / intensity | Warm : Hot; Cool : Cold; Happy : Ecstatic | Stronger form |
| Study : subject | Ornithology : Birds; Entomology : Insects; Ichthyology : Fish; Seismology : Earthquakes; Etymology : Word origins | Is the study of |
| Country : currency | Bangladesh : Taka; Japan : Yen; China : Yuan; South Korea : Won; Malaysia : Ringgit | Uses the currency |
| Country : capital | Bangladesh : Dhaka; Nepal : Kathmandu | Capital is |
| Male : female | Horse : Mare; Lion : Lioness; Nephew : Niece | Female is |

Watch the look-alikes: **Entomology** (insects) vs **Etymology** (word origins).

## Non-verbal analogy (numbers and letters)
The same method works for numbers and letters.
- Number: **3 : 27 :: 4 : 64** (the second number is the cube).
- Number: **5 : 26 :: 7 : 50** (n² + 1).
- Letter: **ABC : DEF :: PQR : STU** (next three letters).

## Worked examples
**Example 1.** Pen : Writer :: Brush : ?
Sentence: "a writer uses a pen". A **painter** uses a brush. **Answer: Painter.**

**Example 2.** Cow : Calf :: Sheep : ?
Sentence: "the young one of a cow is a calf". The young one of a sheep is a **lamb**. **Answer: Lamb.**

**Example 3.** Ammeter : Current :: Hygrometer : ?
Sentence: "an ammeter measures current". A hygrometer measures **humidity**. **Answer: Humidity.**

**Example 4.** Happy : Ecstatic :: Angry : ?  Options: Upset, Furious, Calm, Sad.
Sentence: "ecstatic is a very strong form of happy". A very strong form of angry is **furious**. Upset is weaker, and calm is the opposite. **Answer: Furious.**

**Example 5.** 4 : 17 :: 6 : ?
4² + 1 = 17, so 6² + 1 = **37**. **Answer: 37.**

## Quick revision
- Name the relationship in one sentence, then apply it to every option.
- Keep the order of the pair the same.
- Barometer → atmospheric pressure; hygrometer → humidity; seismograph → earthquakes.
- Horse → foal (young), neigh (sound), stable (home), mare (female).
- Elephant → trumpet; donkey → bray; snake → hiss.
- Ornithology = birds; entomology = insects; ichthyology = fish; etymology = word origins.
- Japan → Yen; China → Yuan; South Korea → Won.
- If two options fit, make your relationship sentence more specific.

**3.** Cow : Calf :: Horse : ?
(a) Foal (b) Kid (c) Cub (d) Puppy

**4.** Lion : Roar :: Elephant : ?

(a) 25 (b) 15 (c) 100 (d) 125

# Types of computers

> **Why it matters:** Exams ask which computer works on continuous vs discrete data, what a hybrid computer is used for, and the names of supercomputers. Questions are short and factual.

## Classification by working principle (data type) 🔥
| Type | Works on | Examples / uses |
|---|---|---|
| 🔥 **Analog computer (অ্যানালগ কম্পিউটার)** | **Continuous** data (voltage, pressure, temperature); measures | Speedometer, thermometer, voltmeter, seismograph, old slide-rule type devices |
| 🔥 **Digital computer (ডিজিটাল কম্পিউটার)** | **Discrete** data, **binary digits (0 and 1)**; counts | Personal computers, laptops, calculators, smartphones |
| 🔥 **Hybrid computer (হাইব্রিড কম্পিউটার)** | **Both** analog and digital | **ICU/hospital patient monitoring**, ECG machines, weather forecasting, missile and aircraft systems |

- An analog computer **measures**; a digital computer **counts**.
- Most computers used today are **digital**.

## Classification by size and capacity 🔥
| Type | Key features | Examples |
|---|---|---|
| 🔥 **Supercomputer** | **Fastest and most powerful**; speed measured in **FLOPS** (floating-point operations per second); thousands of processors in parallel | **Frontier** (USA), **El Capitan** (USA), **Fugaku** (Japan), Summit; first well-known supercomputer: **CDC 6600** (1964, Seymour Cray) |
| **Mainframe computer** | Large; serves **hundreds or thousands of users at once**; high reliability | Banks, airlines, insurance, census; **IBM zSeries (IBM Z)** |
| **Minicomputer** | Medium-sized; multi-user (tens to hundreds of users) | **PDP-8, PDP-11** (DEC), IBM AS/400 |
| **Microcomputer** | Smallest; built around a **microprocessor**; one user | Desktop, laptop, tablet, smartphone |

- 🔥 **Seymour Cray** is called the **father of the supercomputer**.
- Uses of supercomputers: **weather forecasting**, climate modelling, nuclear research, space research, genome analysis.
- Supercomputer rankings are published twice a year in the **TOP500** list (June and November). **Frontier** (USA) was the first to officially pass **1 exaflop** (2022); **El Capitan** (USA) topped the list from November 2024.

> 🔄 Update: check the latest TOP500 list; the top supercomputer changes every six months.

## Types of microcomputers
| Type | Notes |
|---|---|
| **Desktop** | Sits on a desk; separate monitor, keyboard, CPU case |
| **Laptop / Notebook** | Portable, battery-powered |
| **Tablet** | Touchscreen, no physical keyboard (e.g. iPad) |
| **Palmtop / PDA** (Personal Digital Assistant) | Handheld; now replaced by smartphones |
| **Smartphone** | Mobile phone with a full operating system |
| **Workstation** | High-end single-user computer for engineering, graphics and design work |
| **Server** | Provides services (web, files, email, database) to other computers over a network |

## Classification by purpose
- **General-purpose computer:** can do many kinds of jobs (PC, laptop).
- **Special-purpose (dedicated) computer:** built for one job, e.g. an **embedded system** in a washing machine, microwave, ATM, traffic light or car.

## Other terms asked
- **Embedded system:** a computer inside another device to control it; usually runs one fixed program.
- **Quantum computer:** uses **qubits**, which can be 0 and 1 at the same time (**superposition**). Linked with the 5th generation.
- **Thin client:** a simple computer that depends on a server for most processing.

## Computers in Bangladesh
- First computer: **IBM 1620** (1964), Atomic Energy Centre, Dhaka. It was a **2nd-generation** (transistor) machine.
- Guidebooks usually name **BUET** as the place where Bangladesh's first supercomputer was installed. The details vary between sources, so learn only the name.

## Quick revision
- Analog = **continuous**, measures; Digital = **discrete (0/1)**, counts; Hybrid = **both**.
- Hybrid computer example: **hospital ICU / patient monitoring**.
- Most powerful computer: **supercomputer**; speed in **FLOPS**.
- Father of supercomputer: **Seymour Cray**; CDC 6600.
- Banks and airlines use **mainframe** computers.
- PC, laptop, smartphone are **microcomputers**.
- Supercomputers are used most for **weather forecasting**.

## Practice MCQ
**1.** Which computer works on continuous data?
(a) Analog (b) Digital (c) Micro (d) Mainframe

**2.** A computer used in a hospital ICU to monitor a patient's heartbeat and blood pressure is usually a:
(a) Mainframe computer (b) Minicomputer (c) Hybrid computer (d) Supercomputer

**3.** The speed of a supercomputer is measured in:
(a) MIPS only (b) FLOPS (c) Baud (d) Hertz only

**4.** Who is known as the father of the supercomputer?
(a) Charles Babbage (b) Alan Turing (c) Bill Gates (d) Seymour Cray

**5.** Large banks and airlines, where thousands of users work at once, mostly use:
(a) Microcomputers (b) Mainframe computers (c) Analog computers (d) Palmtops

**6.** A digital computer works on:
(a) Discrete binary data (b) Continuous signals only (c) Pressure readings (d) Temperature only

**7.** A smartphone belongs to which class of computers?
(a) Minicomputer (b) Mainframe (c) Supercomputer (d) Microcomputer

**8.** PDP-11 is an example of a:
(a) Supercomputer (b) Minicomputer (c) Hybrid computer (d) Analog computer

## Answer key
| Q | Ans | Explanation |
|---|---|---|
| 1 | a | Analog computers measure continuous quantities |
| 2 | c | Hybrid computers combine analog and digital, e.g. ICU monitoring |
| 3 | b | FLOPS = floating-point operations per second |
| 4 | d | Seymour Cray designed the CDC 6600 |
| 5 | b | Mainframes serve many users at once with high reliability |
| 6 | a | Digital computers use 0 and 1 |
| 7 | d | Microcomputers are built around a microprocessor |
| 8 | b | PDP-8 and PDP-11 were DEC minicomputers |

# সংখ্যাবাচক ও ক্রমবাচক শব্দ

> **Why it matters:** "'ষোড়শ' কোন সংখ্যার পূরণবাচক রূপ?", "'দোসরা' কোন ধরনের সংখ্যাবাচক শব্দ?", "'অশীতিপর' মানে কত বছর বয়সী?", "'পঞ্চাশত্তম' বানান" — এগুলো থেকে প্রিলিমিনারি ও শিক্ষক নিয়োগে প্রশ্ন আসে।

## সংখ্যাবাচক শব্দের প্রকারভেদ 🔥
| প্রকার | অর্থ | উদাহরণ |
|---|---|---|
| **অঙ্কবাচক** | অঙ্কে লেখা সংখ্যা | ১, ২, ৩, ১০ |
| **পরিমাণ/গণনাবাচক** | কত সংখ্যক | **এক, দুই, তিন, দশ, শত** |
| **ক্রমবাচক (পূরণবাচক)** | ক্রম বা স্থান বোঝায় | **প্রথম, দ্বিতীয়, তৃতীয়, দশম** |
| **তারিখবাচক** | মাসের দিন বোঝায় | **পহেলা, দোসরা, তেসরা, চৌঠা** |

| সংখ্যা | ক্রমবাচক | স্ত্রীবাচক রূপ (তিথি) | সংখ্যা | ক্রমবাচক |
|---|---|---|---|---|

| ২ | **দ্বিতীয়** | দ্বিতীয়া | ১২ | **দ্বাদশ** |
| ৩ | **তৃতীয়** | তৃতীয়া | ১৩ | **ত্রয়োদশ** |
| ৪ | **চতুর্থ** | চতুর্থী | ১৪ | **চতুর্দশ** |
| ৫ | **পঞ্চম** | পঞ্চমী | ১৫ | **পঞ্চদশ** |
| ৬ | **ষষ্ঠ** | ষষ্ঠী | ১৬ | **ষোড়শ** 🔥 |
| ৭ | **সপ্তম** | সপ্তমী | ১৭ | **সপ্তদশ** |
| ৮ | **অষ্টম** | অষ্টমী | ১৮ | **অষ্টাদশ** |

| ১০ | **দশম** | দশমী | ২০ | **বিংশ / বিংশতিতম** |

### বড় সংখ্যার ক্রমবাচক 🔥
| সংখ্যা | সংস্কৃত সংখ্যাশব্দ | ক্রমবাচক |
|---|---|---|
| ২১ | একবিংশতি | **একবিংশ / একবিংশতিতম** |
| ৩০ | **ত্রিংশৎ** | **ত্রিংশ / ত্রিংশত্তম** |
| ৪০ | **চত্বারিংশৎ** | **চত্বারিংশ / চত্বারিংশত্তম** |
| ৫০ | **পঞ্চাশৎ** | **পঞ্চাশত্তম** |
| ৬০ | **ষষ্টি** | **ষষ্টিতম** |
| ৭০ | **সপ্ততি** | **সপ্ততিতম** |
| ৮০ | **অশীতি** | **অশীতিতম** |
| ৯০ | **নবতি** | **নবতিতম** |
| ১০০ | **শত** | **শততম** |

- ক্রমবাচক গঠনে প্রত্যয়: **-ম** (পঞ্চম, সপ্তম), **-থ** (চতুর্থ), **-য়** (দ্বিতীয়, তৃতীয়), **-ষ্ঠ** (ষষ্ঠ), **-তম** (বিংশতিতম, শততম)।
- 🔥 "ৎ"-এ শেষ হওয়া শব্দে **-তম** যোগে **ত্ত** হয়: ত্রিংশৎ + তম = **ত্রিংশত্তম**, পঞ্চাশৎ + তম = **পঞ্চাশত্তম**।
- বয়স বোঝাতে: **ষষ্টিপর** (ষাটোর্ধ্ব), **সপ্ততিপর** (সত্তরোর্ধ্ব), **অশীতিপর** 🔥 (আশি বছরের বেশি), **নবতিপর** (নব্বই বছরের বেশি)।
- **শতবার্ষিকী** = ১০০ বছর পূর্তি; **সার্ধশতবার্ষিকী** = ১৫০ বছর পূর্তি।

## তারিখবাচক শব্দ 🔥
| তারিখ | শব্দ | তারিখ | শব্দ |
|---|---|---|---|
| ১ | **পহেলা** | ৬ | **ছয়ই (ছউই)** |
| ২ | **দোসরা** | ৭ | সাতই |
| ৩ | **তেসরা** | ১০ | দশই |
| ৪ | **চৌঠা** | ১৮ | আঠারোই |
| ৫ | **পাঁচই** | ১৯ থেকে ৩১ | **-এ** যোগে: উনিশে, বিশে, **একুশে**, বাইশে, ত্রিশে, একত্রিশে |

- **১ থেকে ৪** তারিখের রূপ হিন্দি/ফারসি প্রভাবিত (পহেলা, দোসরা, তেসরা, চৌঠা); **৫ থেকে ১৮** পর্যন্ত **-ই**; **১৯ থেকে** **-এ** যোগ হয়।
- "পহেলা বৈশাখ", "একুশে ফেব্রুয়ারি" — তারিখবাচক শব্দের উদাহরণ।

## পরিমাণ ও ভগ্নাংশবাচক শব্দ
| শব্দ | মান | শব্দ | মান |
|---|---|---|---|
| **জোড়া** | ২ | **পোয়া / সিকি** | ১/৪ |
| **হালি / গন্ডা** | ৪ | **আধা** | ১/২ |
| **ডজন** | ১২ | **পৌনে** | ১/৪ কম (পৌনে দুই = ১¾) |
| **কুড়ি** | ২০ | **সোয়া** | ১/৪ বেশি (সোয়া দুই = ২¼) |
| **পণ** | ৮০ (২০ গন্ডা) | **দেড়** | ১½ |
| **শ / শত** | ১০০ | **আড়াই** | ২½ |
| **হাজার / সহস্র** | ১০০০ | **সাড়ে** | ১/২ বেশি (সাড়ে তিন = ৩½) |

- বড় সংখ্যা: **অযুত** = ১০,০০০; **লক্ষ** = ১,০০,০০০; **নিযুত** = ১০,০০,০০০; **কোটি** = ১,০০,০০,০০০।
- সংখ্যাবাচক শব্দ পূর্বপদে থেকে **দ্বিগু সমাস** গঠন করে: **ত্রিভুবন, চৌরাস্তা, তেমাথা, সপ্তাহ, পঞ্চবটী, শতাব্দী, ত্রিফলা**।

## Quick revision
- সংখ্যাবাচক শব্দ **৪ প্রকার**: অঙ্কবাচক, গণনাবাচক, ক্রমবাচক, তারিখবাচক।
- ১৬ = **ষোড়শ**; ১৮ = **অষ্টাদশ**; ১৯ = **ঊনবিংশ**; ২০ = **বিংশ**।
- ৩০ = **ত্রিংশত্তম**; ৪০ = **চত্বারিংশত্তম**; ৫০ = **পঞ্চাশত্তম**; ৬০ = **ষষ্টিতম**।
- **অশীতিপর** = আশি বছরের বেশি বয়সী।
- **পহেলা, দোসরা, তেসরা, চৌঠা** = তারিখবাচক।
- **কুড়ি = ২০, পণ = ৮০, গন্ডা/হালি = ৪**।
- সংখ্যাবাচক পূর্বপদ → **দ্বিগু সমাস** (ত্রিভুবন, শতাব্দী)।

## Practice MCQ
**1.** "ষোড়শ" কোন সংখ্যার ক্রমবাচক রূপ?

**2.** "দোসরা" কোন ধরনের সংখ্যাবাচক শব্দ?
(ক) তারিখবাচক (খ) ক্রমবাচক (গ) গণনাবাচক (ঘ) অঙ্কবাচক

**3.** পঞ্চাশ সংখ্যার ক্রমবাচক রূপের শুদ্ধ বানান কোনটি?
(ক) পঞ্চাশতম (খ) পঞ্চাশত্তম (গ) পঞ্চশততম (ঘ) পঞ্চাশতমো

**4.** "অশীতিপর" বলতে কত বছরের বেশি বয়সী বোঝায়?
(ক) ষাট (খ) সত্তর (গ) নব্বই (ঘ) আশি

**5.** "ঊনবিংশ" কোন সংখ্যার ক্রমবাচক রূপ?
(ক) উনিশ (খ) একুশ (গ) নয় (ঘ) উনত্রিশ

**6.** "পণ" বলতে কত সংখ্যা বোঝায়?

**7.** "চত্বারিংশৎ" কোন সংখ্যা?
(ক) চার (খ) চল্লিশ (গ) চৌদ্দ (ঘ) চারশো

**8.** সংখ্যাবাচক শব্দ পূর্বপদে থাকলে সাধারণত কোন সমাস হয়?
(ক) দ্বন্দ্ব (খ) কর্মধারয় (গ) বহুব্রীহি (ঘ) দ্বিগু

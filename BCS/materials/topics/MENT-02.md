# Word meaning based reasoning

> **Why it matters:** Exams test how well you handle words logically: putting words in dictionary order, arranging words in a meaningful sequence, making words from the letters of a given word, and finding synonyms, antonyms or a word from jumbled letters.

## 1. Dictionary (alphabetical) order 🔥
- Compare the **first letter**. If it is the same, compare the **second letter**, and so on.
- A shorter word that is the **start of a longer word comes first**: **Govern** comes before **Governance**.
- Tip: write only the part where the words differ. For Adapt / Adjust / Admire / Adopt, compare the 3rd letter: a, j, m, o. So the order is **Adapt, Adjust, Admire, Adopt**.

## 2. Logical (meaningful) sequence of words 🔥
Arrange the words by a natural order:
| Basis | Example (correct order) |
|---|---|
| Life cycle | Birth → Childhood → Youth → Old age → Death |
| Size (small to big) | Letter → Word → Phrase → Sentence → Paragraph |
| Administrative units of Bangladesh | Village → Union → Upazila → District → Division |
| Process | Seed → Plant → Flower → Fruit |
| Education | Primary → Secondary → Higher Secondary → Graduation |
| Making cloth | Cotton → Yarn → Cloth → Garment |

Method: find the **first** and **last** words first; then fill in the middle. Then check the options. Often only one option starts with the right word.

## 3. Making words from the letters of a given word 🔥
- A word **can be formed** only if every letter it needs is in the given word, **and in enough numbers**.
- Method: count the letters of the given word first. EXAMINATION has E, X, M, T, O once each and A, I, N twice each.
- Then check each option letter by letter. One missing letter (or one letter used too often) means the word **cannot** be formed.
  - From EXAMINATION: NATION ✔ (N twice is available), EXAM ✔, MINT ✔, **TAMIL ✘** (there is no L).

## 4. Jumbled letters (anagrams)
- Rearrange the letters to make a meaningful word, often of a given category (fruit, country, animal).
- Start with common endings (-ION, -ING, -ER, -TION) or with a vowel–consonant pattern.
- Examples: NGAMO → **MANGO**; ANDIA → **INDIA**; LEPPA → **APPLE**.

## 5. Synonyms and antonyms in reasoning
- **Synonym (সমার্থক):** word with nearly the same meaning. Abundant = **Plentiful**; Candid = **Frank**.
- **Antonym (বিপরীতার্থক):** word with the opposite meaning. Ancient ↔ **Modern**; Scarce ↔ **Plentiful**.
- Watch out for options that are related but not the same, like "Rare" for Abundant.

## Worked examples
**Example 1.** Arrange in dictionary order: Principle, Principal, Prince, Print.
Common start "Prin". Next letters: c (Prince, Principal, Principle), t (Print). Within "Princ": Prince (e), Principal (i-p-a), Principle (i-p-l). "a" comes before "l". **Order: Prince, Principal, Principle, Print.**

**Example 2.** Arrange in a meaningful order: 1. Wall 2. Clay 3. House 4. Room 5. Brick.
Clay → Brick → Wall → Room → House = **2, 5, 1, 4, 3.**

**Example 3.** Which word cannot be formed from INFORMATION?
Letters: I, N, O (two each); F, R, M, A, T (one each). FOREST needs E and S, which are not there. **Answer: FOREST.**

**Example 4.** Rearrange NGAMO to get a fruit. What is the last letter?
NGAMO → **MANGO**, so the last letter is **O**.

## Quick revision
- Dictionary order: compare letter by letter; a shorter word that is the start of a longer one comes first.
- Meaningful order: find the first and the last word, then fill the middle.
- Village → Union → Upazila → District → Division.
- Letter → Word → Phrase → Sentence → Paragraph.
- To form a word, check both that each letter is there and that there are enough of it.
- Anagram: try common endings (-TION, -ING, -ER).

## Practice MCQ
**1.** Which word comes third in dictionary order: Admire, Adjust, Adopt, Adapt?
(a) Adjust (b) Admire (c) Adopt (d) Adapt

**2.** Arrange in a meaningful order: 1. Birth 2. Death 3. Childhood 4. Youth 5. Old age
(a) 1, 3, 5, 4, 2 (b) 3, 1, 4, 5, 2 (c) 1, 3, 4, 5, 2 (d) 1, 4, 3, 5, 2

**3.** Which word cannot be formed from the letters of EXAMINATION?
(a) NATION (b) MINT (c) TAMIL (d) EXAM

**4.** Which word is nearest in meaning to ABUNDANT?
(a) Scarce (b) Plentiful (c) Empty (d) Rare

**5.** If the letters NGAMO are rearranged to make the name of a fruit, what is the last letter of that word?
(a) M (b) N (c) G (d) O

**6.** Arrange in a meaningful order: 1. Word 2. Paragraph 3. Sentence 4. Letter 5. Phrase
(a) 4, 1, 3, 5, 2 (b) 4, 1, 5, 3, 2 (c) 1, 4, 5, 3, 2 (d) 4, 5, 1, 3, 2

**7.** Which word comes last in dictionary order?
(a) Governance (b) Government (c) Governor (d) Govern

**8.** Which word cannot be formed from the letters of INFORMATION?
(a) FORMAT (b) NATION (c) MOTION (d) FOREST

**9.** Arrange from smallest to largest: 1. Village 2. District 3. Division 4. Upazila 5. Union
(a) 1, 5, 4, 2, 3 (b) 1, 4, 5, 2, 3 (c) 5, 1, 4, 2, 3 (d) 1, 5, 2, 4, 3

**10.** Which word is the opposite of ANCIENT?
(a) Modern (b) Old (c) Historic (d) Antique

## Answer key
| Q | Ans | Explanation |
|---|---|---|
| 1 | b | Order is Adapt, Adjust, Admire, Adopt (3rd letters a, j, m, o). |
| 2 | c | Birth, Childhood, Youth, Old age, Death. |
| 3 | c | EXAMINATION has no L, so TAMIL cannot be formed. |
| 4 | b | Abundant means plentiful. |
| 5 | d | NGAMO = MANGO, which ends in O. |
| 6 | b | Letter, Word, Phrase, Sentence, Paragraph. |
| 7 | c | Govern, Governance, Government, Governor; "o" comes after "a" and "m". |

# সমাস: তৎপুরুষ, বহুব্রীহি, দ্বিগু, অব্যয়ীভাব

> **Why it matters:** "পঙ্কজ", "বিলাতফেরত", "নীলকণ্ঠ", "হাতাহাতি", "দশানন", "সপ্তাহ", "ত্রিফলা", "আজানুলম্বিত", "যথারীতি", "উপকূল" — সমাস নির্ণয়ের প্রশ্ন প্রায় প্রতিটি পরীক্ষায় থাকে।

## তৎপুরুষ সমাস 🔥🔥
পূর্বপদের **বিভক্তি লোপ** পায় এবং **পরপদের অর্থ প্রধান** হয়। পূর্বপদে যে বিভক্তি লোপ পায়, সে অনুযায়ী নাম।

| প্রকার | লুপ্ত বিভক্তি/অনুসর্গ | উদাহরণ |
|---|---|---|
| **দ্বিতীয়া** | কে, রে, ব্যাপিয়া | **দুঃখকে প্রাপ্ত = দুঃখপ্রাপ্ত**, **বিপদকে আপন্ন = বিপদাপন্ন**, **চিরকাল ব্যাপিয়া সুখী = চিরসুখী** |
| **তৃতীয়া** | দ্বারা, দিয়ে | **মন দিয়ে গড়া = মনগড়া**, **শ্রম দ্বারা লব্ধ = শ্রমলব্ধ**, **মধু দিয়ে মাখা = মধুমাখা**, **ঢেঁকি দিয়ে ছাঁটা = ঢেঁকিছাঁটা** |
| **চতুর্থী** | জন্য, নিমিত্ত | **গুরুকে ভক্তি = গুরুভক্তি**, **ছাত্রদের জন্য নিবাস = ছাত্রনিবাস**, **বসতের নিমিত্ত বাড়ি = বসতবাড়ি**, **বিয়ের জন্য পাগলা = বিয়েপাগলা** |
| **পঞ্চমী** | থেকে, হতে | 🔥 **বিলাত থেকে ফেরত = বিলাতফেরত**, **খাঁচা থেকে ছাড়া = খাঁচাছাড়া**, **পদ থেকে চ্যুত = পদচ্যুত**, **জেল থেকে খালাস = জেলখালাস** |
| **ষষ্ঠী** | র, এর | **রাজার পুত্র = রাজপুত্র**, **গঙ্গার জল = গঙ্গাজল**, **খেয়ার ঘাট = খেয়াঘাট**, **দেবতার আলয় = দেবালয়**, **বিদ্যার আলয় = বিদ্যালয়** |
| **সপ্তমী** | এ, য়, তে | **গাছে পাকা = গাছপাকা**, **দিবায় নিদ্রা = দিবানিদ্রা**, **বাক্সে বন্দি = বাক্সবন্দি** |
| **নঞ্ তৎপুরুষ** | না-বাচক অব্যয় | **ন জানা = অজানা**, **ন আদর = অনাদর**, **ন অতিদীর্ঘ = নাতিদীর্ঘ**, **ন অতিশীতোষ্ণ = নাতিশীতোষ্ণ** |
| **উপপদ তৎপুরুষ** 🔥 | কৃদন্ত পদের আগের পদ | **পঙ্কে জন্মে যা = পঙ্কজ**, **জলে চরে যা = জলচর**, **সত্য বলে যে = সত্যবাদী**, **ছেলে ধরে যে = ছেলেধরা**, **পকেট মারে যে = পকেটমার** |
| **অলুক তৎপুরুষ** | বিভক্তি লোপ পায় না | **ঘিয়ে ভাজা**, **তেলে ভাজা**, **গায়ে পড়া**, **কলের গান** |

## বহুব্রীহি সমাস 🔥🔥
সমস্যমান পদগুলোর কোনোটির অর্থ না বুঝিয়ে **অন্য কোনো পদের অর্থ** বোঝায়। (বহু ব্রীহি [ধান] আছে যার = বহুব্রীহি)

| প্রকার | উদাহরণ |
|---|---|
| **সমানাধিকরণ** (পূর্বপদ বিশেষণ, পরপদ বিশেষ্য) | **নীল কণ্ঠ যার = নীলকণ্ঠ**, **হত হয়েছে শ্রী যার = হতশ্রী**, **পীত অম্বর যার = পীতাম্বর** |
| **ব্যধিকরণ** (দুটিই বিশেষ্য) | **আশীতে (দাঁতে) বিষ যার = আশীবিষ**, **কথা সর্বস্ব যার = কথাসর্বস্ব** |
| **ব্যতিহার** (একই রকম দুই পদ, পরস্পর ক্রিয়া) | 🔥 **হাতে হাতে যে যুদ্ধ = হাতাহাতি**, **লাঠিতে লাঠিতে যে লড়াই = লাঠালাঠি**, **কানে কানে যে কথা = কানাকানি**, **চুলে চুলে টেনে যে ঝগড়া = চুলোচুলি** |
| **নঞ্ বহুব্রীহি** | **নাই জ্ঞান যার = অজ্ঞান**, **নাই বোধ যার = নির্বোধ**, **নাই লজ্জা যার = নির্লজ্জ**, **নাই নুন যাতে = আলুনি**, **নাই চারা (উপায়) যার = নাচার** |
| **মধ্যপদলোপী বহুব্রীহি** | **হাতে খড়ি দেওয়া হয় যে অনুষ্ঠানে = হাতেখড়ি**, **গায়ে হলুদ দেওয়া হয় যে অনুষ্ঠানে = গায়েহলুদ**, **বিড়ালের চোখের ন্যায় চোখ যে নারীর = বিড়ালচোখী** |
| **অলুক বহুব্রীহি** | **মুখে মধু যার = মুখে-মধু**, **গলায় গামছা যার = গলায়-গামছা** |
| **সংখ্যাবাচক বহুব্রীহি** | 🔥 **দশ আনন যার = দশানন**, **পঞ্চ আনন যার = পঞ্চানন**, **ত্রি নয়ন যার = ত্রিনয়ন**, **সে (তিন) তার যার = সেতার**, **চৌ (চার) চাল যে ঘরের = চৌচালা**, **দুই দিকে অপ (পানি) যার = দ্বীপ**, **তে (তিন) তলা যার = তেতলা** |
| **সহার্থক বহুব্রীহি** | **বান্ধবের সহিত বর্তমান = সবান্ধব**, **সহ উদর যার = সহোদর**, **লজ্জার সহিত বর্তমান = সলজ্জ** |

- সতর্কতা: **পীতাম্বর** = "পীত যে অম্বর" হলে **কর্মধারয়**; "পীত অম্বর যার" (শ্রীকৃষ্ণ অর্থে) হলে **বহুব্রীহি**। অর্থ দেখে সমাস ঠিক করতে হয়।

## দ্বিগু সমাস 🔥
**সমাহার (সমষ্টি)** অর্থে **সংখ্যাবাচক শব্দ + বিশেষ্য**; পরপদের অর্থ প্রধান।
**তিন মাথার সমাহার = তেমাথা**, **তিন পদের সমাহার = ত্রিপদী**, **সপ্ত অহের সমাহার = সপ্তাহ**, **পঞ্চ বটের সমাহার = পঞ্চবটী**, **শত অব্দের সমাহার = শতাব্দী**, **তিন কালের সমাহার = ত্রিকাল**, **নব রত্নের সমাহার = নবরত্ন**, **চৌ রাস্তার সমাহার = চৌরাস্তা**, **তিন ভুবনের সমাহার = ত্রিভুবন**, **তিন ফলের সমাহার = ত্রিফলা**, **পঞ্চ নদের সমাহার = পঞ্চনদ**।

- পার্থক্য: দ্বিগুতে **"সমাহার"**; সংখ্যাবাচক বহুব্রীহিতে **"যার"** (দশানন = দশ আনন যার)।

## অব্যয়ীভাব সমাস 🔥
পূর্বপদে **অব্যয়** থাকে এবং **অব্যয়ের অর্থই প্রধান**।

| অব্যয়ের অর্থ | উদাহরণ |
|---|---|
| **পর্যন্ত (আ)** | **জানু পর্যন্ত লম্বিত = আজানুলম্বিত**, **মরণ পর্যন্ত = আমরণ**, **সমুদ্র থেকে হিমাচল পর্যন্ত = আসমুদ্রহিমাচল** |
| **সামীপ্য (উপ)** | **কূলের সমীপে = উপকূল**, **কণ্ঠের সমীপে = উপকণ্ঠ** |
| **সাদৃশ্য (উপ, প্রতি)** | **বনের সদৃশ = উপবন**, **ধ্বনির সদৃশ = প্রতিধ্বনি** |
| **বীপ্সা/পুনঃপুনঃ (প্রতি)** | **দিন দিন = প্রতিদিন**, **ক্ষণে ক্ষণে = প্রতিক্ষণ** |
| **অনতিক্রম্যতা (যথা)** | **রীতিকে অতিক্রম না করে = যথারীতি**, **সাধ্যকে অতিক্রম না করে = যথাসাধ্য**, **শক্তিকে অতিক্রম না করে = যথাশক্তি** |
| **অভাব (নিঃ, দুঃ, হা)** | **জলের অভাব = নির্জল**, **উৎসাহের অভাব = নিরুৎসাহ**, **ভিক্ষার অভাব = দুর্ভিক্ষ**, **ভাতের অভাব = হাভাত** |
| **পশ্চাৎ (অনু)** | **পশ্চাৎ গমন = অনুগমন**, **পশ্চাৎ ধাবন = অনুধাবন** |
| **বিরোধ (প্রতি)** | **কূলের বিরুদ্ধ = প্রতিকূল** |

## Quick revision
- বিলাতফেরত — **পঞ্চমী তৎপুরুষ**; রাজপুত্র — **ষষ্ঠী তৎপুরুষ**।
- পঙ্কজ, জলচর, সত্যবাদী — **উপপদ তৎপুরুষ**।
- নাতিদীর্ঘ, অজানা — **নঞ্ তৎপুরুষ**; ঘিয়ে ভাজা — **অলুক তৎপুরুষ**।
- হাতাহাতি, লাঠালাঠি — **ব্যতিহার বহুব্রীহি**।
- দশানন, সেতার, দ্বীপ — **সংখ্যাবাচক বহুব্রীহি**।
- সপ্তাহ, ত্রিফলা, শতাব্দী, চৌরাস্তা — **দ্বিগু**।
- আজানুলম্বিত, উপকূল, যথারীতি, প্রতিদিন, দুর্ভিক্ষ — **অব্যয়ীভাব**।
